# 標準音階與琶音指法 (Standard Scale & Arpeggio Fingering)

教學傳統的**基石**（見 `[[concept_pedagogical_fingering_tradition]]`）：音階與琶音的指法是每個學生反覆操練、最早內化的 pattern。本專案的 long-scale thumb-under 規則就是在近似這套慣例。

## 大調音階（白鍵調，C/G/D/A/E）

以 thumb-under 把 7 音分成 **3+4** 兩組：

| 手 | 上行（一個八度）| 下行 |
|---|---|---|
| **RH** | 1 2 3　1 2 3 4　(5 在頂) | 5 4 3 2　1 3 2 1 |
| **LH** | 5 4 3 2　1 3 2 1 | 1 2 3　1 2 3 4　(5 在底) |

- **RH 上行**：拇指在第 4 音（F）穿到第 3 指之下 → 1234 再接。下行則第 3 指跨過拇指。
- **LH 與 RH 鏡像**：LH 上行用 5 起、拇指在第 5 音附近接力。
- 記憶法：RH「拇指過 E、B」（即每組 3、4 音後 thumb-under）；LH 鏡像。

## 核心規則

1. **拇指不落黑鍵**（主要原則）— 決定 thumb-under 的位置。黑鍵多的調（B / F♯ / D♭…）依此調整分組。
2. **以 3 或 4 分組** — 白鍵調是 3+4；黑鍵調依「拇指落白鍵」重新分組（如 B♭ 大調 RH 從 f4 起）。對應 DP 的 black-key-aware pivot（`[[concept_long_scale_thumb_under]]` v3）。
3. **F 大調 RH 例外**：1 2 3 4　1 2 3（B♭ 在第 4 音用 f4，拇指落 C）。
4. **B 大調 / 黑鍵調**：起始指與分組隨黑鍵位置變，不是 3+4。

## 頂音邊界規則（迴轉輕收的生物力學推導，2026-07-14）

**統一 meta 規則（先讀這條；2026-07-16 D♭ 書驗證後修訂）**：迴轉點的頂音指 = 在「已就位手框的最小動作（swing）」與「一次立刻撤銷的手位重定位」之間**取最小成本**。2026-07-14 v1 曾把「迴轉點不為單一音重定位手位」當**禁令**（推出 RH 頂音 = swing finger 3/4）；D♭ RH 書驗證（頂音 2，非預測的 4）將其降級為**成本項**：swing 成本隨跨越深度遞增，重定位成本介於 swing-3 與 swing-4 之間。LH 與 RH 的迴轉結構不同（LH 跨越無法避免 → 取最淺 2；RH 依 n-2 指深度在 swing 與重定位之間換檔），表面矛盾實為結構差異。

### LH 分支：a+b 規則（頂音 2）

書版哈農五個黑鍵主音調 LH 上行頂音 = 2（見下方資料品質警訊 2026-07-04 條）原被歸類為「理論推不出的例外」。user 2026-07-14 提出可推導的邊界規則：

> **規則**：(a) 頂音之後必然折返下行；(b) 若折返後第一個音按錨點規則是拇指——則頂音用 **2**。
> **機制**：此時下行第一步就是 thumb-under。拇指從 2 底下穿過只鑽一根手指、CMC 屈曲＋對掌角度最小；從 3/4 底下穿角度加大且常需手腕代償。循環理論推出的頂音 3/4 會把迴轉點的第一個穿越變深（3→1 / 4→1），改用 2 = 最淺的 2→1。

**條件 (b) 在五個黑鍵主音調全部成立**（頂音下方那個音恰好都是拇指錨點）：

| 調 | LH 拇指錨點 | 頂音下方音 | 是拇指 |
|---|---|---|---|
| B♭ | D, A | A | ✓ |
| E♭ | G, D | D | ✓ |
| A♭ | C, G | G | ✓ |
| D♭ | F, C | C | ✓ |
| G♭ | C♭, F | F | ✓ |

**為什麼恰好是這五調需要例外**：主音是黑鍵 → 拇指不能落主音（原則 1）→ 頂音不可能是 1 → 循環理論推出 3/4 → 邊界規則介入改 2。白鍵主音調 LH 頂音本來就是 1（拇指自己是錨點），折返是 1→2 最淺 cross-over，規則不觸發——那些調「沒有例外」不是循環理論更準，是條件 (b) 沒發生。

**雙向性**：條件 (b) 成立時，上行到達頂音的前一音也是同一拇指錨點 → 到達側自動是 1→2 最淺 cross-over。一條規則同時修好迴轉點兩側。

**LH 結構特徵**（為何取最淺跨越）：LH 拇指之上的音無論用哪根指都是 cross-over（跨越無法避免），而折返之後順指流動零跨越 → 唯一變數是跨越深度 → 最淺的 2 贏。

### RH 分支：swing-finger 規則（2026-07-14 user 提出；2026-07-16 D♭ 書驗證後修訂為深度上限版）

書版 G♭ RH 上行迴轉是 **1 3 1**（`E♭(3) F(1) G♭(3) F(1) E♭(3)`），非 a+b 直覺的 1 2 1。結構與 LH 不同：

- **到達頂音不需跨越**：thumb-under 到次頂音（F）後，2 自然落在頂音上方——用 2 反而是「零跨越」選項。
- **但用 2 = 為單一頂音 commit 一次手位重定位**：thumb-under 翻手到新手框（手掌張開），下一拍折返立即撤銷（收回、再跨回 E♭）——白做一個功。
- **用 3（swing finger）= 手框全程不動**：拇指「借」過去彈 F，手仍停在以 E♭-3 為中心的原手框；3 從 E♭ 盪過拇指點 G♭、再盪回 E♭。整個迴轉零重定位——「少了一個力量」。

> **Swing 規則 v2（深度上限版，2026-07-16）**：RH 次頂音是拇指錨點時，頂音指 = min-cost{ (i) **swing**：n-2 指從拇指上方盪過去拿頂音，成本隨 over-cross 深度遞增（1→3 淺；1→4 深且是弱指）；(ii) **重定位**：thumb-under commit 新手框用 2、折返即撤銷（固定成本）}。n-2 = **3** → swing 贏（G♭ = 1 3 1）；n-2 = **4** → 重定位贏（D♭ = 1 2 1）。

**五調完整分類（2026-07-24 五調全對書後定稿）**：RH 迴轉頂音指 = 「從**末拇指落點**順指數到頂音」，唯一例外是末拇指落在導音（n-1、距頂音僅 1 音）時由 swing / 重定位裝置決定。末拇指落點由 pivot 3+4 分組（依各調黑鍵地形）決定：

| 調 | 末拇指落點 | 頂音指 | 機制 |
|---|---|---|---|
| **B♭** | n-3 | **4** | 順指 1-2-3-4 |
| **E♭ / A♭** | n-2 | **3** | 順指 1-2-3 |
| **G♭ / F♯** | n-1（導音 F / C♭ = 拇指錨點）| **3** | swing（1 3 1）|
| **D♭ / C♯** | n-1（導音 C = 拇指錨點）| **2** | 重定位（1 2 1）|

條件 (b)（次頂音=拇指、觸發 swing/重定位裝置）在降記號調只有 **D♭/G♭** 成立（導音 C/F 恰好是 RH 拇指錨點）；B♭/E♭/A♭ 導音非拇指、走順指、無裝置。注意答案不是「黑鍵愛用 3」，也不是「非 D♭/G♭ 一律 4」——是「末拇指落點的順指自然值，加導音落拇指時的成本折衷」。

**書驗證（2026-07-16）**：D♭ RH 書版頂音 = **2**（1 2 1）——v1 swing 規則的預測 **4（1 4 1）證偽**。關鍵觀察：G♭ 與 D♭ 的迴轉**局部幾何完全相同**（拇指在白鍵導音、頂音為上方半音的黑鍵、n-2 距頂音 3 半音），唯一差別 = n-2 指是 3 還是 4 → 深度上限版是最小修訂，且與 LH a+b 規則共用同一條單調性（跨越深度 2 < 3 < 4，方向鏡像為 over-cross）。

**兩力模型——為何 RH 用 swing、LH 用 2（user 2026-07-16 定稿）**：表面衝突（G♭ RH 頂音 3 vs E♭ LH 頂音 2，同樣「頂音往下」）實為**鏡像結構差異**——頂音之後的下行在兩手用不同的跨越機制，各自的主導成本不同：
- **RH 頂音往下 = cross-over**（3-over-1，拇指留在原位不內彎）→ 主導成本是**手指張開的力量**：用 2 = 為單一頂音 commit 一次 thumb-under 張手、下一拍撤銷；用 3（swing）= 手框不動、省掉一次張開，且迴轉前後**同音同指**自動保持（E♭-3 盪出去再盪回來，零重定位的副產品，呼應同音型同指法 HARD spec）。
- **LH 頂音往下 = thumb-under**（拇指從長指底下鑽）→ 主導成本是**拇指內彎曲度**：2→1 最淺，所以 E♭ LH 取 1 2 1 不取 1 3 1。
- **深度上限是 swing 的適用條件**：省張開力的論證單獨套到 D♭ 會預測 1 4 1，但書版 = 1 2 1——swing 的省力只在 swing 指是 3 時成立；4-over-1 跨越過深（且是弱指），省下的張開力被跨越深度吃掉，寧付一次張手用 2。

**DP 對應**（2026-07-16 B♭ LH 修正 session 實作定稿）：
- **LH 分支已顯式落地**（比「自然湧現」多需兩個機制）：(1) **頂音邊界錨移**——黑鍵頂音的 LH-desc segment，3/4 alternation 相位錨在 idx1 而非 idx0（top=2 → 拇指立刻落頂音下方），五個降記號調（含 C#/F# 異名）全部湧現傳統錨點（B♭→A/D、E♭→D/G、A♭→G/C、D♭→C/F、G♭→F/C♭），連黑落 repair 都不再需要；(2) **邊界 base-only refund**——pivot cancellation 在邊界（desc offset 0 / asc 末音）只退 WRONG_DIRECTION 基額、保留深度斜率，使 2→1 對 3→1/4→1 維持深度分級（否則全額 refund 抹平深度差，DP 選 3）。「自然湧現」的前提（深度遞增訊號到達 DP）本身要靠 refund 設計保住——這是 2026-07-14 版低估的部分。
- **LH-asc 退化 1-2 交替根因**：`lh_thumb_pass_natural`（1→2 上行 ≤3 半音 = 0）與 LH {1,2} ostinato 折扣是**伴奏型規則**，在 len≥7 長音階段內補貼退化走法；gate 掉後（短 segment 保留，無 pivot 出口）B♭ LH asc 湧現書版逐音全等 `3 2 1 4 3 2 1 3 2 1 4 3 2 1 2`。真實曲目收割：Bach Inv4-L m20 長上行的 1-2-1-2 修成正規 thumb-over 跨越（cost −8.2、拇指落黑不變）。
- **RH 分支（2026-07-16 D♭ 證偽後反轉）**：D♭ 選 2 正是 pairwise DP 的天然行為（1→4 over-cross 罰重於 1→2 收攏）——深度上限版 v2 比 v1 對 DP **更友善**。真正超出 pairwise Markov 的只剩 G♭ 選 3 一個 case（「commit-then-revoke 手位」是三音窗 E♭-3, F-1, G♭-X 的二階脈絡，兩條路徑的 pairwise 成本幾乎全同，只差 1↔X 一對）。
- **RH DP 落地（2026-07-20，branch feat-rh-turnaround-junction）**：harness 證實 span 區間制**沒有**接住 swing（合成迴轉 G♭ DP=`3 4 5 4 3` 爬到 5，vs 書版 `3 1 3 1 3`）——與 LH 同，RH 也需顯式機制，三條：(1) **`turn_top` end-guard 放寬**——asc segment 的頂音端與反向 segment 共享迴轉點時 `min_after` 2→1，拇指得落導音（desc 段經 pivot 反轉分支傳同旗標）；(2) **position-guard 豁免**——導音 pivot（curr==end−1）通過守衛，鏡像 LH-asc 末音豁免；(3) **兩力成本項** `RH_TURN_REPOSITION_COST=5.5`（swing 指由末 pivot 群組 size 純幾何算 3/4，深度分級靠既有 relay slope 湧現 `eff(swing-3)<eff(重定位-2)<eff(swing-4)`）。**關鍵 pre-commit 修正**：初版 gate 要求 `pf==1`（post-commit）→ size-3 swing 群組（G♭/F♯）末 thumb-landing 到頂音恰 5 音 = 5 指，DP 可零跨越 `3 4 5` 爬頂完全不放拇指，比書版便宜 ~0.61 core，post-commit surcharge 攔不到。修正 = **拿掉 `pf==1`**：swing 指免費、其餘任何頂音進入方式（重定位到 2、爬到 5）一律加 force——正是計價「RH 頂音往下主導成本 = 手指張開的力量」（爬到 5 = 迴轉頂點把手張到最寬再收回），原模型未計。size-4 swing（D♭）零跨越爬指不可行、拓寬前後 byte-identical，B♭（swing=None）永不觸發。**驗收**：五降記號調（含 F♯/C♯ 異名）合成迴轉窗全對齊書版（G♭/F♯ `3 1 3 1 3`、D♭/C♯ `1 2 1`、B♭ top 4、E♭/A♭ top 3 ✓2026-07-24 對書確認）；PIG 149 首 total GMR 持平、RH +0.1pp、L 手 byte-identical；production 只 K283-R（m8 峰 climb-to-5→swing）/K545-R（m5·m7 峰同指 3-3 缺陷消除）變、皆真迴轉。**坍縮設定**（保留為 safety valve）：常數=0.0 → RH 頂音一律 2；**2026-07-24 user 對書二確認 G♭ 頂音 = 3、E♭/A♭ = 3，兩力模型定稿、不觸發坍縮**。詳 score-claude memory *project_rh_turnaround_junction_2026-07-20*。

## 小調

- **和聲 / 旋律小調**：指法通常與其平行/同名大調相近（升高的 7 音 / 6 音不改 thumb-under 結構，除非變成黑鍵影響拇指落點）。

## 琶音（三和弦）

| 調型 | RH 上行 | LH 上行 |
|---|---|---|
| 多數大三和弦（白鍵根音）| 1 2 3　(5 在頂) / 1 2 3 5 | 5 3 2 1 / 5 4 2 1 |
| 含黑鍵者 | 依「拇指落白鍵」調整（如 F 大調琶音 RH 1 2 4）| 鏡像 |

- 原則同音階：**拇指盡量落白鍵**，跨指（3 或 4 過拇指）發生在能讓拇指落白鍵的位置。

## 與 DP 的對應

- `USE_LONG_SCALE_THUMB_UNDER`（`[[concept_long_scale_thumb_under]]`）即在偵測到音階段落時，取消 thumb-pass 的 wrong-direction 懲罰，並以 black-key-aware greedy 3-or-4 pivot 近似上表。
- **偏離標準指法需要理由**：若 DP 在音階段落給出非標準指法，應能追溯到具體生物力學或樂句邊界因素，否則視為 bug（標準指法是 performance floor 之一）。
- ⚠️ 標準指法是**慣例**，仍受**手大小**（`HAND_SIZE` / `[[concept_finger_span_table]]`）與**樂句邊界**調節——不是硬約束。

**harm / mel（和聲小調 / 旋律小調）**：來源站把它們列為相對小調（key=C 的 minor = a 小調），指法字串幾乎全等於同列大調（差別只在第 7/6 音升高後若落黑鍵，拇指仍迴避，分組不變）。實作上**可直接套大調表**，這也是站方 RULES 的結論（「小調幾乎免費附贈」）。

**站方歸納的核心原則**（與本頁 §核心規則一致，互為佐證）：
1. 拇指永遠只踩白鍵 —— 一切指法的根本。
2. 白鍵調 RH 上行 3+4 或 4+3 分組，拇指落主音 / 第四音。
3. LH = RH 鏡像（LH 上行 ≈ RH 下行）。
4. 多黑鍵調起始指改 2 或 3，讓拇指等到白鍵才出現。
