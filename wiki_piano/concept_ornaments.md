# Concept: Ornaments — 裝飾音

> 前置知識：[concept_trill_fingering](concept_trill_fingering.md), [concept_scale_fingering](concept_scale_fingering.md)

裝飾音（Ornaments）是音樂中用來「裝飾」主要旋律音的短小附加音型。從巴洛克到浪漫時期，裝飾音的寫法、演奏慣例與美學目的發生了巨大變化。本頁系統整理各類裝飾音的定義、演奏方式與時期差異。

---

## 1. 裝飾音總覽

以下為鍵盤音樂中最常見的六種裝飾音（Douglas Niedt, 2023; Cooper Piano, 2024; Wikipedia, "Ornament (music)"）：

| 裝飾音 | 英文 | 符號 | 基本構成 |
|---|---|---|---|
| **顫音** | Trill | tr 或 ~~~~ | 主音與上鄰音快速交替 |
| **逆迴音 / 漣音** | Mordent | ∿（短波浪） | 主音→下鄰音→主音（lower mordent）；主音→上鄰音→主音（upper mordent / pralltriller） |
| **迴音** | Turn | ∽ | 上鄰音→主音→下鄰音→主音（四音組） |
| **倚音** | Grace Note | 小音符 | 附加在主音之前的短音 |
| **長倚音** | Appoggiatura | 小音符（無斜線） | 佔據主音時值的一部分，有和聲功能 |
| **短倚音** | Acciaccatura | 小音符（有斜線） | 極短，幾乎不佔時值 |

### 1.1 Trill（顫音）

Trill 是最常見的裝飾音（詳見 [concept_trill_fingering](concept_trill_fingering.md)）。基本形式為兩個相鄰音的快速交替。在終止式（cadence）中幾乎必出現。

### 1.2 Mordent（漣音）

Mordent 由三個音組成（Niedt, 2023）：
- **Lower mordent**（下漣音）：主音 → 下方鄰音（半音或全音）→ 主音
- **Upper mordent / Inverted mordent**（上漣音 / Pralltriller）：主音 → 上方鄰音 → 主音

> 注意：「mordent」一詞的使用在不同時期與不同國家有歧義。巴洛克時期的德國傳統中，mordent 專指下漣音；上漣音則稱 Pralltriller 或 Schneller。

### 1.3 Turn（迴音）

Turn 通常由四個音組成（Cooper Piano, 2024）：
- **正迴音（regular turn）**：上鄰音 → 主音 → 下鄰音 → 主音
- **逆迴音（inverted turn）**：下鄰音 → 主音 → 上鄰音 → 主音

Turn 符號放在音符上方表示在該音位置演奏；放在兩個音符之間表示在過渡處演奏。

### 1.4 Grace Note, Appoggiatura, Acciaccatura

這三者常被混淆。根據 MasterClass（2026）與 Wikipedia 的區分：

- **Grace Note**（倚音）：泛稱所有附加在主音前的短小音符
- **Appoggiatura**（長倚音）：在強拍上演奏，佔主音時值的一半或更多，有和聲重要性。記譜為小音符，**無**斜線穿過符幹
- **Acciaccatura**（短倚音）：在拍前或拍上極短地演奏，強調落在主音上。記譜為小音符，**有**斜線穿過符幹

## 2. 巴洛克 vs 古典 vs 浪漫時期的裝飾音演奏慣例差異

裝飾音的演奏方式隨時期而有顯著變化。C.P.E. Bach 的《論鍵盤樂器的正確演奏法》（*Versuch über die wahre Art das Clavier zu spielen*, 1753/1762）是理解時期差異的關鍵文獻（Bach, 1753; Britannica; Butt, 1991）。

### 2.1 巴洛克時期（~1600–1750）

| 項目 | 慣例 |
|---|---|
| **Trill 起始音** | 從**上鄰音**開始（幾乎無例外） |
| **Appoggiatura** | 在強拍上，佔主音時值的 1/2 至 2/3 |
| **Mordent** | 在拍上演奏，快速且短促 |
| **即興裝飾** | 大量期望，尤其在反覆段與慢板 |
| **記譜方式** | 常使用裝飾音符號表（ornament table） |

> J.S. Bach 為其子 Wilhelm Friedemann 所寫的裝飾音符號表（*Explication*）是巴洛克鍵盤裝飾音的重要參考資料（Margaret Denton Piano, 2023）。

### 2.2 古典時期（~1750–1820）

| 項目 | 慣例 |
|---|---|
| **Trill 起始音** | 逐漸轉為從**主音**開始（但仍有從上鄰音開始的情況） |
| **Appoggiatura** | 依然在強拍上，但時值處理更規範 |
| **裝飾量** | 減少即興裝飾，作曲家更明確寫出 |
| **Turn** | 大量使用，成為旋律線條的一部分 |

C.P.E. Bach 的著作對古典時期影響深遠。Mozart、Haydn 與 Beethoven 都曾研究此書（C.P.E. Bach Website; Britannica）。

### 2.3 浪漫時期（~1820–1900）

| 項目 | 慣例 |
|---|---|
| **Trill 起始音** | 標準從**主音**開始 |
| **Grace note** | 通常在拍**前**演奏（anacrusis 式） |
| **裝飾量** | 作曲家完全寫出，幾乎不留即興空間 |
| **風格** | 裝飾音融入旋律，不再是「添加物」 |

### 2.4 時期對照總表

| 裝飾音 | 巴洛克 | 古典 | 浪漫 |
|---|---|---|---|
| Trill 起始 | 上鄰音 | 過渡期（兩者皆有） | 主音 |
| Appoggiatura 位置 | 拍上，長時值 | 拍上，較規範 | 多在拍前 |
| Mordent 速度 | 快速，在拍上 | 中速 | 依音樂語境 |
| 即興裝飾 | 大量 | 減少 | 幾乎無 |

## 3. 各種裝飾音的指法選擇原則

### 3.1 Trill 指法

（詳見 [concept_trill_fingering](concept_trill_fingering.md)）

| 選擇 | 指法 | 適用場合 |
|---|---|---|
| 最通用 | 2-3 | 白鍵短 trill |
| 進階 | 3-4 | 中速 trill、需要 1-2 指空出時 |
| 高難度 | 4-5 | 特殊音域（受 juncturae tendinum 限制） |
| 長 trill | 2-3 → 3-4 交替 | 避免疲勞 |

### 3.2 Mordent 指法

- **Lower mordent**：使用與 trill 相同的指法原則（2-3 或 3-4）
- **速度要求**：mordent 僅 3 音，需極快速完成，選擇最靈活的手指組合
- **音域考量**：黑鍵 mordent 可能需要 2-3（避免 thumb 在黑鍵上）

### 3.3 Turn 指法

Turn 為 4 音組，指法選擇需考慮前後文：
- **標準 turn**：如 D 上的 turn（E-D-C-D），可用 3-2-1-2 或 4-3-2-3
- **原則**：turn 結束的手指要能順暢銜接下一音

### 3.4 Grace Note / Appoggiatura / Acciaccatura 指法

- **Acciaccatura**：通常用「輕彈」手法，手指快速滑離，常用 2 指或 3 指
- **Appoggiatura**：因為佔有時值，指法需考慮 legato 連接
- **多音 grace note（如 4 音倚音組）**：視為極短的音階片段，使用音階指法原則

## 4. 速度與節奏處理（在拍上 vs 拍前）

裝飾音的節奏處理是演奏實踐中最具爭議的問題之一（Kroll, 2017; Bakirova, 2020）。

### 4.1 在拍上（On the beat）

- **巴洛克慣例**：裝飾音的第一個音落在拍點上
- **效果**：產生不協和→協和的解決感，增強和聲張力
- **適用**：Trill（巴洛克）、Appoggiatura、Mordent

```
記譜：  ♩ (主音 D，前有 grace note E)
巴洛克：E 落在拍點 → D 在拍後
```

### 4.2 在拍前（Before the beat）

- **浪漫時期慣例**：裝飾音在拍前完成，主音落在拍點上
- **效果**：保持旋律節奏的穩定性
- **適用**：Acciaccatura、浪漫時期 grace note

```
記譜：  ♩ (主音 D，前有 grace note E)
浪漫：  E 在前一拍結尾 → D 落在拍點
```

### 4.3 判斷原則

| 因素 | 傾向在拍上 | 傾向在拍前 |
|---|---|---|
| 時期 | 巴洛克、早期古典 | 晚期古典、浪漫 |
| 記譜 | Appoggiatura（無斜線） | Acciaccatura（有斜線） |
| 和聲功能 | 裝飾音與伴奏形成不協和 | 裝飾音純粹裝飾 |
| 作曲家風格 | Bach, Handel, Rameau | Chopin, Liszt, Schumann |

## 5. 裝飾音符號辨識

### 5.1 常見符號一覽

| 符號外觀 | 名稱 | 演奏方式 |
|---|---|---|
| **tr** 或 **tr~~~~** | Trill | 主音與上鄰音快速交替 |
| **∿**（短波浪，無垂直線） | Upper mordent / Pralltriller | 主音→上鄰音→主音 |
| **∿**（短波浪，有垂直線穿過） | Lower mordent | 主音→下鄰音→主音 |
| **∽**（橫 S 形） | Turn | 上鄰音→主音→下鄰音→主音 |
| **∽** 倒置 | Inverted turn | 下鄰音→主音→上鄰音→主音 |
| 小音符（無斜線） | Appoggiatura | 長倚音，在拍上 |
| 小音符（有斜線） | Acciaccatura | 短倚音，極快速 |
| **tr** + 波浪 + 終止小音符 | Trill with termination | Trill 結尾加 turn（如 C-D-C-D-C-B-C） |

### 5.2 注意事項

- 同一符號在不同時期可能代表不同演奏方式
- 法國巴洛克、德國巴洛克、義大利巴洛克各有不同的裝飾音系統
- 版本（edition）不同，編輯者可能加入不同的裝飾音建議

## 6. 常見錯誤與修正

### 錯誤 1：所有 trill 都從主音開始

**修正**：巴洛克時期的 trill 應從上鄰音開始。演奏 Bach 或 Handel 的作品時，需遵循歷史演奏慣例（Butt, 1991; C.P.E. Bach, 1753）。

### 錯誤 2：Appoggiatura 與 Acciaccatura 混淆

**修正**：Appoggiatura（無斜線）有和聲功能，佔主音時值；Acciaccatura（有斜線）極短，強調主音。兩者的節奏處理完全不同。

### 錯誤 3：裝飾音節奏不穩

**修正**：
- 先以慢速練習，把裝飾音的每個音都彈清楚
- 用節拍器確認拍點位置
- 逐漸加速至目標速度

### 錯誤 4：忽略上下文的調性

**修正**：裝飾音的鄰音應遵循調性。例如，G 大調中 F# 上的 trill 應使用 G（而非 G#）作為上鄰音，除非有臨時升降記號指示。

### 錯誤 5：Turn 方向搞反

**修正**：正迴音（∽）從上鄰音開始；逆迴音（倒置 ∽）從下鄰音開始。記憶方法：符號的第一個彎曲方向決定起始方向。

### 錯誤 6：所有裝飾音都用同樣速度

**修正**：裝飾音的速度應配合音樂的整體速度（tempo）、風格與情感。慢板中的 trill 可以較慢且從容；快板中的 mordent 應極快速。

## 7. 測驗

<details>
<summary>10 題測驗（含解答）</summary>

**Q1: Lower mordent 與 upper mordent（Pralltriller）的演奏差異是什麼？**

A: Lower mordent 演奏為「主音→下方鄰音→主音」；Upper mordent / Pralltriller 演奏為「主音→上方鄰音→主音」。兩者都是三音組，差異在於中間的輔助音方向。

**Q2: 巴洛克時期的 trill 應從哪個音開始？浪漫時期呢？**

A: 巴洛克時期從上鄰音開始；浪漫時期從主音開始。古典時期為過渡期，兩種方式皆有使用。

**Q3: Appoggiatura 與 Acciaccatura 在記譜上如何區分？**

A: Appoggiatura 記譜為小音符，符幹上**無斜線**；Acciaccatura 記譜為小音符，符幹上**有斜線**穿過。

**Q4: C.P.E. Bach 的《論鍵盤樂器的正確演奏法》涵蓋了哪些裝飾音？**

A: 涵蓋了 Appoggiatura（倚音）、Trill（顫音）、Turn（迴音）、Mordent（漣音）、Compound appoggiatura（複合倚音）、Slide（滑音）、Snap（彈音）以及 Fermata 的裝飾處理。

**Q5: 「在拍上」與「在拍前」演奏裝飾音，各自產生什麼不同的音樂效果？**

A: 在拍上演奏產生不協和→協和的解決感，增強和聲張力（巴洛克風格）；在拍前演奏保持旋律節奏的穩定性，裝飾音更像「裝飾」而非結構性元素（浪漫風格）。

**Q6: Turn 的標準（正迴音）演奏順序是什麼？**

A: 上鄰音 → 主音 → 下鄰音 → 主音，共四個音。例如 D 上的 turn：E-D-C#-D（假設在 A 大調或 D 大調中）。

**Q7: 為什麼同一個裝飾音符號在不同版本的樂譜中可能有不同的演奏建議？**

A: 因為不同編輯者可能依據不同的歷史文獻或演奏傳統來詮釋符號。此外，法國、德國、義大利巴洛克各有不同的裝飾音系統，對同一符號的定義可能不同。

**Q8: 演奏 G 大調作品中 B 音上的 trill，上鄰音應該是什麼？**

A: 應為 C（自然音），遵循 G 大調的調性。除非有臨時記號另行指示，否則裝飾音的鄰音應符合所在調性的音階。

**Q9: 長 trill 的指法如何避免手指疲勞？**

A: 可使用指法交替（finger change），例如 2-3 → 3-4 交替。這樣不同的手指組合輪流工作，避免單一組合持續快速運動導致疲勞。

**Q10: 巴洛克時期對即興裝飾的期望與浪漫時期有何不同？**

A: 巴洛克時期大量期望演奏者自行添加裝飾音，尤其在反覆段（da capo）與慢板中，即興裝飾被視為演奏者能力的展現。浪漫時期作曲家幾乎完全寫出所有裝飾音，不留即興空間，演奏者應忠實於譜面。

</details>
