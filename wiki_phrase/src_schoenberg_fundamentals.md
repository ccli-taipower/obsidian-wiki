# Source: Arnold Schoenberg《Fundamentals of Musical Composition》

> Faber & Faber / St. Martin's Press, 1967 (posthumous), ed. Gerald Strang & Leonard Stein, English
> ISBN: 0-571-09276-4
> Ingested: 2026-05-28

## 一句話總結

Schoenberg 在 1937–1948 間為美國學生整理的作曲教學筆記，由 Strang 與 Stein 編訂於 1967 年遺著出版；以 Beethoven 鋼琴奏鳴曲為主要範例，由「基本動機 (basic idea / motive)」出發，逐層搭建至 sentence、period、small ternary、rondo、奏鳴曲式。是 20 世紀古典時期形式學的奠基文本，後來 William Caplin (*Classical Form*, 1998) 的 sentence / period taxonomy 即由此書定義而來。

## 重點概念清單（供其他 concept 頁引用）

### 基本動機 Basic Idea / Motive (Grundgestalt)
- 全曲所有發展的「種子」單位，通常 2–4 拍（半小節到 1 小節）
- 包含節奏輪廓 + 音程輪廓 + 和聲含義三項基本要素
- **Grundgestalt**（基本形態）為 Schoenberg 私下使用的更廣義術語：不只動機，還包含其和聲、伴奏與聲部配置的「基本形狀」
- 同一動機可透過 ornamentation / condensation / expansion / inversion / retrograde 等手法變形
- 變形後仍要可辨識為「同一個 idea 的後代」

### Phrase（Schoenberg 用法，有歧義）
- 有時 = sentence 的一半（2 小節 antecedent）
- 有時 = 一個完整的 8 小節 sentence
- 有時 = 一個短的「呼吸單位」（無固定長度）
- Schoenberg 本人並未嚴格區分；Caplin 後來才把 phrase / sentence / period 三層拆乾淨
- 教學上 Schoenberg 強調「以呼吸與終止式判定」，不強調小節數

### Sentence (Satz) — Schoenberg 原型定義
- 典型 8 小節結構：**presentation (mm.1–4)** + **continuation + cadence (mm.5–8)**
- **Presentation**：基本動機 (mm.1–2) + 立刻重複或變奏 (mm.3–4)
- **Continuation**：動機 fragment 化 + sequence + 加速和聲節奏
- **Cadence**：標準終止式（多為 PAC / HC）
- 範例：Beethoven Op.2 No.1 第一樂章 mm.1–8、Op.10 No.1 mm.1–8
- 後來 Caplin 形式化為 statement / response / fragmentation / cadence 四階段

### Period — Schoenberg 原型定義
- antecedent (mm.1–4，弱終止 HC/IAC) + consequent (mm.5–8，強終止 PAC)
- 二者開頭通常**相同**（symmetric construction）
- consequent 通常修改後段以走向更強終止
- Schoenberg 對 period 的處理較 sentence 簡略 — 視為「對稱的兩個 phrase」即可
- Caplin 後來才細化 antecedent/consequent 內部的 basic idea + contrasting idea 結構

### Liquidation（液化、消散）
- Schoenberg 獨創術語：cadence 接近時，動機元素逐步被「中性化」
- 從具特徵的動機 → 通用的 sequence pattern → scale or arpeggio → 單純的 cadential figure
- 目的：避免動機本身與終止式衝突；讓 listener 在情緒上接受「段落結束」
- **典型徵兆**：節奏密度遞減、音程縮窄、和聲節奏加速、織度變薄
- 範例：Beethoven Op.2 No.1 mvt1 mm.5–8 的下行 sequence + 縮窄

### 變奏手法 Variation Techniques
- **Ornamentation**：加裝飾音、passing notes、neighbor notes
- **Condensation**：縮短時值、抽掉部份音
- **Expansion**：延長時值、插入 passing material
- **Inversion / Retrograde**：音程反向 / 時序倒退
- **Sequence**：保持輪廓、移調重複
- 所有變奏手法的共同要求：必須維持基本動機可辨識性

### 形式階層（Schoenberg 提出的層級）
1. Motive / basic idea（2–4 拍）
2. Phrase（不固定，2–4 小節常見）
3. Theme（sentence / period，多為 8 小節）
4. Section（A / B / A' 等）
5. Movement（整個樂章）
- DP「reset」應對應到 phrase 或 theme 邊界，**不是 section** — section 邊界太粗，會跨多個自然呼吸點

## 歷史與作曲家

- 寫作時期：1937–1948，Schoenberg 在 UCLA / USC 任教時的教學筆記
- 出版：1967 年遺著，由 Strang + Stein 編訂
- 範例庫：絕大多數來自 Beethoven 鋼琴奏鳴曲（Op.2、Op.10、Op.14 等），少量 Mozart / Haydn
- 主要影響：
  - Erwin Ratz (*Einführung in die musikalische Formenlehre*, 1951) — 德語對照系統
  - William Caplin (*Classical Form*, 1998) — 英語分析學派的形式化版本
  - Janet Schmalfeldt (*In the Process of Becoming*, 2011) — process-based form 理論的前身
- Schoenberg 自己的作曲實踐（無調性 / 12 音）並未直接出現在本書，但其分析方法在他自己作品分析中亦適用

## 對指法系統的啟示（synthesized — 不是文章原文）

1. **Liquidation 預測 cadence 前的織度變薄**：Schoenberg 描述的「動機消散」過程（節奏密度遞減、音程縮窄、織度變薄）與我們 `concept_texture_change_detection` 的 density-shift detection 完全吻合。Liquidation 偵測可作為 cadence detection 的**早期信號**（提前 1–2 小節），先於 music21 roman 在 measure-final chord 上的 PAC 確認。

2. **Basic idea repetition 結構 = motif consistency 的理論基礎**：Schoenberg 強調 presentation phase (mm.1–4) 是「動機 + 立即重複/變奏」結構；重複的兩次必然是「同一個 idea 的兩次手感」。這直接支持 `feedback_personal_biomechanics.md` 的「同 motif → 同 fingering」HARD 要求。Schoenberg 的「可辨識性」標準恰好對應我們 v5 motif overrides 的 exact-pitch + entry-context schema。

3. **Phrase ≤ sentence ≤ section 的層級觀念決定 DP reset 粒度**：DP 邊界 reset 應落在 phrase 或 sentence 邊界（4–8 小節），不應在 section 邊界（16+ 小節）reset — section 太粗，內含多個自然呼吸點；motive 太細，會破壞「同動機同手感」原則。當前 `_detect_phrase_starts` Pass 2 預設 phrase_period=4 與 Schoenberg sentence 4-bar presentation 段落吻合。

4. **Schoenberg vs Caplin 的歧義**：Schoenberg 的「phrase」一詞在不同段落指涉不同尺度（2 / 4 / 8 小節），需在引用時明確標示是「Schoenberg phrase ≈ Caplin antecedent」還是「Schoenberg phrase ≈ Caplin theme」。我們的 wiki 應以 Caplin 的精確定義為主，Schoenberg 為歷史源頭。

5. **Grundgestalt 比 motive 大**：包含和聲與聲部配置 — 提示我們未來 motif detection 不該只看 melody pitch sequence，也該考慮**伴奏輪廓 + 和聲走向**作為 motif identity 的一部分（目前 v5 schema 是 exact-pitch only，這是限制）。
