# Source: Johann Joseph Fux《Gradus ad Parnassum》(1725)

> 標準英譯：*Steps to Parnassus* / *The Study of Counterpoint*, trans. Alfred Mann (1943/1965), W. W. Norton
> 原文拉丁文，1725 Vienna 出版；歷代鋼琴教育（Haydn, Mozart, Beethoven 皆受訓於此書）的對位聖經
> Ingested: 2026-05-28

## 一句話總結

Fux 以師生對話形式（Aloysius 老師＝Palestrina 化身；Josephus 學生）系統化建立**五種對位法（species counterpoint）**——從 1:1 音對音逐級遞進到自由花式（florid），以 cantus firmus（固定旋律）為腳手架訓練聲部獨立性、不和諧音解決、避免平行五/八度。此書是 Bach Inventions / Fugues / Art of Fugue 背後的教學血脈，也是我們 phrase 分析對「聲部獨立性 = per-hand DP 合理性」的歷史依據。

## 重點概念清單（供其他 concept 頁引用）

### Cantus firmus（固定旋律）
- 預先給定的單聲部旋律（通常全音符），位於下方或上方
- 學生在另一聲部上作對位，cf 本身不動
- 旋律走法以級進為主，避免大跳；長度約 8–12 音
- **對指法系統的延伸意義**：cf 對應現代音樂中的「ostinato 主軸」或「LH 伴奏動機」——固定的低層結構

### 五種對位法（Five species）
- **第一種 (1:1, note-against-note)**：每個 cf 音對一個對位音；只能用 consonance（純一/五/八 + 大小三/六）；首尾必須完全和諧（perfect consonance）
- **第二種 (2:1)**：每個 cf 音對兩個對位音；弱拍允許 passing tone（經過音）造成的不和諧
- **第三種 (4:1)**：每個 cf 音對四個對位音；passing + neighbor tone（鄰音）拓展不和諧位置
- **第四種 (syncopation / 切分)**：對位音延留跨拍，造成 suspension（懸留）；強拍不和諧、弱拍解決
- **第五種 (florid / 花式)**：綜合前四種，加入更多節奏變化，最接近實際作曲風格

### Consonance / Dissonance 規則
- **Perfect consonances**：純一、純五、純八（首尾必用；中間慎用，避免平行）
- **Imperfect consonances**：大小三度、大小六度（中間段落首選）
- **Dissonances**：二度、七度、增四/減五（tritone）——必須準備並解決
- **平行禁制**：parallel fifths / parallel octaves 嚴禁
- **大跳後反向**：跳進後通常以反向級進「補償」

### Voice independence（聲部獨立性）
- **反向動 (contrary motion)** 為首選；斜向動 (oblique) 次之；同向動 (similar) 末
- 避免 **voice crossing**（聲部交叉）與 **voice overlap**（聲部重疊）
- 大跳（> 6 度）盡量避免，特別禁止連續大跳
- 每聲部須有自己的旋律輪廓，不可只是和聲填充

### Suspension types（懸留分類，第四種對位法核心）
- **4-3 suspension**：上聲部 4 度懸留下行解決到 3 度（最常用）
- **7-6 suspension**：上聲部 7 度懸留下行解決到 6 度
- **9-8 (2-1) suspension**：較少用，因解決到 perfect consonance
- **2-3 suspension**（低音）：下聲部 2 度懸留下行解決到 3 度
- 懸留結構三段：**preparation（準備，consonance）→ suspension（懸留，dissonance on strong beat）→ resolution（解決，下行級進到 consonance）**

### Cadence formulas（終止式公式）
- **Clausula vera**（真終止）：兩聲部一拉一推到 octave 或 unison；通常上聲部 7→8、下聲部 2→1（在主調）
- 倒數第二拍常用 7-6 或 4-3 suspension 加強終止感
- 末音永遠是 perfect consonance（unison / fifth / octave）

### Two-voice → Three-voice → Four-voice
- Fux 從兩聲部開始，逐章加聲部數
- 三聲部以上規則放寬（如平行五度在特定條件下允許）
- 但聲部獨立性原則貫穿到底

### Modal framework（調式系統）
- 仍工作於教會調式（Dorian / Phrygian / Lydian / Mixolydian / Aeolian / Ionian）
- 尚未進入 major/minor 二元
- Bach 時代開始向 tonal 過渡，但對位規則本身仍以調式 cantus firmus 為訓練載體

### Dialogue 教學形式
- Aloysius（代表 Palestrina）與 Josephus（學生）的師徒對話
- 每章一個小規則 + 譜例 + 學生練習 + 老師批改
- 影響後世音樂教學「規則 + 反例 + 修正」的書寫範式

## 歷史與作曲家
- **作者**：Johann Joseph Fux (1660–1741)，奧地利作曲家、Habsburg 宮廷樂長
- **出版**：1725 Vienna，拉丁文（後譯為德、義、英、法等多種語言）
- **教學血脈**：Haydn、Mozart、Beethoven、Schubert 皆以 Fux 為對位教本；Bach 雖未直接用 Fux，但其對位訓練源自同一晚文藝復興 / Palestrina 傳統
- **後續發展**：19 世紀 Cherubini、20 世紀 Schenker、Knud Jeppesen（《The Style of Palestrina and the Dissonance》）持續沿用 species 訓練法
- **現代用途**：對位課程標準教材；Bach Inventions / WTC 分析的基石

## 對指法系統的啟示（synthesized — 不是文章原文）

1. **聲部獨立性 = per-hand DP 的歷史正當性**：Fux 強調每聲部須有自己的旋律輪廓、反向動為首選——這在鍵盤上對應「兩手有獨立樂句結構」。我們 `_detect_phrase_starts` per (sheet, hand) 跑、不強制兩手對齊，正是 species counterpoint 聲部觀的延伸（mvt4 LH m50 boundary、RH 沒抓到，這種非同步是 counterpoint 的真實面貌，不是 bug）。
2. **Bach Inventions = 二聲部第五種對位的鍵盤化身**：Bach 把 Fux 第五種（florid）拓展成完整鍵盤作品，加入主題模仿（subject imitation）與 episode 自由對位。我們的 `[[concept_subject_imitation_detection]]` Pass 5 偵測新聲部接過主題，本質是在 Fux 框架內找「對位的入聲時刻」。
3. **Suspension（第四種）解釋 2 聲部指法的延留困境**：當一手保留懸留音（finger 被占住）、另一手必須繼續推進——這是鍵盤指法中「為何某指必須提前準備」的歷史根源。`THUMB_PASS_PHRASE_BUDGET` 與 thumb-reservation rule 在精神上與此呼應：某些手指要為將來的音做保留。
4. **Dissonance resolution = phrase 內部張力曲線**：第四種對位法的 prep→susp→resolve 結構，就是 phrase 內「累積緊張 → 釋放」的最小單位。`[[concept_cadence_detection]]` 偵測 clausula vera + 4-3 / 7-6 suspension 正是 Fux 規則的計算化。
5. **Cantus firmus 傳統 = LH ostinato 偵測的祖先**：Fux 的 cf 固定不動、對位聲部活躍，對應現代音樂的 LH alberti bass / waltz 伴奏 / Chopin 夜曲分解和弦。`[[concept_texture_change_detection]]` 偵測 LH 紋理切換時，本質上是在問「cantus firmus 換了沒」。
6. **第五種 florid → 裝飾音整合的模型**：Fux 第五種允許節奏自由化但仍受聲部規則約束；現代鋼琴 fioritura / ornament 偵測（next priorities 列表）可借鑑——花飾部分仍應「附著於某條主聲部」，不破壞聲部獨立性。
7. **大跳後反向級進 = 樂句內走向的微觀規則**：Fux 要求跳進後反向補償，這對指法的意義是「大跳後不會再大跳」——已隱含在我們 `LARGE_LEAP_THRESHOLD` 與 `RH_LARGE_LEAP_MAX_FINGER_CHANGE` 規則中，但 Fux 提供了歷史依據。
8. **Modal vs tonal 對 cadence 偵測的影響**：Fux 的 clausula vera 在調式系統下定義；Bach 時代開始與 tonal V→I 融合。我們的 `_detect_cadence_boundaries` Phase 2 用 music21 roman numerals 工作於 tonal 框架——對 Bach 早期 modal 殘留段落可能偵測不到 cadence，這是歷史層次帶來的偵測極限。
