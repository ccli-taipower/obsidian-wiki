# Source: William E. Caplin《Classical Form: A Theory of Formal Functions for the Instrumental Music of Haydn, Mozart, and Beethoven》

> Oxford University Press, 1998, English
> ISBN: 978-0-19-510480-9
> Ingested: 2026-05-28

## 一句話總結

Caplin 在《Classical Form》(1998) 為 Viennese Classical Style (Haydn / Mozart / Beethoven) 提出一套**form-functional theory**：每個樂句、主題、段落都承擔可命名的「形式功能」(beginning / middle / end)，且這些功能由**和聲進行**與**cadential function** 而非表面旋律或長度決定。書中對 sentence、period、hybrid theme、cadence taxonomy 的定義是當代古典曲式分析的標準參考。

## 重點概念清單（供其他 concept 頁引用）

### Beginning / Middle / End 三大形式功能 (Formal Functions)

Caplin 的核心抽象：每個音樂單位 (motif / phrase / theme / section) 都可標記為承擔以下功能之一：

- **Beginning function** — 提出 (presentation)：穩定的調性、清晰的 idea、tonic prolongation
- **Middle function** — 推進 (continuation / contrasting middle)：和聲流動加快、motivic fragmentation、調性離開 tonic、sequence
- **End function** — 結束 (cadential)：明確的 cadential progression (T-PD-D-T)，落在 cadence

**重點**：functions 是**抽象標記**，與**時間位置**解耦 — 一個 8-bar 主題在更大層級裡整個都是 "beginning function"。功能是**遞迴**的：phrase 有 b/m/e、theme 有 b/m/e、section 也有。

### Sentence Structure (8-bar 標準)

```
| Presentation (4 bar)             | Continuation (4 bar)              |
| basic idea + basic idea repeat   | fragmentation / sequence + cad.   |
| 2 + 2                            | 2 + 2                             |
| (tonic prolongation)             | (harmonic acceleration → cadence) |
```

- **Basic idea (b.i.)**：2-bar motivic unit，承擔 presentation function
- **Basic idea repetition**：原樣或變奏（exact / sequential / statement-response）
- **Fragmentation**：basic idea 被切成更短的 motivic 子單位（1-bar 或半 bar）
- **Cadential function**：最後 2 bar 是明確的 cadential progression，以 PAC 收尾

**Caplin 強調**：sentence 的「中間」是和聲加速 + motivic 縮短的**雙重訊號**，不只是「長度過半」。

### Period Structure (8-bar 標準)

```
| Antecedent (4 bar)               | Consequent (4 bar)                |
| basic idea + contrasting idea    | basic idea + contrasting idea     |
| → HC (或 IAC)                    | → PAC                             |
```

- **Antecedent**：以**弱 cadence** (HC / IAC) 收，產生「未完成感」
- **Consequent**：開頭與 antecedent 平行（"parallel period"）或對比（"contrasting period"），以 **PAC** 收
- **Contrasting idea (c.i.)**：antecedent 後半的 idea，與 b.i. 對比但不是 fragmentation

**Caplin 嚴格區分** period 與 sentence：period 是**對稱對照**結構（兩個 4-bar phrase 並置），sentence 是**遞進加速**結構（單一 phrase 內部演進）。

### Hybrid Theme Types

Caplin 列出五種混合主題（既非純 sentence 也非純 period）：

| Hybrid | 前半 (4 bar) | 後半 (4 bar) |
|---|---|---|
| Hybrid 1 | antecedent | continuation |
| Hybrid 2 | antecedent | cadential |
| Hybrid 3 | compound b.i. | continuation |
| Hybrid 4 | compound b.i. | consequent |
| (Sentence / Period 純式) | | |

**Compound basic idea** (c.b.i.)：4-bar 的擴大 b.i.，內部含 b.i. + c.i. 但不收 cadence；功能等同 sentence 的 presentation。

### Cadence Taxonomy (Caplin 嚴格化版本)

Caplin 對 cadence 的定義比傳統和聲教科書嚴格：cadence 不只是「V → I」，而是承擔 **cadential function** 的完整進行 (T-PD-D-T)。

| 類型 | 縮寫 | 條件 (Caplin) | 形式功能 |
|---|---|---|---|
| **Perfect Authentic** | PAC | V (root) → I (root)，soprano 落 tonic | 強樂句結束（period / sentence / 段落終點） |
| **Imperfect Authentic** | IAC | V → I，缺 root-position 或 soprano-on-tonic 之一 | 中等結束（antecedent 常用） |
| **Half Cadence** | HC | 結束於 V（**不**是 V→I 的 V）；V 須是穩定的 root-position triad | 樂句中點（antecedent 結尾） |
| **Deceptive** | DC | V → vi/VI 替代 I | **不是真正的 cadence** — Caplin 視為 cadential evasion，預期後面有真正 PAC |

**Caplin 關鍵主張**：
- **HC 嚴格化**：許多教科書把任何「停在 V」都當 HC；Caplin 要求 V 為**穩定 root position triad**（不接 V7、不在 inversion）。這排除了大量 piano accompaniment textures 上的偽 HC。
- **Cadential function ≠ melodic cadence**：旋律的「停頓感」不等於 cadential function；後者由和聲進行決定。
- **Cadential 6/4**：I 在第二轉位接 V7 → I 視為 cadential dominant 的延伸，不另計 cadence。

### Tight-knit vs. Loose Themes

- **Tight-knit**：典型 sentence / period / hybrid，調性穩定、phrase 對稱、material 重複 — 通常是**主題** (main theme, subordinate theme 開頭)
- **Loose**：transition、development、retransition、coda — 調性流動、長度不對稱、material 片段化、modulation 頻繁

**對指法的意義**：tight-knit 段落的 phrase boundary **可預測**（4 / 8 bar，cadence 結尾）；loose 段落需仰賴 cadence detection 與 modulation detection，4-bar fallback 會錯。

### Form-functional Hierarchy

```
Movement (奏鳴曲一個樂章)
  └── Section (exposition / development / recapitulation)
        └── Thematic group (main theme group / subordinate theme group)
              └── Theme (8-bar period / sentence / hybrid)
                    └── Phrase (4-bar antecedent / continuation / etc.)
                          └── Idea (2-bar basic idea / contrasting idea)
                                └── Motif (sub-2-bar unit)
```

**每一層都有自己的 beginning / middle / end function**。指法 DP 的 phrase 概念對應**最底兩層**（idea / phrase），但 cadence detection 需看到 theme 層才能正確判斷。

## 歷史與作曲家

- **方法論源頭**：Schoenberg 1967《Fundamentals of Musical Composition》(posth.) 首提 sentence / period 區分；Ratz 1951《Einführung in die musikalische Formenlehre》系統化；Caplin 1998 為集大成版本
- **覆蓋範圍**：限定 1780-1810 Viennese Classical Style — Haydn、Mozart、Beethoven (early-to-middle)
- **後續影響**：Hepokoski-Darcy 2006《Elements of Sonata Theory》(sonata form 層級)、Vasili Byros (modulation typology)、Janet Schmalfeldt (form-as-process) 皆建立於 Caplin 框架之上
- **教科書地位**：北美音樂理論研究所 sonata-form 必讀；Yale / Eastman / Indiana 等校研究生分析課指定教材

## 對指法系統的啟示（synthesized — 不是文章原文）

1. **Cadence detection 範圍限定 PAC + IAC 來自 Caplin 的 HC 嚴格定義**：Caplin 要求 HC 為穩定 root-position V triad；piano accompaniment 上 K545 m1/m2/m4 末小節常見的**孤立 dominant 音**完全不符合 Caplin HC 條件。`USE_CADENCE_DETECTION` 排除 HC 不是工程性的避錯，而是**形式功能上的正確選擇** — 那些位置原本就不是 cadence。

2. **Measure-final chord analysis 對應 cadential function 的本質**：Caplin 強調 cadential function 是「整個 cadential progression 的功能」，落點在**最終的 I 和弦**。Phase 2 把分析點從 per-tick chordify 改為 measure-final chord 不只是工程簡化，是**對齊 Caplin 對 cadence 的形式定義**：cadence 發生在 progression 的**結束點**，不是中間每個 onset。

3. **Mozart K283 作為主要驗證範例的選擇正確**：K283 1st mov 是 Caplin 書中 Chapter 9「Subordinate Theme Group」的範例；Mozart sonata-allegro 主題群是 tight-knit theme + standard cadence 的純正範本。其他 PIG 曲目（Bach Inventions = counterpoint、Chopin = 浪漫 expanded harmony、Debussy = non-functional）都不適合驗證 cadence detection；K283 是**唯一**能在 PIG 內部單獨驗證 Caplin-style cadence 的曲目。

4. **「phrase = breath = reset」對應 Caplin 的 tight-knit theme boundary**：project memory `feedback_phrase_as_breath.md` 主張樂句邊界是手位 reset 點；Caplin 框架下，**theme boundary**（tight-knit theme 之間）正好對應呼吸點 — `INTER_PHRASE_SCALE=0.0` 對位於 Caplin theme-level boundary，`PHRASE_SEAM_TC_SCALE=0.5` 則對應 antecedent-consequent 的 HC 中點（弱結束、不完全切斷）。這在 Caplin 框架下是**有理論支撐**的設計，不是 ad-hoc weighting。

5. **Form-functional levels 解釋為什麼 `_detect_phrase_starts` 既要 cadence 也要 4-bar fallback**：Caplin 的 hierarchy（idea < phrase < theme）意味著樂句邊界存在於**多個層級**。Cadence detection 抓 theme-level；4-bar fallback 抓 phrase-level；2-bar repeat detection（待實作）抓 idea-level。三者**並非互斥而是互補**。目前 `CADENCE_DISABLES_FALLBACK=False` 的 window mode 設計（cadence 偵測點 ±1 bar 內 disable fallback，遠處保留）正是 multi-level boundary 的工程實現。

6. **Hybrid themes 解釋為什麼純結構 detection 必須允許不對稱**：純 4-bar period 假設只覆蓋 Caplin 五種 hybrid + sentence + period 中的兩種；hybrid 1-4 + sentence 共五種主題型態都**前 4 後 4** 但內部結構不同 — 對 phrase boundary detection 而言，**phrase 中點訊號**（presentation→continuation, antecedent→consequent）必須允許不同種類的 detection 訊號（cadence-based vs. fragmentation-based vs. material-contrast-based）。

7. **Tight-knit / Loose 的區分支持 per-piece flag 策略**：Caplin 主張古典主題段是 tight-knit、transition / development 是 loose；同一首曲子內部兩種段落需要**不同的 phrase detection 策略**。`SINGLE_PDF_PHRASE_FLAGS` per-piece opt-in 機制天然契合此區分 — 後續可擴充為 per-section flags（main theme: cadence ON, development: cadence OFF + texture ON）。
