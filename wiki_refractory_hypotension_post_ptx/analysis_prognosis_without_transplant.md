# 分析：無移植情境下的預後推估與可修正因子

> ⚠️ 本分析為風險框架推估，非精確預測。個體差異極大，最終判斷需心臟科 + 腎臟科整合評估。

完整病人摘要見 [analysis_refractory_idh_treatment_plan](analysis_refractory_idh_treatment_plan.md)。

## 基線：透析患者存活率

| 數據來源 | 年齡層 | 5 年存活率 | 10 年存活率 |
|---------|------|---------|---------|
| USRDS（美國） | 45-54 歲 HD | ~50-55% | ~25-30% |
| 台灣腎臟醫學會 | 類似年齡層 | 略優於美國 | — |

基線預期：一般 48 歲透析病人，中位存活約 5-7 年。但個人化因子會大幅偏離。

## 個人化風險分層

### 不利因子（縮短壽命）

| 因子 | 嚴重度 | 機轉 |
|------|--------|------|
| **SSS=16 嚴重可逆缺血** | 🔴 極高 | 年心臟事件率估 10-15%；未血管重建時 5 年心臟存活率差 |
| **RCA CTO + 多血管 CAD** | 🔴 高 | 缺血範圍跨 LAD/LCX/RCA territory（核醫 2025/08） |
| **頑固性 IDH** | 🟠 中高 | 反覆 myocardial stunning → 加速心肌損傷；腦部已有 mild WMH |
| **血管鈣化**（主動脈 + 冠脈） | 🟠 中高 | 進行性；iPTH 過度抑制 + 鈣 binder 1,200 mg/日持續加重 |
| **Adynamic bone**（iPTH 17.5 + ALP 61） | 🟠 中 | 鈣無法進入骨骼 → 血管沉積 |
| HD 11 年 | 🟡 中 | 累積尿毒素、血管通路消耗 |
| AVG 反覆狹窄 | 🟡 中 | 通路壽命有限；2026/02 PTA 90% |
| **FlowPRA Class I 44%** | 🟡 中 | 中度致敏，移植配對池縮小；MFI 563 偏低是緩衝 |

### 有利因子（延長壽命）

| 因子 | 意義 |
|------|------|
| **年齡 48（相對年輕）** | 比 65+ 透析患者有更大生理儲備 |
| **ADPKD 病因** | ADPKD 透析患者存活率優於糖尿病腎病變（較好營養、較少全身性微血管病變） |
| **ADPKD 保留 EPO 分泌** | 透析 11 年不用 EPO、不輸血、Hb 自維持 12.3 → 囊腫壁細胞仍能分泌 EPO（ADPKD 特殊優勢）；不再輸血 = PRA 不會繼續升高 |
| **Albumin 4.2** | 營養狀態好是透析患者存活的強力保護因子 |
| **EF 73.7%** | 收縮功能保留（雖有 HFpEF 但收縮儲備仍在） |
| **CTR 0.4** | 心臟結構尚未不可逆損傷 |
| **仍正常上班** | 功能狀態好，強力預後指標 |
| **顱內動脈瘤陰性** | ADPKD 最怕的致命併發症已排除 |

## 最大單一威脅：SSS=16

核醫 SSS=16 + ΔTPD=16% 是整個預後的關鍵決定者。

在透析患者中：
- SSS ≥ 13 屬於 severe abnormal
- 嚴重可逆缺血且未血管重建 → 年心臟死亡率估 8-15%
- 5 年內發生重大心臟事件（MI、心因性猝死）風險非常高
- 缺血範圍跨多個 territory 進一步加重風險

**如果不處理 CAD，心臟是最可能的死因，時間框架可能比一般透析存活預期更短。**

## 情境分析

| 情境 | 預估中位存活 | 主要風險 |
|------|-----------|--------|
| **什麼都不改變** | **3-5 年** | 心因性猝死或急性冠脈事件；IDH 持續 stunning → 心功能惡化 |
| **處理可調因子但不處理 CAD** | **5-7 年** | 停沛暢 + iPTH 回升 + ferric citrate 改善 IDH，但冠脈缺血仍是定時炸彈 |
| **積極處理 CAD + 可調因子** | **7-10+ 年** | RCA CTO 開通 + LCX 再評估 → 大幅降低心臟事件風險；移植可能性也大增 |

## 移植免疫障礙：FlowPRA 數據（2026/03/02）

雖然本分析以「無移植」為前提，但移植仍是排序第一的預後改變槓桿。以下數據直接影響移植可行性。

### FlowPRA 結果

| 項目 | 數值 | 解讀 |
|------|------|------|
| **FlowPRA Class I (%)** | **44%** | 中度致敏（20-80% 區間） |
| FlowPRA Class I MFI | 563 | 抗體強度偏低（<1,000） |
| **FlowPRA Class II (%)** | **11%** | 輕度致敏（10-20% 區間） |
| FlowPRA Class II MFI | 355 | 抗體強度低 |

同日其他數據：Potassium K 6.1（115/02/12，與既有 K 6.0 趨勢一致）

### 臨床意義

**Class I PRA 44% = 每 100 個潛在捐贈者中，約 44 個因 HLA Class I 抗體不合而配對失敗**。等待時間顯著延長。

致敏原因：透析 11 年間歷次輸血累積（手術、急性事件）。ADPKD 本身不增加致敏風險。

**重要更新**：病人目前不用 EPO 也不輸血（ADPKD 囊腫壁細胞仍能分泌 EPO，Hb 12.3 自維持）。HLA 抗體由記憶 B 細胞維持，不會自行消失，但**不再輸血 = PRA 不會繼續升高**。

### 相對有利點

MFI 563 / 355 均偏低 → 抗體存在但**強度不高**：
- 虛擬交叉試驗（virtual crossmatch）結果可能比 PRA 百分比樂觀
- 若做 single antigen bead（SAB）細分，部分抗體 MFI 可能低到可接受範圍
- 不是所有 44% 的不合都會造成超急性排斥

### 移植的三道關卡

| 關卡 | 狀態 | 對策 |
|------|------|------|
| **① 心臟（SSS=16）** | 嚴重可逆缺血，移植前需先處理 | RCA CTO 開通 + LCX 再評估；2026/07/29 重複核醫定奪 |
| **② 免疫（PRA Class I 44%）** | 中度致敏，配對池縮小 | SAB 細分 + acceptable mismatch + 活體評估 |
| **③ 解剖（ADPKD 巨腎 + 髂股動脈 anatomy）** | TKV 3,407 → 1,030-1,048 mL（−69-70%）已落在「邊緣值」；**6/4 CT 拆分 R 427.7 + L 602.3（右側比左側小 41%）+ 半年 stable**；左 CFA moderate < 50% 無症狀 | 🟢 **green light 升級**：血管面 ✅ + 巨腎右側 ✅（**移植側偏小、不需切原生腎論證更強**）|

三個關卡都需要**主動積極處理**，不能被動等待。**好消息**：解剖關卡兩個面向都接近 green light——血管（5/19 下肢動脈超音波無 hemodynamically significant 狹窄）+ TKV（雙腎 TAE 後從幾乎不可能直接移植，變成可能不需切原生腎）。

### 免疫對策建議

1. **確認是否已做 SAB（單抗原珠檢測）** → 精確辨識是哪幾個 HLA 抗原有抗體，排除「可接受的不匹配」
2. **加入 acceptable mismatch program**（台大/長庚等移植中心）→ 擴大有效配對池
3. **評估 desensitization（脫敏治療）可行性** → 若出現合適捐贈者但交叉試驗弱陽性，可用 IVIG / rituximab / plasmapheresis
4. **活體捐贈評估** → 如有家人願意，可針對特定 donor 交叉試驗；44% 對單一已知捐贈者不一定是障礙
5. **減少未來致敏** → 盡量避免不必要輸血（EPO + IV iron 維持 Hb；ferric citrate switch 有助於此）

### 解剖障礙：ADPKD 巨腎與下肢動脈評估

腹部 MRI（2025/12）顯示雙側腎臟明顯增大，**加上移植團隊 order 的 2026/05/19 下肢動脈超音波**，共同構成解剖關卡評估：

#### 下肢動脈超音波（2026/05/19，移植團隊 pre-op order）

| 項目 | 結果 |
|------|------|
| 主要發現 | **左 CFA moderate stenosis** |
| 整體判讀 | **無 > 50% 顯著狹窄** |
| 臨床症狀 | 無下肢 claudication / 冰冷 / 傷口問題 |
| 結尾建議 | "Please correlation with clinical status" |
| 解讀 | 影像有 finding 但臨床無 hemodynamically significant 狹窄 |

**對移植技術可行性的意涵：**
- 移植腎一般接到**右側 external iliac**（多數情境）→ 左 CFA stenosis 不影響首選位置
- 即使選擇左側 anastomosis，moderate（< 50%）也通常可接受
- **血管面 → 大致 green light**
- 但仍需移植外科 confirm（術前 angiography 可能還是必要）

#### 🩻 為什麼移植腎放在右髂窩 + 你個案的 6-factor fit

「移植腎放右髂窩」是國際慣例，但需要解釋為什麼——以及為什麼**你的個案剛好全套 favorable**。

**5 個一般解剖 / 手術原因**

| # | 原因 | 解釋 |
|---|------|------|
| 1 | **髂血管解剖** | 右髂靜脈走右髂動脈**外側、淺**（容易暴露）；左髂靜脈被右髂動脈蓋住、走在**內側、深**處（暴露需要更多解剖、出血風險高）|
| 2 | **大腸位置** | 右側盲腸 + 升結腸**鬆、可動性高**（撥開容易）；左側降結腸 + 乙狀結腸**黏住後腹膜**（撥開困難）|
| 3 | **輸尿管接合** | 右輸尿管到膀胱右上角距離短、角度自然；左側繞較多、張力較大 |
| 4 | **外科姿勢** | 多數外科醫師右撇子，站病人右邊操作右髂窩最順手 |
| 5 | **保留左側給二次移植** | 第一次移植腎 10-15 年後失敗時，第二次標準放左側——先用右側、留左側做後備 |

**ADPKD 特殊考量（額外第 6 個因子）**

| # | 原因 | 解釋 |
|---|------|------|
| 6 | **同側原生腎大小決定空間** | 一般人原生腎不影響移植空間（不在 surgical territory）；但 **ADPKD 巨腎可能下延伸到髂窩** → **同側原生腎越小越好** |

**你個案的 6 因子 fit（全打勾）**

| 因子 | 標準需要的條件 | 你的狀況 | Fit |
|------|--------------|---------|-----|
| 1. 右髂血管 | 無 stenosis | 5/19 下肢超音波：**右側無 stenosis、左 CFA moderate < 50%**（左側才有問題）| ✅ |
| 2. 右側結腸可動 | 無腹部手術史 | 無闌尾炎 / 疝氣 / 沾黏史 | ✅ |
| 3. 右輸尿管 / 膀胱 | 標準解剖 | 標準（atrophic bladder 但結構完整）| ✅ |
| 4. 外科姿勢 | — | 標準 | ✅ |
| 5. 保留左側給未來 | — | 適用（49 歲、可能有二次移植機會）| ✅ |
| 6. **右側原生腎較小** | 越小越好 | **右腎 427.7 mL < 左腎 602.3 mL（小 41%）**——剛好右側比較小！| ⭐⭐⭐ |

→ **6 個 factors 全 favor 右側**。你個案是右髂窩移植的**教科書 perfect candidate**——尤其第 6 條（右側原生腎較小）是個 ADPKD 病人未必都有的 favorable 解剖。

**這對「不需切原生腎」論證的強化**

之前 wiki 的論證鏈：「TKV 1,030 邊緣值 → 不一定要切」。**現在升級為**：

```
TKV 1,030 mL 是邊緣值
  ↓ (CT 6/4 拆分)
右側原生腎 427.7 mL（移植側）
  ↓
右髂窩有足夠空間
  ↓
不需切原生腎就能直接移植
```

而左腎 602.3 mL **不在 surgical territory**——無關緊要。整個論證**比之前單看合計 TKV 強很多**。

**何時可能反過來移植到左側（你都不適用）**

| 反向情境 | 你的狀況 |
|---------|---------|
| 右髂血管嚴重病變 / 鈣化 / 狹窄 | ❌ 你右側 OK |
| 右髂窩手術史（疝氣 / 闌尾沾黏）| ❌ 你沒有 |
| 右側原生腎極大、左側相對小 | ❌ **你反過來**（右小於左）|
| 二次移植（第一次失敗）| 不適用你目前 |

→ 你目前沒有任何「需要反向」的指標。

#### ADPKD 巨腎 — TAE 後其實已大幅改善

ADPKD 腎臟巨大原本是移植的解剖障礙，但**雙腎 TAE 策略（2019/10 + 2019/12）已成功減容 ~70%**：

| 時點 | TKV（雙腎合計）| R / L 拆分 | vs 正常 | 評估 |
|------|--------------|----------|---------|------|
| 正常成人雙腎 | ~300 mL | ~150 / ~150 | 1× | — |
| **2019/10 TAE 前 (MRI)** | **3,407 mL** | 未拆分（推估 1,700/邊）| **11× normal** | 嚴重，幾乎一定要原生腎切除才能移植 |
| 2025/12 (MRI) | 1,048 mL | 未拆分 | 3.5× normal | 邊緣值 |
| **🔥 2026/06/04 (CT)** | **1,030 mL** | **R 427.7 + L 602.3** | **R 2.9× + L 4.0×** | **邊緣值** + **右側比左側小 41%** + **半年 TKV 穩定**（vs 12/2025 MRI 1,048）→ **不需切原生腎的論證更強** |
| 變化 | **−69.8%** | — | 11× → ~3.4× | TAE 效果極為成功 + 右側偏小利於移植 |

**為什麼曾經是障礙：**
- 移植腎放在髂窩（骨盆腔），巨大原生腎佔據腹腔空間 → 移植腎放不進去或被壓迫
- 腫大腎臟壓迫髂動靜脈 → 血管接合困難、外科視野差
- 術後巨大腎臟持續生長 → 壓迫移植腎 → 影響移植腎功能

**為什麼現在較不是障礙（TAE 後）：**
- 1,030-1,048 mL 落在「邊緣值」區間（1,000-1,500 mL），多數情境可直接移植不切原生腎
- 🔥 **2026/06/04 CT 拆分顯示右腎 427.7 mL、左腎 602.3 mL（右側比左側小 41%）**
- 半年內 TKV stable（MRI 1,048 → CT 1,030，−1.7%）→ 兩個 modality 互證、移植窗口時間相對寬裕
- **移植腎標準放入右髂窩 → 右側原生腎大小最關鍵 → 你右側偏小**反而是 favorable 結構
- 5/19 下肢動脈超音波也支持右側 anastomosis（左 CFA moderate < 50%、右側無問題）
- 整體：**血管面 + 巨腎右側面雙重 green light**，左側雖較大但不在 surgical territory
- 但仍需移植外科 confirm（個別腹腔解剖差異）

詳細時間軸見 [analysis_hospitalization_timeline §1 TKV 軌跡](analysis_hospitalization_timeline.md#住院-1右腎-tae--pd-改-hd20191015-24ntuh)。

**原生腎切除（Native Nephrectomy）時機選擇：**

| 時機 | 優點 | 缺點 |
|------|------|------|
| **移植前切除** | 騰出空間，移植手術簡化 | 無腎期（完全依賴透析）、等待期感染風險增加 |
| **移植同時切除** | 一次手術解決 | 手術時間長、出血風險高 |
| **移植後切除** | 先確保移植成功 | 若空間不夠則無法執行移植 |

台灣多數移植中心傾向移植前或同時切除，取決於腎臟體積（通常以 TKV 總腎臟體積評估）。

**對策：**
1. 確認腹部 MRI 2025/12 是否有報告 TKV（total kidney volume）
2. 與移植外科 / 泌尿外科討論原生腎切除的時機與方式
3. 若決定移植前切除，需考量：切除後完全無殘餘腎功能、術後恢復期、與心臟手術的排程協調

## 核心訊息

不是「還能活多久」的問題，而是「有哪些可以做的事能改變軌跡」。

這位病人的**可調空間不小**：
- 最大威脅（SSS=16）是**可逆缺血**（心肌仍存活）→ 血管重建有機會大幅改善
- 多個低成本介入**已執行**：2026/05/19 停沛暢、2026/05 停 vit D（iPTH 17.5 → 28.6 證實有效）；**BB trial 失敗 6/4 停藥**（多因素疊加，需待 Ca/Hb/iPTH 穩定後再評估）；剩 ferric citrate 換 binder + 補鐵
- 功能狀態好（正常上班）+ 營養好（Alb 4.2）→ 承受積極治療的本錢仍在
- 心臟結構尚未不可逆（CTR 0.4、EF 73.7%）→ 時間窗口還沒關閉

**但時間窗口有限**——SSS=16 每多一年未處理，心肌從可逆缺血進展到不可逆壞死的風險就在累積。

## 病人自我管理建議（仍正常上班的前提下）

病人目前功能狀態良好（正常上班），這本身是強力預後保護因子。但 SSS=16 + 頑固性 IDH 意味著日常生活需要主動管理風險。

### 1. 工作安全

- 確認工作性質是否涉及駕車、高處作業、操作機具 → IDH 造成的「眼前發黑」有暈厥風險
- **透析隔天（二、四、六早上）是最脆弱時段** → 避免安排需要高度專注或體力的工作
- 隨身攜帶**緊急聯絡卡**（透析患者身份、用藥、AVG 側肢體不量血壓不抽血）

### 2. 心臟猝死預警

SSS=16 嚴重可逆缺血 = 隨時可能發生急性冠脈事件。必須辨識：
- 胸悶、冷汗、下巴/左臂痛、突然喘不過氣 → **立刻叫 119，不要忍**
- 透析中血壓掉到比平常更低且合併胸悶 → 主動告知護理師（不是「老問題」）
- 與心臟科討論是否備用舌下 NTG（但 IDH 體質需極度謹慎使用）

### 3. 飲食管理 — K 6.0 是最緊急的自我管理項目

K 6.0 + active ischemia = 心律不整風險明顯升高：

| 建議 | 說明 |
|------|------|
| **楊桃絕對禁止** | ADPKD + 透析 = 神經毒性 |
| 高鉀水果減量 | 香蕉、奇異果、番茄、柳橙 |
| 蔬菜先燙再炒 | 溶出 30-50% 鉀 |
| 湯品少喝 | 鉀溶在湯裡 |
| **不要用低鈉鹽** | 低鈉鹽 = 高鉀鹽 |
| IDWG 控制 | 目前 5%，目標 <4%，控制兩次透析間飲水量 |

### 4. 運動建議

[Petraki 2008](src_petraki2008_exercise_training_brs.md) 顯示透析中運動改善壓力反射敏感度（BRS +23%），直接對抗 IDH 的自主神經失調面向。

| 類型 | 建議 |
|------|------|
| **透析中腳踏車** | intradialytic cycling，跟洗腎室確認設備 |
| 非透析日有氧 | 中等強度快走 30 分鐘，**避免透析隔天早上** |
| 避免 | 重量訓練到 Valsalva（血壓劇烈波動 + ischemia 風險） |
| 注意 | 運動前不要空腹（低血糖 + IDH 體質 = 暈厥風險） |

### 5. 🦶 足部每日自我檢查（透析病人標準照護）

11 年 HD + 廣泛血管鈣化 + 頻繁 IDH 三個因子疊加，足部 PAD 風險基底高（雖然目前無症狀）。**每天花 1-2 分鐘自查**——比任何儀器都早發現問題。

**Daily checklist**：

| 項目 | 怎麼看 / 摸 | 警訊 |
|------|----------|------|
| **皮膚** | 整個腳掃視（含足底、趾縫）| 任何破口、水泡、紅腫、雞眼、變色 |
| **腳溫** | 跟手背比 | 比手明顯更冷 → ⚠️ |
| **腳趾顏色** | 看趾尖 | 蒼白 / 紫黑 / 暗紅 → ⚠️ |
| **足背動脈跳動** | 摸 **腳背中央偏內**（dorsalis pedis） | 摸不到 / 跳動弱 → ⚠️ |
| **後脛動脈跳動** | 摸 **內踝後方凹陷處**（posterior tibial）| 同上 |
| **趾甲** | 看顏色、形狀 | 變黃變厚（真菌）、嵌入肉裡 |
| **趾縫** | 撥開看 | 脫皮、白色濕潤（香港腳）|

**穿鞋習慣**：
- 室內穿軟底拖鞋（不要赤腳——刺到不知道）
- 不穿過緊或過硬的鞋
- 任何長水泡的鞋立刻換掉
- 修剪趾甲時不要太短、不要剪到嵌甲

**任何下列症狀立刻看血管外科 / 透析科**：

| 症狀 | 為什麼緊急 |
|------|---------|
| 走幾百公尺後小腿酸痛（claudication）| PAD progressive、可能急性事件前兆 |
| 任何破口 3 天沒明顯癒合 | 周邊血流不夠 + 感染 |
| 趾尖突然變色（特別紫黑）| 急性缺血、可能截肢風險 |
| 趾尖夜間痛醒 | rest pain = severe PAD |
| 任何發燒 + 足部紅腫 | 蜂窩性組織炎，HD 病人會 escalate 很快 |

→ **不要拖、不要 self-treat**——HD 病人足部小問題 escalate 成截肢只要幾週。

### 6. 最重要的單一行動：推動心臟科再評估

- 「還能上班」≠ 心臟沒事 — SSS=16 是影像硬證據，心肌正在缺血
- 目前是**可逆缺血**（心肌還活著）→ 血管重建有意義
- 每多拖一年，可逆→不可逆壞死的風險在累積
- **這也是移植的門票** — 腎移植評估時 SSS=16 會被要求先處理
