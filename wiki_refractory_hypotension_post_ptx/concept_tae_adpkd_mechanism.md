# TAE 如何讓 ADPKD 巨腎縮小——4 個機轉 + 對移植的 enabler 意義

**TAE (Trans-Arterial Embolization，經動脈栓塞術)** 是 ADPKD 巨腎的 volume-reduction 介入手段——**經股動脈插導管進腎動脈、打線圈 + 顆粒堵住主要血管**、讓囊腫因缺血萎縮。日本 Ubukata / Sakuhara 團隊開創、pre-transplant 或 symptomatic bulk 個案的重要選項。**對本個案而言，2019 年的雙腎 TAE 是 2026 年成為 transplant candidate 的 critical enabler**——沒 TAE、3,407 mL 巨腎會擋住右髂窩移植空間、可能需 pre-transplant nephrectomy 大手術。

## TAE 縮小 TKV 的 4 個機轉

### ① 缺血性萎縮（ischemic atrophy）

- 主腎動脈被 coils 堵住 → 血流「near stasis」
- 囊腫上皮 (cyst epithelium) 缺氧 → 細胞死亡
- 囊腫組織被 body 逐步 reabsorb → 纖維化萎縮

### ② 停止液體分泌

- **囊腫上皮 = 液體工廠**：主動分泌液體讓 cyst 變大
- 工廠死了 → 沒新液體進 cyst
- 已有液體透過殘餘微血管 / 淋巴慢慢被吸收
- Cyst 從液性 → 半固態 → 纖維化

### ③ 阻止細胞增殖

- ADPKD 囊腫變大 = 上皮細胞不斷分裂增殖
- 沒血 = 沒 nutrient supply = 細胞不分裂 = 囊腫不 expand
- 這是 TAE 相對於 cyst decompression（引流）的**根本優勢**——引流只是釋放液體、細胞還會繼續分泌；TAE 是把工廠關掉

### ④ 纖維化塌陷

- 囊腫壁失去內壓支撐
- 塌陷 → 纖維化結節
- 最終 kidney 從「充滿囊腫的巨球」→「萎縮的纖維團」

## 時間軸

| 時點 | 變化 |
|------|------|
| 立刻 | 幾乎無變化（血栓正在形成中）|
| 3-6 個月 | 明顯縮小開始 |
| **1-2 年** | **大部分縮小完成**（typical −50-70%）|
| 2 年後 | 慢速持續萎縮、多數進入 stable plateau |

## 個案數據（教科書級成功案例）

| 時點 | TKV | 累積變化 |
|------|-----|---------|
| 2019/10/15（TAE 前 MRI）| **3,407 mL**（Grade IV，75-100%）| baseline |
| 2019/10/17 | **右腎 TAE**（NTUH，多 coils、near stasis）| — |
| 2019/12/05 | **左腎 TAE**（NTUH，near stasis）| — |
| 2025/12（MRI）| 1,048 mL | **−69.2%** |
| 2026/06/04（CT）| **1,030 mL = R 427.7 + L 602.3** | **−69.8%** |
| 半年變化（12/25 → 6/26）| −18 mL | **−1.7%（已 plateau、CT 明確寫 "stable"）** |

→ **超乎典型 −50-70% 上限**，達 −69.8% + 已到 stable plateau

## 囊腫還會繼續長嗎？分 4 塊看

### ① 已 TAE 的原生腎（絕大部分）

✅ **不會繼續長**
- 血流被切、細胞不分裂、囊腫不擴大
- **半年 stable 實證確認**（12/2025 1,048 → 6/2026 1,030 = 1.7% 變化 in modality noise range）
- 這是 permanent freeze，不是暫時的

### ② 未被完全 embolize 的殘餘活組織

⚠️ 理論上可以、但實際極少
- TAE 不可能 100% 完全（總有 collateral circulation）
- 但主要血管切、殘餘 flow 微弱
- 7 年下來 stable = collateral 幾乎沒推動新囊腫

### ③ 肝臟囊腫（ADPKD 也會表現在肝）

⚠️ **會繼續慢慢長**（沒 TAE 過）
- 2026/06/04 CT: **多囊肝 Grade II**
- ADPKD gene 在肝細胞一樣 active
- 通常成長很慢、大多無臨床意義
- 只有大到壓迫症狀時才處理（引流 / TAE / 部分肝切）

### ④ 移植後的新腎臟

✅ **不會長囊腫**
- 別人的腎、沒 ADPKD gene defect
- 唯一例外：活體 donor 是有相同 mutation 的家人（罕見、且評估會排除）

## 對本個案移植的 3 個 direct implications

### 1. 不需 pre-transplant nephrectomy

- 3,407 mL 巨腎會擋右髂窩移植空間、typical 需先切腎（大手術、術後 recovery 拖延移植）
- **TAE 後 1,030 mL = 已到 plateau、右側 427.7 mL 特小 → 直接放右髂窩移植不擠**
- 詳見 [analysis_prognosis_without_transplant §為什麼移植腎放右髂窩](analysis_prognosis_without_transplant.md)

### 2. 右髂窩選擇的加強論證

- 右腎小 41%（vs 左 602.3 mL）讓右側移植空間充裕
- 詳見 [analysis_prognosis_without_transplant §足部血管 nuance](analysis_prognosis_without_transplant.md)

### 3. 移植腎不會被 ADPKD 侵犯

- ADPKD 是 gene defect 疾病、不是感染性
- 別人的腎 = 別人的基因 = 沒 defect
- 移植腎的長期 outcome 跟 ADPKD 完全 decouple

## Meta 觀察

**2019 年做 TAE 是 6 年後 leverage 為 transplant candidate 的 critical foundation**。當時可能主 indication 是**囊腫出血 + PD 效率下降 + polycystic kidney 持續長大**（見 [analysis_hospitalization_timeline 住院 #1](analysis_hospitalization_timeline.md)）、而非明確為移植準備。但**回頭看、TAE 是把「移植路徑幾乎不可能」翻轉為「三大關卡最好的一個」的 keystone intervention**。

→ ADPKD 病人若已 ESRD + 有移植意願、TAE 值得**及早討論**（不要等到需要移植前才想）——TAE 需要 1-2 年才完全 shrink，太晚做會撞到移植 timing。
