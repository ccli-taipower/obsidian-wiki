# Source: Türk《Klavierschule》(1789)

> Daniel Gottlob Türk (1750-1813), *Klavierschule, oder Anweisung zum Klavierspielen für Lehrer und Lernende* (1789, Leipzig/Halle)；英譯 *School of Clavier Playing* (Raymond H. Haggh 譯, 1982, Nebraska University Press)
> 引用方：[[concept_articulation_overview]] §3 (Baroque/Classical 過渡時代 default), [[concept_non_legato_baroque]] §2, [[concept_legato_substitution]] §2

## 1. 作者背景

Daniel Gottlob Türk 是 18 世紀末德國（薩克森邦）鍵盤教育核心人物，任教 Halle 大學。其 *Klavierschule* (1789) 是**18 世紀末最系統化的鍵盤演奏教材**，記錄了 Baroque 末期→Classical 早期的演奏實踐。

書中對象主要是 clavichord 與 fortepiano（早期錘擊鋼琴），harpsichord 已逐漸退場。但 articulation 慣例承襲 Baroque 傳統（C.P.E. Bach 影響顯著）。

## 2. Türk 的歷史定位

時代背景：
- 1750: J.S. Bach 過世，Baroque 結束
- 1789: Mozart 在世（K545 出版於 1788），Beethoven 19 歲，Classical 中期
- Türk *Klavierschule* 正好記錄此過渡期的演奏實踐

→ Türk 的文獻價值：**Baroque non-legato 默認 → Classical 平衡** 的橋樑文獻。

## 3. 對 articulation 的核心主張

### 3.1 「ordentliches Fortgehen」(規矩的繼續) — Baroque default 的精確化 ⚠

⚠ Training-data verification needed: Türk 在「觸鍵」章節定義「ordentliches Fortgehen」：

> 「規矩的繼續是音的持續略短於書寫值（約 3/4 或 4/5），不是真正的 legato，也不是 staccato。這是無標記時的演奏方式。」

→ 為「Baroque non-legato default ~85%」這個操作型百分比提供 18 世紀的明確文獻依據。詳見 [[concept_non_legato_baroque]] §2 引述。

### 3.2 Articulation 標記的階段分類 ⚠

⚠ Training-data verification needed: Türk 給出 articulation 從最連到最斷的分類：
- **Schleifen / Legato**: 完全連奏，前指持續到後指彈下
- **Tragend / Portato**: 「攜帶」式，半連
- **Ordentlich**: 無標記時的默認（~85%）
- **Spitzig / Staccato**: 「尖銳」短斷

這個分類比 Czerny Op.500 更早 50 年，是 18 世紀末→19 世紀中葉教學連貫性的證明。

### 3.3 對 finger substitution 的態度

⚠ Training-data verification needed: Türk 提到 substitution（Fingerwechsel）是「**成熟演奏者必備**」的技術：

> 「在持續的 legato 段，當同一手指無法接續演奏時，必須透過 Fingerwechsel（換指）保持連續性。」

→ 這是 [[concept_legato_substitution]] 提到的「18 世紀末以來 substitution 是標準教學」的具體文獻支持。

### 3.4 Fortepiano vs Clavichord 的觸鍵差異

Türk 同時討論兩種樂器：
- **Clavichord**: 觸鍵 sensitive，可做 vibrato、bebung；legato 較容易（音長衰減慢）
- **Fortepiano** (錘擊): 觸鍵需主動加重；legato 較難（必須靠 substitution + 正確指法）

→ 對指法的意涵：18 世紀末 fortepiano 的崛起**強化了 substitution 的必要性**，因為錘擊樂器物理上比 clavichord 更需要主動 legato 技術。

## 4. 對 C.P.E. Bach 的承繼

Türk 在書中多次引述 C.P.E. Bach *Versuch über die wahre Art das Clavier zu spielen* (1753)，承繼其：
- Non-legato default 主張
- 「短於書寫值」具體百分比的精確化
- Articulation 與表情關係的論述

Türk 與 C.P.E. Bach 一起構成 [[concept_non_legato_baroque]] 的雙重文獻基礎。

## 5. 對指法系統的具體影響

| Türk 主張 | 對 score-claude DP 的對應 |
|---|---|
| Ordentliches Fortgehen ~85% | [[concept_non_legato_baroque]] 默認 default operational value |
| Substitution 是成熟演奏者必備 | [[concept_legato_substitution]] §2 文獻依據之一 |
| Fortepiano 強化 substitution 必要 | 為何現代鋼琴演奏 Baroque 仍需考慮 legato substitution（雖然部分段落 non-legato）|

## 7. 與其他來源對比

| 來源 | 年份 | 對 Baroque non-legato 的立場 |
|---|---|---|
| **C.P.E. Bach Versuch** | 1753 | 提出「~50%」短於書寫值（更短） |
| **Türk Klavierschule** | 1789 | 精確化為「~75-85%」（中間值） |
| **Czerny Op.500** | 1839 | 同上，加入更系統化分類 |
| **Donington Baroque** | 1982 | 學術回顧 + 現代演奏建議 |

Türk 處於關鍵過渡期，提供「**默認的精確操作型百分比**」是 [[concept_non_legato_baroque]] §2 操作型定義的核心來源。
