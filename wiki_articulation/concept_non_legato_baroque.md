# Concept: Non-Legato Baroque — 巴洛克的默認 articulation

> 來源：Türk *Klavierschule* (1789) §「ordentliches Fortgehen」、C.P.E. Bach *Versuch* §觸鍵章、Donington *Baroque Music: Style and Performance*、Couperin *L'Art de toucher le Clavecin* (1716)
> 引用方：[concept_articulation_overview](concept_articulation_overview.md) §3、[concept_period_defaults](concept_period_defaults.md)

## 1. Baroque 為什麼預設不是 legato

當代鋼琴家容易把樂譜的「沒有 staccato 或其他標記」理解為「應該 legato 連奏」。這是**浪漫派之後的習慣**，套在 Baroque 文獻上是 anachronism。

歷史事實：
- Baroque 時代主要鍵盤樂器是 **harpsichord（大鍵琴）+ clavichord**，不是現代鋼琴
- Harpsichord 撥弦發聲、音長極度衰減，物理上**不可能達成真正 legato**（演奏者的指尖控制改變不了發聲後的衰減曲線）
- 因此 Baroque 教學 default = 「**ordentliches Fortgehen**」(Türk) 意即「規矩的繼續」= 每音清晰、留微小空隙、約 85% 音長

當這些作品演奏在現代鋼琴上時，**保留 non-legato default 是 stylistically faithful 的演奏**，不是「沒做到 legato」。

## 2. 歷史文獻共識

### C.P.E. Bach《Versuch über die wahre Art das Clavier zu spielen》(1753)
> 「音符的持續時間應大約是其書寫值的一半，除非在抒情段（chantant）或標有 legato 的段落。」

C.P.E. Bach（J.S. Bach 之子）明確說「默認非連奏」是正確演奏。

### Türk《Klavierschule》(1789) §「ordentliches Fortgehen」
> 「規矩的繼續是音的持續略短於書寫值（約 3/4 或 4/5），不是真正的 legato。」

Türk 給出更精確的時長百分比 — 約 75-85%。

### Couperin《L'Art de toucher le Clavecin》(1716)
> 「鍵盤的精緻 = 每個音清晰、互不模糊。」

Couperin 從 harpsichord 演奏實踐角度確認 non-legato 是美學選擇，不是限制。

## 3. 對指法策略的意涵

Baroque 預設 non-legato 表示指法系統應該：

| 約束 | 為何適用於 non-legato |
|---|---|
| **不誘導同音換指** | 沒有「保持 legato 連續性」的需求；substitution 反而不必要 |
| **不過度懲罰同指連續** | 兩個短音之間天然有空隙，同指彈兩音不會 audibly broken |
| **允許 thumb 較自由** | 雖不像 staccato 完全鬆綁，但比 legato 段自由 |
| **不誘導 hand jump** | non-legato 不是 staccato；手位仍應穩定、減少不必要動作 |

→ Baroque non-legato 段的指法目標：**clean separation + stable hand position**，避免兩端極端。

## 4. 例外情況 — Baroque 中的 legato 段

Baroque 並非全曲都 non-legato。明確 legato 段：

| 情境 | 出處 |
|---|---|
| **明確 slur 標記** | Bach 偶爾標 slur（French Suite, Inventions 個別段）|
| **「chantant」/「cantabile」標記** | C.P.E. Bach 等明確標記抒情段需 legato |
| **Sarabande / Adagio 慢板樂章** | 慢速本身暗示 legato 詮釋 |
| **Vocal-derived melody（如 chorale-prelude）**| 模擬人聲必須 legato |

這些段落應該套用 [concept_legato_substitution](concept_legato_substitution.md) 規則，**不**按 non-legato default 處理。

## 5. 對指法系統的實作意涵

許多現代 edition（特別 Czerny 編訂、19 世紀浪漫派人士編訂的 Bach）會額外加上大量 slur。這些 slur 不是 Bach 原意，是編訂者的詮釋。

→ 指法系統面對 Baroque MXL 時應該謹慎：
- 信原譜（urtext / Bärenreiter / Henle）的少量 slur 標記
- **不要**因為現代 edition（Schirmer / Wiener Urtext）加大量 slur 就大規模啟用 legato substitution 規則

## 6. 適用作曲家 / 曲目

| 作曲家 / 時期 | 是否 non-legato default |
|---|---|
| **J.S. Bach** (1685-1750) | ✓ 主要 default |
| **G.F. Handel** (1685-1759) | ✓ |
| **Domenico Scarlatti** (1685-1757) | ✓（但 sonata 內有大量明確 staccato）|
| **F. Couperin / Rameau** | ✓（French school）|
| **C.P.E. Bach / Haydn early works** | 過渡期 — 部分仍 non-legato，部分轉向 Classical 平衡 |
| **Mozart (1756-1791)** | ✗ Classical 平衡（[concept_period_defaults](concept_period_defaults.md)）|

→ 指法系統判定為「Baroque」可參考作曲家 + 出版年（< 1750 視為 Baroque、1750-1820 視為 Classical 過渡）。
