# Concept: Tenuto — 持音的「禁止換指」約束

> 來源：Neuhaus *The Art of Piano Playing* §持音與重量、Czerny *Op.500*、Brendel essays §Beethoven 持音標記詮釋
> 引用方：[[concept_articulation_overview]] §4

## 1. Tenuto 是什麼

Tenuto（持音 / 保持音）= 標記 `–`（短線在音符上下方）。

意涵：
- **持滿值**：彈奏到該音規定的全部時長（不可提早釋放）
- **常含重量感**：相對於周圍音稍微壓重（但不強到 accent 的程度）
- **微停**：有時暗示在連接時略略 broaden，表現「強調」

不是 dynamic accent，是 duration + weight 的微強調。

## 2. 對指法的根本約束：禁止換指

Tenuto 的核心是「**這個音這個手指彈到底**」。同音換指（substitution）會破壞 tenuto 本意，因為：
- Substitution 必然有 release-attack 微切換點
- 即使 overlap 完美，weight transfer 在切換瞬間會弱化
- Tenuto 要求的「壓重感」需要單一手指持續施加力

→ 在 tenuto 音上：**禁用 finger substitution；強制保持原指**。

## 3. 適合彈 tenuto 的手指

不是所有手指都同樣適合 tenuto。考慮：

| 手指 | 持音穩定度 | 適合 tenuto？ |
|---|---|---|
| **1 (拇指)** | 高 — 大塊肌肉、可靠的 weight transfer | ✓ 適合 |
| **2 (食指)** | 高 — 獨立、強壯 | ✓ 適合 |
| **3 (中指)** | 高 — 最長、最穩 | ✓ 最適合 |
| **4 (無名指)** | 中 — 與 3/5 共用 juncturae tendinum，獨立性差 | △ 勉強 |
| **5 (小指)** | 低 — 小、力弱、難維持壓重 | ✗ 應避免 |

→ 指法系統遇到 tenuto 音時應**偏好 1/2/3**，避免 4/5（特別 5）。

## 4. Tenuto 與其他 articulation 的疊加

| 疊加 | 意涵 |
|---|---|
| **Tenuto + accent (`>`)** | 持音 + 額外重音；偏好強指 + 持滿值 |
| **Tenuto + staccato dot** | 矛盾標記，通常解讀為 portato（[[concept_portato_mezzo_staccato]]）|
| **Tenuto + slur 內** | 在 legato 段內的特定強調音；fingering 應「持指不換」即使周圍是 substitution-friendly 段 |
| **Tenuto + fermata** | 雙重延長；按 fermata 處理（額外時長），手指選擇按 tenuto 處理 |

## 5. 適用情境

| 情境 | 範例 |
|---|---|
| **Beethoven 持音標記** | 慢板樂章內聲部、後期作品大量 tenuto（Op.110, Op.111）|
| **Brahms 內聲部** | Intermezzo / Klavierstücke 經常用 tenuto 強調 inner voice |
| **Bach 重要 cadence 解決音** | 雖然 Baroque 沒有 tenuto 標記，演奏家會詮釋性加 tenuto |
| **Schumann / Liszt agogic 段** | Tenuto 暗示 micro-rubato |

## 6. 對既有指法策略的覆寫優先級

當 tenuto 與其他 articulation 規則衝突：

- Tenuto vs legato substitution → **tenuto 勝**（不換指）
- Tenuto vs accent strong-finger 偏好 → **同方向**（兩者都偏好 1/2/3）
- Tenuto vs staccato → 不會同時出現（矛盾標記）
