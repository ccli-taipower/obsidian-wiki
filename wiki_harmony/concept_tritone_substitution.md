# 三全音代理（Tritone Substitution）

> 前置知識：[concept_seventh_chord — 七和弦](concept_seventh_chord.md)（屬七和弦的結構與三全音解決）
> 建議先讀：[concept_secondary_dominant — 副屬和弦](concept_secondary_dominant.md)（V/X 的概念與離調）

你已經知道屬七和弦（dominant 7th）裡的**三全音（tritone）**是推動解決的核心力量——B↔F 這對音帶著強烈的張力，渴望解決到 C 和 E。現在問一個有趣的問題：**有沒有另一個屬七和弦，裡面藏著完全相同的三全音？**

答案是有，而且只有一個。這就是**三全音代理（Tritone Substitution）**的基礎。

---

## 1. 什麼是三全音代理

**三全音代理**：任何屬七和弦都可以被**根音相距三全音（6 個半音）的另一個屬七和弦**替換。

以 C 大調為例：

- 原本的解決：**G7 → C**（V7 → I，純五度下行）
- 三全音代理：**D♭7 → C**（♭II7 → I，半音下行）

為什麼 D♭7 能代替 G7？因為它們共享同一對三全音：

```
G7  的組成音：G – B – D – F
                   ↑           ↑
                三全音：B ↔ F（6 個半音）

D♭7 的組成音：D♭ – F – A♭ – C♭(=B)
                    ↑              ↑
                三全音：F ↔ C♭(=B)（6 個半音）
```

**三全音（三音和七音）是屬七和弦解決力量的核心**——既然 G7 和 D♭7 擁有相同的三全音，它們就擁有相同的解決引力，可以互相替換。

---

## 2. 為什麼可以代理

讓我們仔細對比 G7 和 D♭7 的內部結構：

| 組成音位置 | G7 | D♭7 |
|-----------|-----|------|
| 根音（Root） | G | D♭ |
| 三音（3rd） | **B** | **F** |
| 五音（5th） | D | A♭ |
| 七音（7th） | **F** | **C♭ (= B)** |

關鍵觀察：

1. **G7 的三音 B = D♭7 的七音 C♭**（異名同音，enharmonic）
2. **G7 的七音 F = D♭7 的三音 F**
3. 三音和七音**互換了角色**，但**是同樣兩個音**

解決方式也完全一致：

```
G7 → Cmaj7                    D♭7 → Cmaj7

B（G7 的三音）→ C（半音上行）    C♭=B（D♭7 的七音）→ C（半音上行）
F（G7 的七音）→ E（半音下行）    F  （D♭7 的三音）→ E（半音下行）
```

不管用 G7 還是 D♭7，那對三全音最終都以同樣的方式解決：**B → C**（半音上行）、**F → E**（半音下行）。所以耳朵聽到的張力釋放感幾乎一樣。

---

## 3. 低音的半音下行效果

三全音代理最迷人的地方不只是「可以替換」，而是替換後**低音線（bass line）變得極度平滑**：

| 進行 | 低音移動 | 聽感 |
|------|---------|------|
| G7 → C | G → C（下行純五度） | 強力、傳統，和聲引力最強 |
| D♭7 → C | D♭ → C（下行半音） | 滑順、時髦，半音滑入主和弦 |

半音下行的低音移動是爵士和聲最有魅力的色彩之一——那種「滑進去」的感覺帶著一絲慵懶的優雅。

### ii–V–I 中的三全音代理

當三全音代理用在完整的 ii–V–I 進行中，效果更驚人：

```
原版 ii–V–I：     Dm7  →  G7   →  Cmaj7
低音線：           D       G       C     （D 下行四度到 G，G 下行五度到 C）

三全音代理版：    Dm7  →  D♭7  →  Cmaj7
低音線：           D       D♭      C     （全部半音下行！）
```

**D → D♭ → C**——三個低音全部半音相連，形成一條完美的**半音下行線（chromatic descent）**。這是爵士鋼琴家和貝斯手最愛的聲響之一。

---

## 4. 實際應用

### 4-a. 基本用法：替換 V7

最直接的用法就是把 V7 → I 改成 ♭II7 → I：

```
原版：   Dm7 → G7  → Cmaj7       （ii–V–I）
代理版： Dm7 → D♭7 → Cmaj7       （ii–♭II7–I）
```

### 4-b. 用在副屬和弦上

三全音代理不只能用在 V7 上——任何屬七和弦都可以做三全音代理，包括副屬和弦：

| 原本的副屬和弦 | 解決到 | 三全音代理 | 代理後進行 |
|--------------|--------|-----------|----------|
| A7（V7/ii） | Dm | E♭7 | E♭7 → Dm |
| D7（V7/V） | G | A♭7 | A♭7 → G |
| E7（V7/vi） | Am | B♭7 | B♭7 → Am |

### 4-c. 連鎖三全音代理：半音下行低音線

當你對多個副屬和弦連續做三全音代理，會得到漂亮的半音下行低音線：

```
原版（副屬和弦連鎖）：
A7 → Dm7 → D7 → G7 → C
低音：A    D     D    G    C

三全音代理版：
A7 → Dm7 → A♭7 → G7 → C
低音：A    D     A♭    G    C

混合代理版（交替使用）：
E♭7 → Dm7 → A♭7 → G7 → Cmaj7
低音：E♭    D     A♭    G     C
```

### 4-d. 往 V 方向的代理

三全音代理也可以用在「前往 V」的路上。在 C 大調中，V7/V = D7（解決到 G）。D7 的三全音代理是 A♭7：

```
原版：  Cmaj7 → D7  → G7 → Cmaj7
代理版：Cmaj7 → A♭7 → G7 → Cmaj7
低音：   C       A♭    G     C    （A♭ → G 半音下行！）
```

## 5. 與增六和弦的關係

這裡有一個令人驚喜的發現：**古典和聲裡的增六和弦（augmented 6th chord）其實就是三全音代理的古典版本！**

以 C 大調為例，德國增六和弦（German augmented 6th，簡稱 Ger+6）：

```
Ger+6 in C：A♭ – C – E♭ – F#

等和聲（enharmonic）重新拼寫：
A♭ – C – E♭ – G♭ = A♭7（A♭ 屬七和弦）
```

- A♭7 是 D7 的三全音代理（根音相距 6 個半音）
- D7 = V7/V（C 大調中 G 的屬七和弦）
- Ger+6 解決到 V（G），等同於 A♭7 → G

**結論**：德國增六和弦就是 V7/V 的三全音代理——古典理論家和爵士理論家用不同的名字描述了同一件事！

```
古典觀點：Ger+6（A♭-C-E♭-F#）→ V（G）
             ↕ 其實是同一個東西
爵士觀點：A♭7（三全音代理 D7）→ G
```

差別只在**拼寫**：古典理論寫 F#（增六度，向上解決到 G），爵士理論寫 G♭（小七度）。聽起來完全一樣。

## 6. 口訣與記法

### 快速找到三全音代理

從任何屬七和弦的根音出發，**上行或下行 6 個半音（三全音 = 增四度 = 減五度）**，得到的就是它的三全音代理：

```
G  →（+6 半音）→ D♭ / C#     G7  ↔ D♭7
A  →（+6 半音）→ E♭ / D#     A7  ↔ E♭7
D  →（+6 半音）→ A♭ / G#     D7  ↔ A♭7
E  →（+6 半音）→ B♭ / A#     E7  ↔ B♭7
B  →（+6 半音）→ F           B7  ↔ F7
F  →（+6 半音）→ B           F7  ↔ B7
C  →（+6 半音）→ F# / G♭     C7  ↔ F#7/G♭7
```

### 記法口訣

> **屬七雙胞胎**：相距三全音的兩個屬七和弦共享同一對三全音（三音和七音），因此可以互換。
>
> **找代理**：從根音數 6 個半音（上或下都可以），那就是你的代理和弦。
>
> **代理的魅力**：低音半音下行滑入目標和弦。

## 7. 小測驗

試著回答以下問題（答案在下方）：

1. G7 的三全音代理是什麼和弦？為什麼它可以代替 G7 解決到 C？
2. 在 C 大調中，ii–V–I 的三全音代理版本是什麼？低音線有什麼特點？
3. A7（V7/ii in C）的三全音代理是什麼和弦？它解決到哪裡？
4. D♭7 和 G7 的三音和七音分別是什麼？它們之間有什麼關係？
5. 三全音代理的低音移動（♭II7 → I）和傳統 V7 → I 的低音移動有什麼不同？各自的聽感如何？
6. 為什麼三全音代理只對屬七和弦有效？（提示：想想哪種和弦裡面的三音和七音恰好形成三全音。）
7. 在 C 大調中，德國增六和弦（Ger+6 = A♭-C-E♭-F#）等和聲地等於什麼屬七和弦？它是哪個和弦的三全音代理？
8. E7 的三全音代理是什麼？如果在 C 大調中用它代替 V7/vi（E7），進行會變成什麼？
9. 在進行 Dm7 → G7 → Cmaj7 中，如果只對 G7 做三全音代理，低音線從什麼變成什麼？
10. B7（V7/iii in C）的三全音代理是什麼？代理後解決到 Em 時，低音移動方向是什麼？

<details>
<summary>答案</summary>

1. **D♭7** — G 和 D♭ 相距三全音（6 個半音）。G7 的三全音是 B↔F，D♭7 的三全音是 F↔C♭(=B)，兩者共享同一對三全音，因此擁有相同的解決引力，B → C（半音上行）、F → E（半音下行）。

2. **Dm7 → D♭7 → Cmaj7** — 低音線為 D → D♭ → C，全部半音下行，形成完美的半音下行線（chromatic descent）。這是爵士中最經典的三全音代理用法。

3. **E♭7** — A 和 E♭ 相距三全音。E♭7 解決到 Dm（和原本的 A7 → Dm 解決到同一個目標）。進行變成 E♭7 → Dm，低音 E♭ → D 為半音下行。

4. **D♭7：三音 = F，七音 = C♭(=B)。G7：三音 = B，七音 = F** — D♭7 的三音是 G7 的七音，D♭7 的七音是 G7 的三音。三音和七音互換了角色，但是同樣兩個音（B 和 F）。

5. **V7 → I 的低音是純五度下行（G → C），聽感強力、傳統、「有重量的著陸」；♭II7 → I 的低音是半音下行（D♭ → C），聽感滑順、時髦、「慵懶地滑入」**。兩者解決的張力感相同（因為三全音一樣），但低音移動方式不同，帶來截然不同的風格。

6. **只有屬七和弦的三音和七音恰好形成三全音（增四度 / 減五度 = 6 個半音）** — 大七和弦的三音和七音形成純五度（不是三全音），小七和弦也不是。屬七和弦的結構（大三度 + 小三度 + 小三度）使得三音和七音間距恰好為三全音，這才讓「相距三全音的兩個屬七和弦共享同一對三全音」成為可能。

7. **A♭7（= A♭-C-E♭-G♭，其中 F# 等和聲於 G♭）。它是 D7（V7/V）的三全音代理** — A♭ 和 D 相距三全音。古典理論稱之為「德國增六和弦」，爵士理論稱之為「D7 的三全音代理」，是同一件事的兩種描述。

8. **B♭7** — E 和 B♭ 相距三全音。在 C 大調中代替 V7/vi（E7 → Am），進行變成 B♭7 → Am，低音 B♭ → A 為半音下行。

9. **原本低音線：D → G → C（四度上行 + 五度下行）；代理後低音線：D → D♭ → C（半音 + 半音，全部半音下行）** — 原版的根音移動走五度圈（引力強），代理版變成連續半音下行（更平滑流暢）。

10. **F7** — B 和 F 相距三全音。F7 → Em 時低音為 F → E，半音下行。原本的 B7 → Em 低音是純五度下行（B → E），代理後變成半音滑入。

</details>
