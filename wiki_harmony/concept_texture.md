# 音樂織體（Musical Texture）

和弦決定「在這個時間點，哪些音同時響」；聲部導進決定「音如何從一個和弦走到下一個」；而**織體（texture）**決定的是更根本的東西：這些音層是怎麼**組織在一起**的？

對鋼琴演奏而言，織體識別不只是樂理課題——它直接決定**你用哪套指法策略**。同一組音符，若它是主音織體中的分解和弦，指法邏輯完全不同於多聲部複音織體中兩條旋律線的交織。**DP 指法引擎在計算之前，必須先確定織體類型。**

---

## 1. 什麼是織體

**織體 = 聲部的數量 × 聲部的獨立程度 × 節奏關係**

- 聲部少、節奏同步 → 簡單織體（單音、和弦）
- 聲部多、節奏各自獨立 → 複雜織體（複音）
- 一條主旋律 + 陪伴層 → 中間地帶（主音）

織體不只影響聽感，更決定：
1. 雙手如何**分工**（哪隻手負責哪條聲部）
2. 每隻手內部如何**配置手指**（旋律指法 vs. 和弦指法 vs. 律動型指法）
3. 指法**換指替代（finger substitution）** 的需求高低

---

## 2. 四種基本織體

### 2a. 單音織體（Monophony）

**定義**：只有一條旋律線，無任何和聲陪伴。

**鋼琴實例**：
- Beethoven Sonata Op. 57「熱情」第三樂章開頭，兩手同向八度齊奏
- 清唱劇改編中，旋律以 unison 出現的段落

**指法策略**：
- 純旋律／音階指法，maximize legato
- 若八度齊奏：雙手各用 **1–5** 八度指法，同步翻越
- 單手旋律：按音階走向選擇最自然的拇指跨越點
- DP 引擎：只需考慮單條音序的最小位移成本，無聲部分配問題

---

### 2b. 主音織體（Homophony）

**定義**：一條主旋律 + 陪伴層，兩者節奏可以不同步。最常見的鋼琴織體。

兩種常見子類型：

#### Block chord 主音（旋律 + 柱式和弦）
- RH 旋律：旋律指法（連貫優先）
- LH 和弦：和弦指法（全音符或二分音符的靜態和弦，換指用聲部導進邏輯）
- 指法邏輯：**兩手使用不同策略**，分開計算，最後合成

**鋼琴實例**：Schubert 小夜曲、簡單的讚美詩配合奏

#### Alberti bass 主音（旋律 + 分解伴奏）
- RH 旋律：旋律指法
- LH Alberti bass（如 C–G–E–G）：**先識別底層和弦**（C major），再用和弦手型套入分解型式

**Alberti bass 指法範例（以 C major 為例）**：

```
音符序列：C3 – G3 – E3 – G3 – C3 – G3 – E3 – G3
↓ 識別為：C 大三和弦的分解（根–五–三–五 循環）
↓ 手型：5 在 C，2 在 E，1 在 G
↓ 指法：5–1–2–1 – 5–1–2–1
```

**關鍵洞察**：若把這串音當作「音階」來算指法，結果是錯的。必須先辨識出分解和弦，才能用正確手型。

**DP 引擎考量**：
- 旋律手 → 旋律成本函數（legato 連接、拇指橫越代價）
- 伴奏手 → 模式識別（broken chord / Alberti），鎖定和弦手型後再展開

---

### 2c. 複音織體（Polyphony）

**定義**：兩條以上旋律線，各自在節奏和旋律上**獨立**前進。

**鋼琴實例**：
- Bach《二聲部創意曲》：左右手各一條獨立旋律
- Bach《賦格》：同一隻手可能同時承載主題聲部 + 對題聲部
- Brahms 間奏曲：RH 旋律線 + 內聲部反旋律

**指法策略**：
- 每條聲部有**自己的旋律指法**，互相獨立計算
- 同一隻手承擔兩條聲部時，需用**換指替代（finger substitution）**：同一個音，先用一指按住，再悄悄換另一指，以解放前者去移動到下一個聲部的音
- 聲部分配本身也是指法問題：哪個音給哪隻手？

**換指替代（Finger Substitution）**的典型場景：
```
soprano: C4（二分音符）────────────
alto:          E4（四分）→ F4（四分）

C4 先用 RH 3 按，再悄換 RH 2，讓 3 去按 E4
```

詳見 → [[concept_counterpoint_basics]]，有完整的複音指法框架

---

### 2d. 和弦織體 / 同節奏織體（Homorhythm / Chordal）

**定義**：所有聲部**節奏完全同步**，像磚塊堆砌。

**鋼琴實例**：
- 讚美詩（hymn）配合奏（SATB 四聲部，每個音節同時換和弦）
- Bach《聖詠》編曲
- Chopin Prelude Op. 28 No. 20（C minor）

**指法策略**：
- 雙手皆用**和弦指法**
- 指法轉換成本 = 聲部導進的距離（音符移動愈少，換指愈自然）
- 常見的聲部導進原則（如保留共同音、平行五度禁忌）在這裡直接轉化為「換指成本」

**DP 引擎考量**：
- 節點 = 每個和弦時間點的手型
- 邊 = 和弦間的換指代價（由聲部導進距離決定）
- 最短路徑 = 最省力的和弦序列指法

詳見 → [[concept_voice_leading]]，有聲部導進到指法成本的對應

## 3. 織體如何決定指法策略——決策框架

| 織體類型 | 指法模式 | DP 引擎主要考量 | 典型曲目 |
|----------|----------|----------------|----------|
| **單音（Monophony）** | 旋律／音階指法 | 連貫成本、拇指橫越點 | Beethoven 八度齊奏段落 |
| **主音—柱式（Homophony block）** | RH 旋律 + LH 和弦（分開策略） | 兩手獨立計算，各用其策略 | Schubert 小夜曲 |
| **主音—分解（Homophony broken）** | 旋律 + 和弦手型展開 | 先識別底層和弦，鎖定手型 | Mozart／Haydn 慢板 |
| **複音（Polyphony）** | 多聲部各自旋律指法 + 換指替代 | 聲部分配 + per-voice 成本 | Bach 創意曲、賦格 |
| **和弦（Homorhythm）** | 和弦指法 + 聲部導進轉換 | 和弦間換指成本 = 聲部移動量 | Bach 聖詠、讚美詩 |

**核心洞察**：一段看起來是「散落音符」的鋼琴音序，可能是：

1. 分解和弦（homophonic）→ 應識別底層和弦，用和弦手型
2. 兩條交織旋律（polyphonic）→ 應分離聲部，各自算指法
3. 快速音階裝飾（monophonic）→ 應用音階指法

三種情況下，最佳指法**完全不同**。指法引擎若跳過織體識別，直接套用單一策略，結果幾乎必然是次優的。

## 4. 織體轉換

真實音樂中，織體在樂曲內**不斷切換**。每次切換都意味著指法策略要跟著換。

**Chopin Nocturne Op. 9 No. 2 的織體地圖**（示意）：

```
mm. 1–4    (A 段)   主音織體：RH 旋律 + LH 三連音分解和弦
mm. 5–8    (A')     同上，但 RH 加裝飾音（仍主音）
mm. 9–12   (B 段)   複音傾向：RH 旋律 + 內聲部反旋律浮現
mm. 20–23  (Coda)   主音（簡化），最後幾小節和弦織體收尾
```

每個邊界 = **指法策略切換點**。DP 引擎應該：
1. 在織體邊界**重置策略模型**（不要跨邊界延伸錯誤策略）
2. 在邊界附近允許稍微「貴」的換指，以為下一段做好手型準備

另一個例子——**Chopin Étude Op. 10 No. 1**：
- 主織體：RH 是 monophony（單音線性走法）？不對——是分解和弦 broken chord（arpeggiated texture）
- 正確識別：每一組音符 = 和弦的散奏，手要展開成和弦手型，指法用 1–2–1–2–1–5 等形式
- 若誤識別為音階，指法會完全錯誤

## 5. 織體識別的實際指法應用

### 5a. Alberti Bass 識別

**音符序列**：`C3 G3 E3 G3 | C3 G3 E3 G3`

- 錯誤路徑：視為線性音序，用音階指法 → 5-4-3-2 …（不穩定，每次位置不同）
- 正確路徑：識別為 C major 分解 → 固定手型 5(C)-2(E)-1(G)，指法 **5–1–2–1** 循環

### 5b. 一手兩音——顫音 or 複音？

**音符序列**：`E4 F4 E4 F4 E4 F4`（很快）

- 若是**顫音（trill）**：單聲部，用 **2–3** 或 **1–2** 交替，優化速度
- 若是**兩條獨立聲部**（一條持 E，一條走旋律）：需要換指替代，完全不同手型

識別關鍵：看記譜的符桿方向（stem up = 上聲部；stem down = 下聲部）

### 5c. 八度重複——單音織體確認

**音符序列**：`C4 D4 E4` 同時 `C5 D5 E5`（雙手）

- 這是 monophony 的八度加厚，不是兩條獨立旋律
- 指法：兩手各用 **1–2–3**，完全鏡射，不需要換指替代
- 絕對不要把上方八度視為獨立聲部而拆開計算

### 5d. 柱式和弦 vs. 旋律音

**場景**：RH 同時有 `{G4, B4, D5}` 再加 `E5`（主旋律最高音）

- 和弦部分 {G4, B4, D5} = 和弦指法（2–3–5 或 1–2–4）
- 旋律音 E5 = 這一組的最高音，由最高指（5 或改配置後的指）承接
- 旋律指（最高音）要有**觸鍵深度**差異，比和弦音稍重
- 指法分配時，旋律音的指號優先固定，和弦音指號圍繞它調整

## 6. 小結：織體識別清單

在計算指法之前，先問以下問題：

```
1. 這段有幾條獨立的聲部線？
   → 1 條           : 單音織體 → 旋律指法
   → 1 主 + 伴奏    : 主音織體 → 分開策略
   → 2+ 條各自獨立  : 複音織體 → per-voice + 換指替代
   → 全部同步       : 和弦織體 → 和弦指法 + 聲部導進成本

2. 伴奏層是柱式和弦還是分解音型？
   → 分解型 → 先找底層和弦，再套指法

3. 快速交替音是顫音還是兩個聲部？
   → 看符桿方向、看持續長度

4. 這個織體在哪裡結束、下一個從哪裡開始？
   → 邊界 = 策略切換點
```
