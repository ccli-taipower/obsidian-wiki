### 音程

1. **增五度（A5），8 個半音** — B♭ → F 是完全五度（P5，7 半音），F 升到 F# 增加一個半音 = 增五度。

2. **8 個半音；轉位是大三度（M3，4 半音）** — 轉位規則：度數 = 9 − 6 = 3，性質小→大。驗算：8 + 4 = 12 ✓

3. **聽起來一樣（等音異名），但音程名稱不同** — C → G♭：白鍵 C → G 是五度，♭ 縮小 = 減五度（d5）。C → F#：白鍵 C → F 是四度，# 擴大 = 增四度（A4）。兩者都是 6 個半音（三全音 tritone），名字不同是因為起算的字母（度數）不同。

4. **大六度（M6）或減七度（d7）** — 同樣 9 個半音，字母距離 6（如 C→A = M6）就是大六度，字母距離 7（如 C→B𝄫 = d7）就是減七度。

### 音階與調性

5. **4 個升記號：F# C# G# D#** — 五度圈順時針：C→G(1#)→D(2#)→A(3#)→E(4#)。

6. **D♭ 大調；音階：D♭–E♭–F–G♭–A♭–B♭–C–D♭** — 5 個降記號（B♭ E♭ A♭ D♭ G♭），倒數第二個降記號是 D♭ = 調名。

7. **ii = Gm（G-B♭-D），vi = Dm（D-F-A）** — F 大調音階：F-G-A-B♭-C-D-E，ii 級以 G 為根音疊三度，vi 級以 D 為根音疊三度。

8. **第 6 音不同：和聲小調的第 6 音是 A♭，旋律小調上行的第 6 音是 A♮** — C 和聲小調 = C-D-E♭-F-G-**A♭**-B，C 旋律小調上行 = C-D-E♭-F-G-**A**-B。旋律小調升第 6 音是為了避免 A♭→B 的增二度（聽感不自然的跳躍）。

### 教會調式

9. **F G A B C D E；和 F 大調差在第 4 音：B♭ → B♮** — Lydian 的特徵音是 #4。F 大調的第 4 音 B♭ 升半音 = B♮，結果剛好是全白鍵（= C 大調的音從 F 開始讀）。

10. **B♭ C D E♭ F G A♭** — 步驟：B♭ 大調 = B♭-C-D-E♭-F-G-A；Mixolydian = 大調降第 7 音：A → A♭。

11. **母調是 C 大調；E Phrygian = E F G A B C D** — Phrygian 是母調的第 III 級。E 是 C 大調的第 3 個音，所以 E Phrygian = C 大調音群從 E 開始讀。

12. **Lydian #4（最亮）→ Ionian 無差異 → Mixolydian ♭7（最暗）** — 三種大調型都和大調比較：Lydian 唯一升一個音（更亮），Mixolydian 唯一降一個音（更暗），Ionian 就是大調本身。

### 三和弦

13. **E♭ 大三 = E♭-G-B♭，E♭ 小三 = E♭-G♭-B♭；只差三音（G vs G♭）** — 大三和弦 = M3+m3（E♭→G 4 半音，G→B♭ 3 半音），小三和弦 = m3+M3（E♭→G♭ 3 半音，G♭→B♭ 4 半音）。

14. **A 大三和弦的第二轉位（6/4），根音是 A** — A-C#-E 重排為 E-A-C#，最低音 = 五音 E = 第二轉位。

15. **6 個半音，叫做減五度（d5），也就是三全音（tritone）** — m3（3 半音）+ m3（3 半音）= 6 半音。減三和弦正是因為這個不穩定的減五度而帶有強烈張力。

16. **I = D（大），ii = Em（小），iii = F#m（小），IV = G（大），V = A（大），vi = Bm（小），vii° = C#dim（減）** — D 大調音階：D-E-F#-G-A-B-C#，每級疊三度。口訣「大小小大大小減」適用於所有大調。

### 七和弦

17. **E♭-G-B♭-D；堆疊：M3-m3-M3** — E♭→G = M3（4 半音），G→B♭ = m3（3 半音），B♭→D = M3（4 半音）。大七和弦的固定堆疊模式。

18. **ii7 = Cm7（C-E♭-G-B♭），V7 = F7（F-A-C-E♭）** — B♭ 大調音階：B♭-C-D-E♭-F-G-A，ii 級以 C 為根音疊四個三度，V 級以 F 為根音疊四個三度。

19. **F-A♭-C♭-E𝄫（等音 = F-A♭-B-D）；等音於 A♭dim7、Bdim7、Ddim7** — 減七和弦四個音各距 3 半音（3+3+3+3=12），完全對稱，任何一個音都可視為根音，所以 12 個音只能組成 3 組不同的減七和弦。

20. **10 個半音，小七度（m7）** — M3（4）+ m3（3）+ m3（3）= 10 半音。這是屬七和弦的標誌：大三和弦（明亮）+ 小七度（張力），兩者結合產生強烈的解決驅動力。

21. **最低音是 B（三音），數字低音 6/5** — G7 = G-B-D-F，第一轉位把三音 B 放最低：B-D-F-G。完整數字低音 6/5/3，省略 3 後寫 6/5。

### 延伸和弦

22. **F-A-C-E♭-G** — F 屬七和弦 = F-A-C-E♭（1-3-5-♭7），再加九音 G（= F 上方大九度）。

23. **保留：根音(C)、♭7(B♭)、9(D)、11(F)；省略：三音(E)、五音(G)** — 三音 E 和十一音 F 只差半音，同時彈奏極度衝突，所以三音最先省略。五音 G 不影響和弦個性，次之省略。

24. **七音不同：Cmaj9 = B（大七度），C9 = B♭（小七度）** — Cmaj9（C-E-G-B-D）清亮、夢幻、安定；C9（C-E-G-B♭-D）因三音 E 和七音 B♭ 形成三全音，帶張力、想解決。一個半音的差異改變了和弦的整體方向感。

25. **十三和弦已包含音階全部 7 個音（1-3-5-7-9-11-13），再疊三度 = 15 = 根音的兩個八度，不產生新音** — 九度=2 的高八度、十一度=4 的高八度、十三度=6 的高八度。七個音階音用完了，無法再延伸。

### Sus 與 Add 和弦

26. **F-B♭-C；解決到 F 大三和弦（F-A-C），四度音 B♭ 下行到三音 A** — sus4 的張力來自四度音佔據了三音的位置，解決就是讓它「落回」三音。B♭→A 是半音下行。

27. **Dadd9 = D-F#-A-E（保留三音 F#），Dsus2 = D-E-A（二音取代三音，無 F#）** — 根本差別是有沒有三音：add9 有三音所以有大小性格，sus2 沒有三音所以性格模糊（懸留狀態）。

28. **懸留的是四度音（sus4）或二度音（sus2），它來自前一個和弦的延留** — 古典理論中，前一個和弦的某個音「懸掛」不解決，佔據了三音的位置。例如 F → Csus4 → C：F 和弦的 F 音延留到 Csus4，然後下行半音解決到 E（C 的三音）。

29. **Csus4 是三和弦層級（C-F-G，無七音），C11 是七和弦的延伸（C-G-B♭-D-F，含♭7）** — C11 必含七音 B♭（否則就不是延伸和弦），還包含九音 D；Csus4 只有三個音，沒有七音。雖然都省略三音、都含 F，但和聲厚度和功能完全不同。

### 功能和聲

30. **T = I(D), iii(F#m), vi(Bm)；S = ii(Em), IV(G)；D = V(A), vii°(C#dim)** — D 大調音階：D-E-F#-G-A-B-C#。功能分配規則和 C 大調相同，只是所有和弦移調。

31. **I = D（D-F#-A），vi = Bm（B-D-F#），共享 D 和 F# 兩個音** — 兩個共同音讓 vi 可以替代 I 而不突兀，但 Bm 是小三和弦，帶有小調的憂鬱色彩。這也是欺騙終止（V → vi）能「騙過」耳朵的原因——vi 和 I 很像，但情緒轉暗。

32. **古典和聲稱為「逆行」（retrogression），被視為不正常的流向** — 但在流行、搖滾、藍調中非常常見。例如 12 小節藍調的第 9→10 小節（V → IV）就是典型的 D → S 逆行。

33. **V = B 大三和弦（B-D#-F#）** — 自然小調的 v = Bm（B-D-F#）缺少導音 D#，無法產生 D#→E 的半音解決。和聲小調升第 7 音（D→D#）就是為了讓 V 級成為大三和弦，獲得導音解決的張力。

### 終止式

34. **B♭ → E♭** — E♭ 大調的 V = B♭，I = E♭。

35. **欺騙終止（V → vi）** — G 大調中 D = V 級，Em = vi 級。V 級沒有解決到預期的 I 級（G），而是「欺騙」聽眾轉向 vi 級。

36. **結束在 V（屬和弦）上** — V 本身有強烈的張力、想解決到 I，所以停在 V 會產生「話還沒說完」的感覺——像問號。這讓它適合放在前句（antecedent）結尾，由後句的正格終止（V→I）來「回答」。

37. **D → A；別名「阿門終止」（Amen cadence）** — 教堂聖歌結尾常用 IV → I 唱「A-men」，因此得名。變格終止比正格終止柔和，缺少導音半音解決的強勢感。

### 和弦進行

38. **A–E–F#m–D** — I=A, V=E, vi=F#m, IV=D。A 大調的調號有 3 個升記號（F# C# G#）。

39. **S → T（下屬功能→主功能）** — IV = 下屬和弦（S），I = 主和弦（T）。這和 V→I（D→T）不同，是一種較柔和的回歸方式，沒有導音半音解決的強勢感。

40. **Am7 → D7 → Gmaj7；根音 A→D→G，每步都是下行純五度** — G 大調：ii = Am(7)，V = D(7)，I = Gmaj7。根音沿五度圈連續下行（A→D→G），每一步都是「屬→主」的引力，形成連鎖解決。

41. **C → D → Bm → Em** — G 大調：IV=C, V=D, iii=Bm, vi=Em。V 之後接 iii 而非 I，讓解決感「來得側面」而非直接。

### 副屬和弦

42. **A7（A-C#-E-G），C# 是臨時升降音** — V/V = V 級（D）的屬和弦。D 的屬音是 A，A 的屬七 = A7。C# 不屬於 G 大調（G 大調只有 F#），是為了形成導音 C#→D 的半音解決。

43. **V/vi，目標和弦是 Am** — E 是 A 的屬音，E7 = A 的屬七和弦。在 C 大調中 A = vi 級（Am），所以 E7 = V/vi。G# 是臨時升降音（導音，半音上行 G#→A）。

44. **因為 vii° 是減三和弦，極不穩定，無法作為副屬和弦的解決目標** — 副屬和弦的目標必須是「能感覺像臨時主和弦」的大三或小三和弦。減三和弦本身就不穩定，不具備主和弦的安定感。

45. **副屬和弦來自「某個順階和弦的屬和弦」（製造短暫離調）；借用和弦來自「同主音的平行調」（引入平行調色彩）** — 例如 C 大調中，A7 = V/ii（副屬，來自 Dm 的屬和弦），Fm = iv（借用，來自 C 小調的四級和弦）。兩者都含非本調音，但來源邏輯不同。

### 轉調

46. **Em 在 G 大調是 vi 級，在 D 大調是 ii 級** — 這讓 Em 成為理想的共同和弦：前半段當作 G 大調的 vi 聽，後半段重新詮釋為 D 大調的 ii，接 D 大調的 V→I 完成轉調。

47. **G 大調、F 大調、A 小調、E 小調、D 小調（共 5 個）** — 近系調 = 調號相差不超過一個升降記號。G（1#）、F（1♭）是大調近系調；A（0#♭）、E（1#）、D（1♭）是它們的關係小調。

48. **直接轉調（Direct Modulation）** — 也叫「卡車司機轉調」（Truck Driver's Modulation）。沒有共同和弦或半音過渡，直接跳到新調，常用於流行歌最後副歌製造「升級」的興奮感。

49. **時間長短和是否在新調建立穩定感** — 離調只是短暫借用（1-2 個和弦後馬上回到原調），轉調則是真正移居到新調（在新調中進行 V→I 等終止式，建立新的主音感，後續的音樂繼續在新調中進行）。

### 跨概念綜合

50. **(a) 和弦分類**：C = I（順階三和弦）；A7 = V/ii（副屬和弦，C# 臨時升降音）；Dm7 = ii7（順階七和弦）；G9 = V9（順階屬七 + 九音延伸）；Cmaj7 = Imaj7（順階七和弦）。**(b) 功能**：C = T；A7 = 離調（指向 ii）；Dm7 = S；G9 = D；Cmaj7 = T。**(c) 功能流向**：T → [V/ii 離調] → S → D → T，是帶有副屬和弦裝飾的完整功能循環。A7 在 Dm7 前面製造短暫離調，讓 ii 級的出場更有引力，之後按正常 S→D→T 回家。
