# Sus 與 Add 和弦（Suspended & Added Tone Chords）

> 前置知識：[concept_triad — 三和弦](concept_triad.md)（三和弦的三音與五音概念）
> 建議先讀：[concept_extended_chord — 延伸和弦](concept_extended_chord.md)（九 / 十一 / 十三和弦的疊加邏輯）

九和弦、十一和弦都必須先通過七和弦，再往上疊。但有兩類和弦走了「捷徑」：

- **sus 和弦**：把三音換掉，改用別的音
- **add 和弦**：三和弦直接加一個音，跳過七音

它們不是延伸和弦的子集，而是獨立的和弦色彩分類。

---

## 1. Sus 和弦（Suspended Chord）

### 「懸掛」的意義

sus 是 **suspended**（懸掛）的縮寫。「懸掛」指的是：三音被「掛」走了，換成另一個音，使和弦沒有大 / 小的明確性格，聽起來「懸而未決」，等待解決。

常見的 sus 和弦有兩種：

### 1a. Sus4 和弦

**公式**：1 – 4 – 5（三音被第四度音取代）

以 **Csus4 = C–F–G** 為例：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●   ●
  根          4   5
  C           F   G
  （沒有 E = 三音）
```

- **無大 / 小性格**：因為沒有三音，聽起來既非大調也非小調
- **開放、空曠、帶期待感**
- **通常解決至大三和弦**：Csus4 → C（F 下行半音到 E，三音「歸位」）

符號：**Csus4 / Csus**（sus 不加數字預設為 sus4）

### 1b. Sus2 和弦

**公式**：1 – 2 – 5（三音被第二度音取代）

以 **Csus2 = C–D–G** 為例：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●   ●           ●
  根  2            5
  C   D            G
  （沒有 E = 三音）
```

- **空靈、飄逸**，比 sus4 更現代感
- 常出現在流行、搖滾的吉他分散和弦（arpeggio）段落
- 有時當作 add9 的精簡版（add9 保留三音，sus2 省略三音）

符號：**Csus2**

### Sus 和弦的解決（Resolution）

```
Csus4 → C（最典型解決）：
F（4）下行半音到 E（3）——三音「落地」，懸掛感消失

Csus4 → Am（常見替代解決）：
C 保留（共同音），F 下行半音到 E，G 上行全音到 A
三個音各只移動一步，Am 是 C 的關係小調，有穩定感但更柔和
```

Sus 和弦常用在歌曲的 **intro / outro / 橋段**，製造期待感或開放感。詳見：[chord_sus](chord_sus.md)

## 2. Add 和弦（Added Tone Chord）

### Add 的定義

**add** = added tone。在**三和弦**的基礎上直接加上一個音，**不需要先有七音**。最常見的是 add9：

### 2a. Add9 和弦

**公式**：1 – 3 – 5 – 9（三和弦 + 九音，但沒有七音）

以 **Cadd9 = C–E–G–D** 為例：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●   ●   ●       ●
  根  9   3       5
  C   D   E       G
  （沒有 B = 七音）
```

- **清新、空氣感**——有三音的大調亮度，加上九音的色彩，但沒有七音的「複雜感」
- 比 C9（含七音）聽起來更簡單、乾淨
- 大量出現在 J-pop、ACG、英式搖滾中

符號：**Cadd9 / Cadd2**（add2 = add9 的另一種寫法，音名相同但位置不同）

### 2b. Add11 和弦

**公式**：1 – 3 – 5 – 11（三和弦 + 十一音）

以 **Cadd11 = C–E–G–F** 為例。三音 E 與十一音 F 相距半音，有時帶輕微衝突感，但在特定聲位下呈現獨特的色彩。

符號：**Cadd11 / Cadd4**

Add11 比 add9 少見，但常出現在特定風格的鋼琴聲位中。

詳見：[chord_add](chord_add.md)

## 3. Sus / Add vs 延伸和弦的區別

### 三者比較表

| 和弦 | 組成音（C 為根） | 有無七音 | 有無三音 | 關鍵特徵 |
|------|----------------|---------|---------|---------|
| **Csus4** | C – F – G | ✗ | ✗（換成 4th） | 三音被替換，無大/小性格 |
| **Csus2** | C – D – G | ✗ | ✗（換成 2nd） | 同上，更空靈 |
| **Cadd9** | C – E – G – D | ✗ | ✓ | 三和弦直接加 9，無七音 |
| **C9** | C – E – G – B♭ – D | ✓（♭7） | ✓ | 延伸和弦，必須有七音 |
| **C11** | C – (E) – G – B♭ – D – F | ✓（♭7） | △（常省略） | 延伸和弦，通常省略三音 |

### 核心區別

**1. add9 vs C9（九和弦）**

```
Cadd9 = C – E – G – D
         根  3   5   9    ← 沒有七音（B♭）

C9    = C – E – G – B♭ – D
         根  3   5   ♭7  9   ← 有七音才是「延伸和弦」
```

> 關鍵：**有沒有七音**。add9 繞過七音直達九音；C9 是七和弦的延伸，必含七音。

**2. Csus4 vs C11（十一和弦）**

```
Csus4 = C – F – G
         根  4   5    ← 三音被替換掉

C11   = C – (E) – G – B♭ – D – F
         根  (3)  5    ♭7   9   11 ← 理論上含三音（但常省略）
```

> 關鍵：**三音是被替換還是保留**。sus4 的三音消失了；11 和弦的三音是理論上保留（實際常省略是為了避免衝突，不是定義上的缺席）。

**省略三音後，C11 和 Csus4 有什麼關係？**

C11 省略三音後 = C-F-G-B♭-D，其實就是 Csus4 加上 ♭7 和 9。爵士裡有時寫成 **C9sus4** 或 **C7sus4(9)**，和 C11（省略三音）是同一個和弦：

```
Csus4       = C – F – G                （三和弦層級，無七音）
C7sus4      = C – F – G – B♭           （加了♭7）
C9sus4      = C – F – G – B♭ – D       （再加九音）= C11 省略三音
```

> 外觀像 sus4，但骨架是延伸和弦（有 ♭7 和 9），厚度和功能完全不同。

### 聽感速記

| 和弦類型 | 聽感一句話 |
|---------|----------|
| sus4 | 懸而未決，等待三音落地 |
| sus2 | 開放空靈，現代感 |
| add9 | 清新大方，大調的空氣 |
| dom9（C9） | 藍調張力，爵士色彩 |
| Maj9（Cmaj9） | 精緻夢幻，都市流行 |

## 4. 小測驗

試著回答以下問題（答案在下方）：

1. 以 G 為根音，分別建構 Gsus4 和 Gsus2，組成音各是什麼？
2. Csus4（C-F-G）和 C11（C-(E)-G-Bb-D-F）都含有 F 這個音，它們最根本的區別是什麼？
3. Cadd9 的組成音是 C-E-G-D，Csus2 的組成音是 C-D-G。兩者都含 D（= 2nd/9th），差別在哪？
4. Sus 和弦最常見的解決方式是什麼？以 Dsus4 為例，它如何解決？
5. Sus 和弦為什麼沒有大/小性格？和弦中缺少了什麼決定性的音？
6. 以 A 為根音，建構 Aadd9，組成音是什麼？它和 A9 有什麼不同？
7. 在流行歌的 intro 或 outro 中，常聽到 Csus4 → C → Csus2 → C 的反覆。這個進行為什麼有效？每一步發生了什麼聲部移動？
8. Csus4 除了解決到 C（大三和弦），還常見解決到哪個小三和弦？為什麼這也合理？
9. Add11 和弦（如 Cadd11 = C-E-G-F）比 add9 少見。為什麼 add11 在使用上需要特別注意？
10. 「sus 不加數字預設為 sus4」——寫 Csus 和 Csus4 是同一個和弦嗎？有些記譜法裡 Csus 指的是什麼？

<details>
<summary>答案</summary>

1. **Gsus4 = G-C-D**（1-4-5，三音 B 被四度音 C 取代）；**Gsus2 = G-A-D**（1-2-5，三音 B 被二度音 A 取代）。兩者都沒有三音 B，所以無大/小性格。
2. **三音的處理方式不同** — Csus4 的三音（E）被**替換**掉了，和弦中沒有 E，因此無大/小性格；C11 的三音理論上**保留**（只是常省略以避免 E-F 半音衝突），而且 C11 必須有七音（Bb）和九音（D），是延伸和弦體系的一部分。
3. **有沒有三音** — Cadd9（C-E-G-D）保留了三音 E，有明確的大調性格，D 是額外「添加」的色彩音；Csus2（C-D-G）沒有三音 E，D 是用來**取代**三音的，和弦沒有大/小性格，聽感更空靈。
4. **Dsus4 → D**（G→F# 解決）— sus4 的四度音（Dsus4 中的 G）下行半音或全音到三音（D 大三和弦的 F#），三音「歸位」，懸掛感消失。Dsus4 = D-G-A → D = D-F#-A，G 下行到 F#。
5. **因為缺少三音（Third）** — 三音是決定和弦大/小性格的關鍵音（大三度 = 大和弦，小三度 = 小和弦）。Sus 和弦用四度或二度取代了三音，沒有了三音的「定性」作用，和弦聽起來既非大調也非小調，呈現開放、懸而未決的感覺。
6. **Aadd9 = A-C#-E-B** — add9 公式：三和弦 + 九音（無七音）。A 大三和弦 = A-C#-E，加上九音 B。**A9 = A-C#-E-G-B**，多了七音 G（小七度）。差別和 Cadd9 vs. C9 一樣：有沒有七音。Aadd9 聽感清新乾淨，A9 帶有屬七的張力色彩。
7. **因為每一步都只有一個音在移動，製造出波動感** — Csus4(C-F-G) → C(C-E-G)：F 下行半音到 E；C(C-E-G) → Csus2(C-D-G)：E 下行全音到 D；Csus2 → C：D 上行全音到 E。整個進行就像三音在 D-E-F 之間來回擺動，根音和五音完全不動，聽感像呼吸一般自然。
8. **Am（A 小三和弦）** — Csus4 = C-F-G，Am = A-C-E。F 下行到 E（半音），G 上行到 A（全音），C 保留為共同音。Am 是 C 的關係小調主和弦，有穩定感但帶憂鬱，懸掛感消失的同時情緒更柔和。
9. **因為 add11 的十一音（F）和三音（E）只相距半音，會產生衝突感** — Cadd11 = C-E-G-F，E 和 F 之間是小二度（1 半音），同時演奏有摩擦。這和屬十一和弦省略三音的原因相同。使用 add11 時需要注意聲位安排，讓 E 和 F 分散在不同八度以減少衝突。
10. **是的，Csus 和 Csus4 是同一個和弦** — 在大多數記譜法和流行音樂實踐中，「sus」不加數字預設為 sus4（因為 sus4 更常見）。如果想指 sus2，必須明確寫出「sus2」。不過少數老式記譜可能有不同慣例，遇到時看上下文判斷。

</details>
