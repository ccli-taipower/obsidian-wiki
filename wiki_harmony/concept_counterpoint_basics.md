# 對位法基礎（Counterpoint Basics）

和聲學告訴我們「這一刻，這幾個音組成什麼和弦」；對位法則問「每條旋律線如何獨立地往前走」。對鋼琴演奏而言，認識對位法不只是樂理知識，更直接決定**雙手如何獨立配置指法**。

---

## 1. 什麼是對位法

**對位法（Counterpoint）** = 多條獨立旋律線同時響起的寫作技術。

字源來自拉丁文 *punctus contra punctum*（point against point）——音符對音符。核心概念：**每一個聲部都是旋律，不是伴奏**。

與之對比的是**主調音樂（Homophony）**：
- **Homophony**：一條主旋律 + 伴奏（伴奏服從和弦節奏，沒有獨立旋律邏輯）
- **Counterpoint**：每一條線都有自己的旋律走向、高低起伏、節奏呼吸

**指法意義**：在主調音樂裡，右手彈旋律、左手跟和弦節奏走；在對位音樂裡，左右兩手**各自負責一條或多條完整旋律線**，指法策略完全不同。

### 典型範例：Bach Two-Part Inventions

Bach 的 15 首二聲部創意曲（Inventions）是對位法最清晰的示範：
- 右手一條旋律線
- 左手一條旋律線
- 兩條線同等重要，共同構成音樂
- 若右手彈「主題」，左手彈的不是伴奏——而是**同一主題的另一次出現**（模仿）

## 2. 對位 vs. 和聲的差異

這兩種思維方式並不互斥，但視角不同，對指法的影響截然不同：

| 維度 | 和聲思維（Harmonic） | 對位思維（Contrapuntal） |
|------|---------------------|------------------------|
| **時間軸** | 垂直（vertical）：某一拍這幾個音是什麼和弦？ | 水平（horizontal）：每條線獨立往前走的邏輯 |
| **聲部角色** | 主旋律 + 伴奏支撐 | 每聲部均等，都是旋律 |
| **和弦分析** | 直接標和弦符號（Dm7, G7…） | 和弦是多線交叉的結果，不是起點 |
| **指法策略** | 右手 lead、左手負責和弦節奏型 | 兩手各自獨立指法，互不依附 |
| **典型曲例** | 蕭邦夜曲（右手歌唱，左手分解和弦） | Bach Inventions、Fugues |

**重要澄清**：Bach 的對位法**同時也是完美的和聲**——兩條線交叉出的每個垂直斷面都有和聲邏輯。對位與和聲是同一音樂的兩種視角，不是兩件不同的事。

## 3. 聲部運動類型（Types of Motion）

兩個聲部之間的運動方向，直接影響**雙手如何協調**。這是從對位法連結到指法最直接的橋梁。

| 運動類型 | 定義 | 指法影響 | Bach 常見場合 |
|---------|------|---------|--------------|
| **同向運動（Similar Motion）** | 兩聲部朝同一方向移動，但間距不同 | 雙手同時移位，協調相對容易；音色容易均勻 | 接近終止式的收攏 |
| **反向運動（Contrary Motion）** | 兩聲部朝相反方向移動 | 雙手呈「鏡像」關係，一手上行時另一手下行；各自獨立，聲部最為清晰 | Invention 主題展開、fugue 答題 |
| **斜向運動（Oblique Motion）** | 一聲部移動，另一聲部保持同音 | 靜止聲部 = **anchor finger**（錨定指），可以持音或準備下一步移動；動態聲部獨立指法 | 保留音（held tone）寫法 |
| **平行運動（Parallel Motion）** | 兩聲部同方向、保持固定音程 | 平行三度/六度：美麗且常見，可用相同指形平移；平行五度/八度：對位禁忌，實際上也很少出現 | 三度/六度平行段落 |

### 反向運動的指法優勢

反向運動（Contrary Motion）是對位法中最有名的手法，也是鋼琴技術的福音：

```
RH: C - D - E - F - G（上行）
LH: C - B - A - G - F（下行）
```

兩手從中間向外展開（或從外向中間合攏），**拇指恰好都在轉折點附近**，自然對稱。C 大調音階的 Hanon 練習就是這個原理：RH/LH 做反向運動，每個手都完整練到自己的換拇指位置。

## 4. 對位織體與指法策略

這是對位法影響指法最核心的部分。聲部數量決定了**每隻手要負責多少條線**，進而決定指法策略的複雜度。

### 4.1 二聲部（Two-Part）

**典型**：Bach Inventions

- 每手一條線 → 每手**獨立指法**
- DP 指法引擎可對兩手分別最佳化，再檢查碰撞
- 注意：兩手都需要**旋律性指法**（musical fingering），而非伴奏型指法

**指法原則**：
1. 每手按自己的音程邏輯選指，不因另一手影響
2. 換拇指（thumb-under）與跨指（over）皆依本手旋律走向決定
3. 音符長度（值）影響是否需要 finger substitution

### 4.2 三聲部（Three-Part）

**典型**：Bach Sinfonias（三聲部創意曲）、三聲部賦格

- 一隻手必須**同時負責兩條線**（通常是右手：高音 + 中音）
- 拇指常成為**一條線的錨點**，手指 2-5 彈另一條線
- 聲部分配（voice allocation）成為關鍵

**常見分配方式**：

```
三聲部：Soprano (S) + Alto (A) + Bass (B)
→ RH: S + A（兩線）
→ LH: B（一線）

或，當中音線音域偏低時：
→ RH: S（一線）
→ LH: A + B（兩線）
```

**難點**：同一隻手的兩條線有時需要**不同的觸鍵力度或音色**（例如高音線需要突出，中音線需要退後）。純指法之外還涉及**獨立控制（finger independence）**。

參見：[../wiki_piano/concept_finger_independence.md](../wiki_piano/concept_finger_independence.md)

### 4.3 四聲部（Four-Part）

**典型**：Bach 四聲部合唱配置（Chorales）、四聲部賦格

- 標準分配：SATB → RH: S+A，LH: T+B（各兩線）
- 但**聲部交叉（voice crossing）** 可能迫使重新分配

**聲部交叉問題**：

```
正常位置：
RH: E4 (S) - C4 (A)
LH: G3 (T) - E3 (B)

聲部交叉後：
Alto 下行到 B3，低於 Tenor 的 C4
→ 此刻 Alto 可能需要由 LH 彈，或 RH 用拇指越過去
```

關於聲部分配與越線問題，參見：[../wiki_piano/concept_cross_staff_voice_boundary.md](../wiki_piano/concept_cross_staff_voice_boundary.md)

與：[../wiki_piano/concept_hand_distribution.md](../wiki_piano/concept_hand_distribution.md)

### 4.4 持音換指（Finger Substitution in Counterpoint）

對位寫作中，**一個聲部持音、另一聲部在移動**的情況極為常見。

```
RH:   G4 ─────────────── G4（持音）
         \
         其他聲部移動中
```

持音期間，若持音音符上的手指需要讓出去彈其他音，就必須做 **finger substitution（同音換指）**：靜悄悄換一根手指繼續壓著同一個琴鍵。

詳見：[../wiki_piano/concept_finger_substitution.md](../wiki_piano/concept_finger_substitution.md)

## 5. 聲部識別對指法引擎的影響

鋼琴指法 DP 引擎若能識別對位結構，可以做到更精準的最佳化：

### 5.1 聲部歸屬（Voice Assignment）

原始 MIDI/樂譜資料是一堆音符時間點；指法引擎需要先**識別哪些音屬於哪條聲部線**，才能決定哪些音應該交給哪隻手。

錯誤的聲部歸屬 → 指法方案不可能優雅（例如把 Soprano 的音分給左手，导致手交叉）。

### 5.2 模仿識別（Imitation Recognition）

對位法中，最常見的手法是**模仿（Imitation）**：一個聲部演奏某個動機，另一個聲部稍後在另一個音高上演奏同樣的動機。

```
RH（第 1 小節）：C - D - E - F（主題）
LH（第 2 小節）：G - A - B - C（同主題，移高五度）
```

**指法引擎應用**：若識別到模仿結構，兩次出現可使用**相同的指法 pattern**（根據音域調整後），減少重新計算成本，也讓演奏者習得後可自動遷移。

### 5.3 模進識別（Sequence Recognition）

**序進（Sequence）** = 同一動機在**不同音高反覆出現**（步進式位移）。

```
D - E - F# - G（動機 1）
C - D - E  - F（動機 2，下移一度）
B - C - D  - E（動機 3，再下移一度）
```

指法引擎識別到序進後，可系統性地將同一 fingering pattern **平移**（加減相應的半音數），而非對每個動機重新最佳化。

## 6. 實例：Bach Invention No. 1（C 大調）

Bach 第一號創意曲是學習二聲部對位指法的最佳起點。

### 6.1 主題（Subject）

```
主題（RH 開頭）：
C - D - E - F - E - D | C - E - G - C（高八度）| ...

指法（建議）：
1 - 2 - 3 - 4 - 3 - 2 | 1 - 2 - 4 - 5 |
```

主題以級進（stepwise）起頭，拇指放在 C，然後 1-2-3-4 上行——經典旋律指法。

### 6.2 模仿出現在左手

```
LH（第 2 小節起）：
C - D - E - F - E - D | C - E - G - C（比 RH 低八度）| ...

指法（建議）：
5 - 4 - 3 - 2 - 3 - 4 | 5 - 3 - 2 - 1 |
```

左手的**指法 pattern 是右手的鏡像**（LH 從小指開始下行到拇指，就像 RH 從拇指上行到五指）。這是反向指法對稱（fingering symmetry）在對位中的具體體現。

### 6.3 聲部導進決定換拇指位置

主題的級進音型決定了拇指換指（thumb-under）的位置：

```
RH 上行超過五度時：
... E - F - G - A（繼續上行）
需要拇指從 F 或 G 下潛，延伸音域
→ 此換指點由**旋律線的音域需求**決定，而非和弦需求
```

這是對位音樂指法與和弦音樂指法的本質差異：旋律型指法看**音的走向**，和弦型指法看**音的位置**。

## 7. 對位法的常見指法陷阱

### 陷阱 A：把對位線當伴奏彈

最常見的錯誤：認出和弦後，用「伴奏邏輯」安排指法（例如拇指固定在根音上），忽略了這條線自己有旋律邏輯。

**解法**：先單獨練每聲部，確認每條線都有流暢的旋律性指法後，再合奏。

### 陷阱 B：忽略聲部的持續時值

對位中，一個音可能需要持續 2-4 拍，同時另一條線在動。若手指被持音佔據，下一個音怎麼準備？

**解法**：提前識別需要 finger substitution 或 voice redistribution 的位置。

### 陷阱 C：兩手速度不對稱

對位音樂要求兩手**節奏獨立但時值精準**（例如切分音、二對三等），若其中一手習慣「跟」另一手，容易出現節奏拖拉。

**解法**：慢練時兩手分別打拍子，確認每手的節奏點獨立。

## 8. 小測驗

試著回答以下問題（答案在下方）：

1. 右手彈 C→D→E（上行），左手同時彈 G→F→E（下行），這兩個聲部之間是什麼運動類型？
2. 在對位法中，平行三度和平行六度是被允許的，但平行五度和平行八度是禁忌。為什麼後者有問題？
3. 右手在彈一個二分音符 G4（持音），同時右手還要彈另一條聲部的 E4→F4。這時候可能需要用什麼技術？
4. 對位音樂（如 Bach Inventions）和主調音樂（如 Chopin Nocturne）的指法策略有什麼根本差異？
5. Bach Invention No. 1 的主題先由右手演奏，左手隨後在低八度模仿。左手的指法 pattern 和右手是什麼關係？為什麼？
6. 三聲部對位（如 Bach Sinfonias）中，一隻手必須同時負責兩條旋律線。此時拇指（finger 1）通常扮演什麼特殊角色？
7. 序進（Sequence）是指同一動機在不同音高反覆出現。對指法引擎來說，識別出序進有什麼好處？
8. 「把對位線當伴奏彈」是最常見的指法陷阱。具體來說，這個錯誤的表現是什麼？正確的練習方法是什麼？
9. 右手上行彈 C-D-E-F-G（五度音程），同時左手下行彈 C-B-A-G-F。這是對位中的反向運動。從鋼琴技術角度，為什麼反向運動對雙手協調特別有利？
10. 在四聲部對位中（如 Bach Chorales），標準的聲部分配是 RH 負責哪兩條聲部、LH 負責哪兩條？什麼情況下需要重新分配？

<details>
<summary>答案</summary>

1. **反向運動（Contrary Motion）** — 兩個聲部朝相反方向移動：右手上行，左手下行。這是對位法中最重要的手法，讓兩條聲部線保持最大的獨立性。對鋼琴指法而言，雙手呈「鏡像」關係，各自獨立，不會互相干擾。
2. **因為平行五度/八度讓兩個聲部失去獨立性** — 完全五度和八度本身就有很強的「融合」效果（協和度最高），如果兩個聲部始終保持這個距離同向移動，聽起來就像一個聲部被加倍（doubling），而非兩條獨立的旋律線在對話。平行三度/六度則不會有這個問題，因為它們的聲部獨立性較好。
3. **換指替代（Finger Substitution / 同音換指）** — G4 先用一根手指（如 3 指）按住，在持音期間悄悄換成另一根手指（如 2 指）繼續壓著同一個琴鍵，把 3 指解放出去彈 E4。這是對位音樂中「一個聲部持音、另一聲部移動」的常見技術。
4. **對位音樂中左右手各負責一條（或多條）獨立旋律線，兩手都需要旋律性指法；主調音樂中右手彈旋律、左手跟和弦節奏走** — 在主調音樂中，右手用旋律指法（連貫優先）、左手用和弦/伴奏指法（手型為主）；在對位音樂中，兩手的指法**都必須按旋律邏輯選擇**，各自獨立計算，不能把任何一條聲部當伴奏處理。
5. **左手的指法 pattern 是右手的鏡像（mirror）** — 右手從拇指（1）上行到小指（5）：1-2-3-4…；左手從小指（5）下行到拇指（1）：5-4-3-2…。因為模仿（imitation）結構相同，只是在不同音域，兩手的指法可以對稱映射，練習時學會一隻手的 pattern 就能遷移到另一隻手。
6. **拇指（finger 1）常成為一條聲部線的錨點** — 當一隻手同時負責兩條線時，拇指固定彈其中一條線（通常是較低的那條），手指 2-5 負責另一條線。拇指的獨立性最強，適合作為分界點。
7. **指法引擎可以將同一 fingering pattern 平移（根據半音數調整），而非對每個動機重新計算最佳化** — 這大幅減少計算量，也讓演奏者練會第一次出現的動機後，後續重複能自動「套用」相同的手感，提高練習效率。
8. **錯誤表現：看到和弦結構後，用「拇指固定在根音」的伴奏邏輯安排指法，忽略該聲部自己的旋律走向** — 例如左手的對位線有上行級進，卻因為「這裡是 Am 和弦」就把拇指放在 A 不動。正確做法：先單獨練每條聲部，確認每條線都有流暢的旋律性指法（按音的走向選指），然後再合奏。
9. **因為兩手從中間向外展開（或從外向中間合攏），拇指恰好都在轉折點附近，自然對稱** — 反向運動讓每隻手的換拇指位置（thumb-under）各自獨立，不會互相牽制。此外，雙手朝相反方向移動不存在手掌交疊的風險，DP 引擎可以對兩手分別獨立最佳化。
10. **RH 負責 Soprano + Alto，LH 負責 Tenor + Bass** — 這是標準的 SATB 分配。需要重新分配的情況是**聲部交叉（voice crossing）**：例如 Alto 的音下行到低於 Tenor 的音域時，Alto 可能需要暫時交給 LH 彈，或 RH 用拇指越過去。聲部交叉是對位音樂中常見的指法難點。

</details>
