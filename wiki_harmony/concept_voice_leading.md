# 聲部導進（Voice Leading）

你已經知道和弦是什麼、它們有什麼功能、怎麼串成進行——但和弦與和弦「之間」發生了什麼事？每個音從舊和弦「走到」新和弦的路徑，就是**聲部導進（Voice Leading）**。

同樣的 G7 → C，可以用很多種方式把每個音安排給不同手指——有的走法平滑、手指幾乎不需要移動；有的走法生硬、手要跳來跳去。聲部導進好不好，直接決定了這段音樂好不好彈。

---

## 1. 什麼是聲部導進

**聲部導進 = 和弦轉換時，每個音如何移動到下一個和弦的對應音。**

以四聲部和聲為例（高音 Soprano、次高音 Alto、次中音 Tenor、低音 Bass），每個聲部都是一條**橫向旋律線（horizontal melodic line）**。好的聲部導進讓每條線獨立、流暢，整體聽起來平滑自然。

換句話說：
- **垂直視角（vertical）** = 和聲：某一拍上，這幾個音構成什麼和弦？
- **水平視角（horizontal）** = 聲部導進：每個聲部從這個和弦到下個和弦「走了多遠」？

**壞的聲部導進**：音跳來跳去、聲部互相交叉、出現平行問題——聽起來粗糙，彈起來笨拙。**好的聲部導進**：每個聲部移動盡量小、平滑——聽起來流動自然，手指也能跟上。

---

## 2. 三大原則

### 2-1 共同音保留（Common Tone Retention）

**同一個音出現在兩個和弦裡，就讓它留在原地。**

例：C 大調，I → vi（C major → A minor）

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I  (C major):  C–E–G   ●   ●   ●
vi (A minor):  A–C–E   ●   ●       ●
                        ↑   ↑
                    共同音 C 和 E：留在原位
```

C 和 E 是共同音——兩個和弦都有它們。指法結論：**按著這兩個音的手指不要動**，只有 G → A 這個音需要移動。

### 2-2 級進移動（Stepwise Motion）

**非共同音應盡量走半音（semitone）或全音（whole tone），即二度（2nd）。**

級進（stepwise motion）= 小步走。相對的，**跳進（leap）**= 超過二度的大跳。

原則：能用級進就不要跳進。

為什麼？兩個理由：
1. **聽感**：級進的旋律線平滑流動，跳進會打斷流動感。
2. **指法**：相鄰音符對應相鄰手指，手不需要大幅移位。

### 2-3 反向運動（Contrary Motion）

**外聲部（soprano + bass）應盡量朝相反方向移動。**

- 高音往上 → 低音往下；高音往下 → 低音往上。
- 這讓高低兩條聲部保持獨立性，不會「擠在一起」或「越來越遠」。

鋼琴的實際對應：
- **右手最高音 ≈ soprano**
- **左手最低音 ≈ bass**

反向運動意味著雙手的走向恰好相反，兩手各自有清楚的移動方向可以依循，相互不干擾。

## 3. 平行運動的禁忌（Parallel Motion Rules）

古典和聲（尤其四部聖詠風格）有兩個嚴格禁忌：

### 3-1 平行五度（Parallel 5ths）

兩個聲部相距完全五度（Perfect 5th, P5），然後同方向移動，還是相距 P5。

```
例（不好）：
Tenor:  G ──→ A
Bass:   C ──→ D    （G–C 是 P4，反過來看 C–G 是 P5；A–D 也是 P4，亦即 D–A 是 P5）
```

**為什麼禁止**：平行五度讓兩個聲部「黏在一起」移動，失去各自的獨立性——聽起來像一個聲部，而不是兩個對話的旋律線。

### 3-2 平行八度（Parallel Octaves）

兩個聲部同向移動且始終相差一個八度。問題同上：聲部獨立性消失，相當於只有一個聲部加倍，沒有真正的多聲部效果。

### 3-3 現代音樂的放寬

流行、爵士、搖滾對平行五度 / 八度的限制幾乎完全取消——平行五度在吉他 power chord 是招牌音色，爵士鋼琴的平行移調（parallel planing）刻意製造色彩。

**重點**：禁忌是針對**古典調性和聲風格**的美學判斷，不是物理定律。理解規則，再決定什麼時候打破它。

## 4. Voice Leading 與指法的關係

這是本頁的核心。鋼琴 DP 指法引擎（dynamic programming fingering engine）在計算最佳指法時，考慮兩大成本：
- **過渡成本（transition cost）**：從前一音到下一音，手指需要移動多遠、換幾根指頭。
- **手位移動成本（position-change cost）**：手的整體位置（hand position）發生了偏移。

聲部導進的三大原則，剛好直接對應這兩種成本的高低：

### 4-1 共同音 = 手指不動（transition cost ≈ 0）

共同音保留在原位時，按住它的手指**完全不移動**——DP 引擎的過渡成本為零。

更重要的是，共同音變成**錨點（anchor finger）**：其他手指圍著它重新分配。舉例：如果中指（finger 3）按住共同音，食指（2）和無名指（4）可以自由移到鄰近的音，整個手的基本位置不需要改變。

> **指法原則**：辨識共同音，優先讓同一根手指維持不動，以此為支點排列其他手指。

### 4-2 級進 = 相鄰手指接力（small transition cost）

二度移動對應鄰指（adjacent fingers）的自然接棒：1→2、2→3、3→4、4→5，或反向。

DP 引擎對「小音程卻用不相鄰手指」（例如跨指按相鄰兩個白鍵）會施加懲罰，因為那會製造不必要的手指張開。級進的聲部導進天然引導出最省力的手指序列。

> **指法原則**：看到二度移動，優先選鄰指；不要在相鄰的兩個音之間插入手位跳躍。

### 4-3 跳進 = 手位移動（high position-change cost）

三度以上的跳進，手指間距可能超出一個手掌的舒適範圍，需要整體手位偏移（position shift）或跨手指。DP 引擎的手位移動成本大幅上升。

特別是超過五度的大跳，往往需要：
- 完整的手位移動（整隻手平移到新位置）
- 或大拇指 / 小指的大幅伸展

> **指法原則**：大跳不可避免時，盡早規劃好手位目標；若大跳不是旋律需要，重新思考聲部配置（例如是否能八度內安排）。

### 4-4 反向運動 = 雙手獨立優化（independent optimization）

當 RH（right hand, 右手）和 LH（left hand, 左手）往相反方向移動，兩手的最佳指法可以**各自獨立計算**，互不牽制。

相反地，若兩手同向移動到相鄰音域（例如都往中央 C 靠攏），會有手掌交疊的風險，DP 引擎需要額外考慮手指間的碰撞避免。

> **指法原則**：反向運動讓雙手在聲部導進上獲得最大自由度，是鋼琴編曲時應積極追求的配置。

## 5. 範例：G7 → C（V7 → I）的聲部導進與指法

V7 → I 是和聲語言最核心的終止式（見 [concept_cadence](concept_cadence.md)）。以 C 大調 G7 → C 為例，逐聲部分析。

### 5-1 和弦組成音

| 和弦 | 組成音 | 
|------|--------|
| G7   | G–B–D–F |
| C    | C–E–G  |

### 5-2 聲部走向

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

G7 聲部：  G   B   D   F
                ↓   ↓   ↓   ↓
C  聲部：  G   -   E   C   (G 留、D 消、B→C、F→E)

具體導進：
  G（根音）→ G   ← 共同音，留在原位  ★
  B（三音）→ C   ← 導音（leading tone）半音上行 +½
  D（五音）→ C   ← 一度下行 -1（或省略，由其他聲部補 C）
  F（七音）→ E   ← 半音下行 -½  ★ 七音解決
```

**關鍵聲部導進**：
- **B → C**（導音解決 / leading tone resolution）：半音上行，是 V7 → I 最強的引力。
- **F → E**（七音解決 / 7th resolution）：半音下行，固定方向不可違背。
- **G → G**：根音的共同音，保留。

### 5-3 雙手指法建議（C 大調，中間八度）

**右手（RH）— 高音聲部 + 中聲部**

```
        G7              →    C

位置：  G   B   D             G   C   E
手指：  1   3   5             1   2   4
        └───────────────────→─────────┘
        （B→C：3指→2指，半音上行，鄰指接力）
        （D→C：5指→ 手縮回，5 可維持或換 4）
```

實際可行指法：G7: 1(G) 3(B) 5(D) → C: 1(G) 2(C) 4(E)
- 大拇指（1）按 G，不動（共同音）
- 中指（3）B 上行半音到 C，改由食指（2）接——過渡自然
- 無名指（4）落在 E

**左手（LH）— 低音 + 支撐聲部**

```
        G7              →    C

位置：  G           F        C           E
手指：  5           2        5           2
        └───────────────────→─────────┘
        （F→E：2指→2指，半音下行，同指滑）
        （G→C：5指→5指，下行四度，手位移動）
```

實際可行指法：G7: 5(G) 2(F) → C: 5(C) 2(E)
- 小指（5）G 往下跳進四度到 C——這是唯一的大跳，但因為是 bass 聲部，手位移動可接受
- 食指（2）F 下行半音到 E，同指保持（或換 3 指）

> **小結**：右手的 B→C（導音）和 F→E（七音）全是半音，鄰指自然接棒；左手唯一的跳進在 bass，相對好處理。這正是 G7→C 在鋼琴上不難彈的原因——聲部導進本身就很順手。

## 6. 常見進行的 Voice Leading 模式

### 6-1 V → I：導音解決

| 聲部 | V（G） | I（C） | 移動距離 | 指法特性 |
|------|--------|--------|---------|---------|
| Soprano | B（導音） | C | +½（半音上） | 鄰指，最流暢 |
| Alto | D（五音） | C or E | -1 or +1 | 小跳，可鄰指 |
| Tenor | F（七音） | E | -½（半音下） | 鄰指，固定方向 |
| Bass | G（根音） | C | -P5 or +P4 | 大跳，LH 手位移 |

**指法要點**：soprano / tenor 的半音移動讓 RH 輕鬆搞定；bass 的大跳靠 LH 整體移位吸收。

### 6-2 IV → V：無共同音，靠級進

C 大調：F → G

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

IV (F): F–A–C
V  (G): G–B–D

聲部走向：
  F → G   (+1，全音上行)
  A → B   (+1，全音上行)
  C → D   (+1，全音上行)
```

F 和 G 沒有共同音，但全部聲部都是全音上行——**同向平行移動（parallel motion）**，且是同樣距離，技術上接近「平行八度」的問題。

古典四部聖詠的解法：讓其中某個聲部往下走（反向或斜向）以破壞完全平行。但**鋼琴伴奏**往往直接整體上移——流行音樂中 IV → V 的「推進感」正是來自這個整體上行。

**指法**：IV 和 V 都在白鍵，手位整體上移一個全音。RH 可以維持相同指型（同一個 3-finger chord shape）平移，成本低。

### 6-3 ii → V → I：爵士必備的三步解決

C 大調：Dm7 → G7 → C（maj7）

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

ii7 (Dm7):   D–F–A–C
V7  (G7):    G–B–D–F
Imaj7 (Cmaj7): C–E–G–B

聲部導進（選一組聲部配置）：
  D → D → C   （根音到五音，再到根音：共同音 D，再解決）
  F → F → E   （共同音 F，再半音下行到 E — 七音解決！）
  A → G → G   （全音下行到 G，G 保留為共同音）
  C → B → B   （半音下行，B 保留）
```

**這個進行如此平滑的秘密**：
1. Dm7 → G7：F 是共同音（Dm7 的三音 = G7 的七音）★
2. G7 → Cmaj7：F→E（七音解決）、B→B（導音成為 maj7）★★

爵士鋼琴的 "shell voicing"（只彈三音 + 七音）正是利用了這兩個共同音 / 半音解決，左手幾乎不動，右手只在每個和弦間微調。

```
LH Shell Voicing（左手）：

Dm7:  F–C    （三音 + 七音）
      ↓   ↓
G7:   F–B    （F 共同音留；C→B 半音下行）
      ↓   ↓
Cmaj7: E–B   （F→E 半音下行；B 共同音留）

RH：自由加旋律或上方音色
```

這是爵士指法高效的核心：用聲部導進讓 LH 幾乎不動，節省出來的精力全部交給 RH 即興。

## 7. 整合：Voice Leading 決策流程

在安排指法或編寫鋼琴聲部之前，依序問以下問題：

```
和弦 A → 和弦 B

① 有共同音嗎？
   有 → 找出是哪個音，安排同一手指保持按住
   沒有 → 繼續往下

② 非共同音的移動距離？
   二度（半音 / 全音）→ 優先用鄰指接棒
   三～四度 → 可能需要跨指或小幅手位移動
   五度以上 → 規劃完整手位移動，或調整聲部配置

③ 雙手移動方向是否相反？
   相反（contrary motion）→ 兩手各自獨立優化指法
   同向 → 注意手掌交疊可能性，提前規劃

④ 有平行五度 / 八度？（古典風格才需要檢查）
   有 → 調整其中一個聲部的移動方向
```

## 8. 下一步

聲部導進處理的是和弦間的**橫向連接**——每個音如何移動到下一個音。當你把多條這樣的線同時疊起來、讓它們相互獨立又彼此呼應，就進入了**對位法（Counterpoint）**的領域：[concept_counterpoint_basics](concept_counterpoint_basics.md)。

此外，聲部導進的考量會因為**織體類型（Texture）**不同而大幅改變——根音位置的柱式和弦（block chords）、分散和弦（arpeggios）、和旋律+伴奏的層次安排，各有不同的指法策略：[concept_texture](concept_texture.md)。

對於 V7 → I 終止式更完整的和聲脈絡，見 [concept_cadence](concept_cadence.md)；ii–V–I 在不同調上的轉換應用，見 [concept_modulation](concept_modulation.md)。

---

*聲部導進的藝術，就是讓每個音都走最短的路回到新和弦——手指跟著聲部走，自然找到最省力的路徑。*
