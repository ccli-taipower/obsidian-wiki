## 變化和弦（Concept 16）

1. 在 D 小調中，拿坡里和弦（♭II）是什麼？寫出原位和第一轉位（N6）的組成音與最低音。

2. 三種增六和弦（義/法/德）的共同音程是什麼？它由哪兩個音構成（以 A 小調為例）？這個音程解決時往哪個方向移動？

3. 以 G 小調為例，寫出法國增六和弦（Fr+6）的組成音。它和義大利增六比，多了哪一個音？

4. 德國增六和弦（Ger+6）為什麼不直接解決到 V，而要先經過 I6/4？以 C 調為例說明。

5. 皮卡第三度（Picardy third）改變了最後和弦的哪個音？以 G 小調為例，最後和弦從什麼變成什麼？

6. 拿坡里和弦和增六和弦在功能上的共同點是什麼？它們分別用什麼方式「加強」這個功能？

7. 在 C 小調中，寫出完整進行：i → N6 → V7 → I（皮卡第三度）的具體和弦與組成音。

8. 增六和弦的命名中，「義大利」最精簡只有 3 個音，「法國」加了什麼音，「德國」加了什麼音？用音級（scale degree）回答。

## 三全音代理（Concept 17）

9. C7 的三全音代理是什麼和弦？寫出兩者的三音和七音，驗證它們共享同一組三全音。

10. 在 G 大調中，ii–V–I 的原始進行是 Am7 → D7 → Gmaj7。對 D7 做三全音代理後，進行變成什麼？低音線如何變化？

11. 三全音代理的低音走半音下行（♭II → I），傳統 V7 的低音走下行五度（V → I）。哪一種聽感更「滑順」？哪一種更「強勢」？

12. B♭7 是哪個屬七和弦的三全音代理？它可以代替那個和弦解決到哪裡？

13. 為什麼三全音代理只適用於屬七和弦，而不適用於大七或小七和弦？

14. 在 C 大調中，連續三全音代理鏈：E7 → E♭7 → D7 → D♭7 → Cmaj7。其中哪些是原始副屬和弦、哪些是三全音代理？每個的目標和弦是什麼？

15. 為什麼古典的德國增六和弦（Ger+6 = A♭-C-E♭-F#）在爵士理論中被重新理解為三全音代理？它等音於什麼屬七和弦？

## 非功能和聲（Concept 18）

16. 平行和弦移動（planing）有兩種：全音平行和半音平行。以 Cmaj7 為起點，分別寫出全音平行和半音平行的接下來兩個和弦。

17. Dorian 調式循環（如 Dm7 ↔ Em7）為什麼被歸類為非功能和聲？它缺少功能和聲的哪個關鍵要素？

18. 大三度循環（如 C → E → A♭ → C）把八度分成幾等分？小三度循環呢？各自的循環長度是幾個和弦？

19. 非功能和聲的四個辨認跡象中，根音移動的特徵是什麼？（和功能和聲的根音移動有什麼不同？）

20. 持續低音（pedal point）手法中，低音和上方和弦各扮演什麼角色？舉一個電影配樂的使用場景。

21. Lydian 調式被用來營造「奇幻飄浮」的感覺。它的哪個特徵音造成了這種效果？為什麼比 Ionian 更「開放」？

22. 功能和聲和非功能和聲可以在同一首曲子裡共存。舉一個混合使用的例子，說明各用在什麼段落。

## 和弦音階對應（Concept 19）

23. C 大調 I 級（Cmaj7）對應 Ionian 音階，它的避免音是什麼？為什麼這個音聽起來刺耳？

24. C 大調的七個順階七和弦中，哪兩個調式沒有避免音？為什麼它們在即興中最「自由」？

25. 屬七和弦可搭配多種音階。Mixolydian 和 Altered 分別代表什麼張力程度？各自適合什麼場景？

26. Altered Scale（變化音階）的公式是 1-♭2-#2-3-♭5-#5-♭7。它衍生自哪個音階的第幾級？以 G Altered 為例，它的母音階是什麼？

27. 在 ii–V–I 進行（Dm7 → G7 → Cmaj7）中，如果三個和弦都用最基本的對應音階，分別是什麼？這三條音階其實都是同一組音嗎？

28. V7 要解決到小調主和弦（如 G7 → Cm）時，最常用什麼音階？這條音階有什麼特殊的聽感？

29. Lydian ♭7 音階的公式是什麼？它最常用在什麼類型的和弦上？

30. 即興演奏時，如果完全不確定該用什麼音階，最安全的策略是什麼？為什麼？

### 變化和弦

1. **♭II = E♭ 大三和弦（E♭-G-B♭）** — 原位最低音 E♭；第一轉位 N6 = G-B♭-E♭，最低音 G（三音）。N6 更常用，因為低音 G 可以半音下行到 V 級的根音 A。

2. **增六度音程，由 ♭6 和 #4 構成** — A 小調：♭6 = F，#4 = D#。F 和 D# 之間是增六度（10 半音）。解決時 F 半音下行到 E，D# 半音上行到 E，兩音向外擴張到八度 E-E（= 屬音）。

3. **Fr+6 = E♭-G-A-C#** — G 小調的 ♭6 = E♭，#4 = C#。法國增六比義大利增六（E♭-G-C#）多了**第 2 音 A**。（注意 A-E♭ 也是三全音，所以法國增六有兩組三全音。）

4. **為了避免平行五度** — Ger+6 in C = A♭-C-E♭-F#。如果直接到 V（G-B-D），E♭→D 和 A♭→G 會形成平行五度。先走 I6/4（G-C-E），E♭→E 和 A♭→G 避開了平行五度，再由 I6/4 解決到 V。

5. **升高最後和弦的三音（♭3 → ♮3）** — G 小調正常結尾：Gm（G-B♭-D）；皮卡第三度：**G 大三和弦（G-B♮-D）**。B♭ 升為 B♮，小調曲子以大三和弦的明亮感結束。

6. **都具有下屬功能（S），加強 → V 的動向** — 拿坡里用 ♭II 的半音低音（♭II6 的低音 → V 的根音 = 半音下行）加強引力；增六和弦用增六度音程的「外擴」解決（兩個音各走半音到屬音八度）加強引力。

7. **Cm → D♭/F → G7 → C** — i = Cm（C-E♭-G）；N6 = D♭/F（F-A♭-D♭）；V7 = G7（G-B-D-F）；I（皮卡第三度）= C 大三和弦（C-**E♮**-G）。低音線：C-F-G-C。

8. **義大利 = ♭6 + 1 + #4（3 音）；法國加了第 2 音（scale degree 2）；德國加了 ♭3 音（scale degree ♭3）** — 法國的 2 與 ♭6 形成第二組三全音；德國的 ♭3 讓整體等音於屬七和弦。

### 三全音代理

9. **C7 的三全音代理 = G♭7（= F#7）** — C7 的三音 = E，七音 = B♭；G♭7 的三音 = B♭，七音 = E（= F♭ 等音）。三音和七音互換，同一組三全音（E-B♭）。✓

10. **Am7 → A♭7 → Gmaj7；低音 A → A♭ → G = 半音下行** — 原始低音 A → D → G（含五度跳躍），代理後變成連續半音下行，聽感更「滑順」。

11. **半音下行（三全音代理）更「滑順」；下行五度（傳統 V7）更「強勢」** — 半音像「滑入」目標，優雅而含蓄；五度跳躍像「跳回家」，果斷而明確。

12. **B♭7 是 E7 的三全音代理** — E7 根音 E，E + 6 半音 = B♭。B♭7 可以代替 E7 解決到 **A**（或 Am）。

13. **因為只有屬七和弦的三音和七音恰好形成三全音（6 半音）** — 大七和弦（M3-m3-M3）的三音到七音是 P5+M3=大七度（11 半音），不是三全音；小七和弦（m3-M3-m3）是 P5+m3=小七度（10 半音），也不是三全音。只有屬七（M3-m3-m3）的三→七 = m3+m3 = 6 半音 = 三全音。

14. **E7 = V7/vi（原始），目標 Am；E♭7 = tritone sub of A7 = subV/ii，目標 Dm；D7 = V7/V（原始），目標 G；D♭7 = tritone sub of G7 = subV/I，目標 C** — 奇數位是原始副屬，偶數位是三全音代理，交替出現，低音半音下行：E-E♭-D-D♭-C。

15. **Ger+6（A♭-C-E♭-F#）等音拼寫為 A♭-C-E♭-G♭ = A♭7** — A♭7 是 D7 的三全音代理（A♭ + 6 半音 = D）。古典的 Ger+6 → V（A♭...F# 解決到 G-G）和爵士的 A♭7 → G 是同一個聲響，只是理論框架不同：古典稱「增六和弦」，爵士稱「三全音代理」。

### 非功能和聲

16. **全音平行：Cmaj7 → Dmaj7 → Emaj7；半音平行：Cmaj7 → D♭maj7 → Dmaj7** — 全音平行根音每次走全音（C-D-E），半音平行每次走半音（C-D♭-D）。兩者都是保持相同和弦品質（maj7）平移，不考慮調性歸屬。

17. **缺少 V → I 的解決動力** — Dm7 ↔ Em7 只是 D Dorian 的 i 和 ii 來回循環，沒有任何和弦扮演屬功能（D），不產生「回家」的引力。這是調式和聲的典型特徵：靠色彩和律動維持音樂，不靠功能解決。

18. **大三度循環分成 3 等分（3 個和弦一輪：C→E→A♭→C）；小三度循環分成 4 等分（4 個和弦一輪：C→E♭→G♭→A→C）** — 大三度 = 4 半音 × 3 = 12；小三度 = 3 半音 × 4 = 12。兩者都無法歸屬於任何單一調性。

19. **非功能和聲的根音移動以半音、全音、三度為主；功能和聲以四度/五度為主** — 功能和聲的核心動力（V→I, ii→V）都是根音下行五度或上行四度。非功能和聲避開這種移動，改用平移（半/全音）或對稱跳躍（三度），讓和弦之間沒有「解決」的方向感。

20. **低音提供穩定的「地面」，上方和弦自由移動製造色彩變化** — 例如恐怖電影中，持續低音 C 不動，上方交替 Cm7 和 D♭maj7，產生懸而未決的緊張感。低音的不動讓聽眾覺得「困在原地」，上方和弦的變化製造不安。

21. **#4（升四度）** — Ionian 的自然四度（P4）距三音只有半音，是避免音，會壓制和弦的明亮感。Lydian 把四度升高，#4 距三音變成全音，不再衝突，反而成為色彩音，產生「無重力」的飄浮感。

22. **例如流行歌：主歌用非功能的調式循環（Em7 ↔ Cmaj7 反覆），營造迷幻氛圍；副歌切換到功能和聲（ii → V → I），製造解決感和高潮** — 非功能段落像「漂浮」，功能段落像「降落」，對比產生戲劇效果。

### 和弦音階對應

23. **避免音是 F（自然四度）** — F 在 E（Cmaj7 的三音）上方半音（小二度），長時間停留在 F 上會和三音 E 產生強烈衝突，聽感像「壓住」和弦的大三度。F 不是不能彈，但只適合當經過音。

24. **ii 級 Dorian 和 IV 級 Lydian 沒有避免音** — Dorian 的所有非和弦音與和弦音之間都至少距全音，沒有半音衝突。Lydian 的 #4 反而是色彩音（不衝突）。所以這兩個調式即興時可以自由使用每一個音，不用「閃避」。

25. **Mixolydian = 最低張力（自然、放鬆），適合藍調/鄉村/一般解決；Altered = 最高張力（所有延伸音都變化），適合強烈解決前的最後推力（如 V7alt → Imaj7 的爵士終止）** — 中間還有 Lydian ♭7（中等張力）和 Diminished H-W（高張力，8 音對稱）。

26. **衍生自旋律小調的第 VII 級** — G Altered：G 上方的 Altered = A♭ 旋律小調的第 VII 級。A♭ 旋律小調 = A♭-B♭-C♭-D♭-E♭-F-G，從第 VII 音 G 開始讀 = G-A♭-B♭-C♭-D♭-E♭-F = G-♭2-#2(♭3)-3(♮)-♭5-#5-♭7。

27. **Dm7 → D Dorian（D-E-F-G-A-B-C）；G7 → G Mixolydian（G-A-B-C-D-E-F）；Cmaj7 → C Ionian（C-D-E-F-G-A-B）** — 是的，三條音階都是同一組音（C 大調的七個自然音），只是起始音不同。這就是順階和弦音階對應的本質：所有順階和弦共用母調的音群。

28. **Phrygian Dominant（弗里吉亞屬音階）：1-♭2-3-4-5-♭6-♭7** — 衍生自和聲小調的第 V 級。以 G7 → Cm 為例，G Phrygian Dominant = G-A♭-B-C-D-E♭-F，帶有西班牙/中東/佛朗明哥的異國風味，♭2（A♭）和 ♭6（E♭）是關鍵色彩音。

29. **1-2-3-#4-5-6-♭7；最常用在副屬和弦和三全音代理上** — 它是旋律小調的第 IV 級衍生音階。和 Mixolydian 比，唯一差別是 #4（而非 ♮4），避免了四度音和三音的半音衝突。例如 D7（V7/V in C）可用 D Lydian ♭7。

30. **彈和弦琶音（1-3-5-7）** — 和弦音永遠不會「錯」，因為它們就是和弦本身的骨架。在不確定音階時，用琶音加上經過音（半音或全音靠近和弦音）即可安全即興，不會產生避免音衝突。
