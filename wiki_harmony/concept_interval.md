# 音程（Interval）

音程是兩個音之間的距離（distance between two pitches）。它是和聲理論（harmony）的最小單位——所有和弦（chord）、音階（scale）、旋律（melody）都由音程堆疊而成。理解音程，等於拿到了讀懂和弦的鑰匙。

---

## 1. 半音與全音（Semitone & Whole Tone）

### 鍵盤的最小單位：半音（Semitone）

在鋼琴鍵盤上，**相鄰兩個鍵**（無論白鍵或黑鍵，只要中間沒有其他鍵）之間的距離，就是一個**半音（semitone，縮寫 st）**，也叫做**小二度**。

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
 ←→
 半音（C → C#）
```

- **C → C#**：中間沒有其他鍵，距離 = **1 半音**
- **E → F**：兩者相鄰（E 和 F 之間沒有黑鍵），距離 = **1 半音**
- **B → C**：同理，距離 = **1 半音**

### 全音（Whole Tone）

**兩個半音 = 一個全音（whole tone）**，也叫做**大二度**。

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
 ●           ●
 C → D = 全音（2 半音，中間跨過 C#）
```

- **C → D**：C → C# → D，共 2 半音 = **1 全音**
- **D → E**：D → D# → E，共 2 半音 = **1 全音**
- **F → G**：F → F# → G，共 2 半音 = **1 全音**

> 記憶口訣：**半音 = 緊鄰，全音 = 跳一格**（跨過一個黑鍵或白鍵）。

### 特殊白鍵相鄰：天然半音

有兩對白鍵之間沒有黑鍵分隔，它們本身就是半音：

| 位置 | 距離 |
|------|------|
| E → F | 1 半音（天然半音） |
| B → C | 1 半音（天然半音） |

這是初學者常混淆的地方：不是所有白鍵相鄰都是全音，**E-F 和 B-C 是例外**。

## 2. 音程度數（Interval Number）

### 什麼是「度數」？

**度數（interval number）**是計算兩個音之間包含多少個字母音名（letter name）。計算時，**起點和終點都要算進去**（inclusive counting）。

舉例：

```
C  D  E  F  G  A  B  C'
1  2  3  4  5  6  7  8
```

- **C → E**：C(1), D(2), E(3) → **三度（3rd）**
- **C → G**：C(1), D(2), E(3), F(4), G(5) → **五度（5th）**
- **C → C'（高八度）**：C(1)…C'(8) → **八度（8th / octave）**

> 重要：度數只計算「字母名稱的數量」，**不管半音數多少**。C → E 和 C → Eb 都是三度，但半音數不同（見下節「音程性質」）。

### 基本度數一覽（以 C 為根音）

| 度數 | 名稱（中） | 名稱（英） | 舉例（上行） |
|------|-----------|------------|-------------|
| 1 度 | 一度 / 同音 | Unison | C → C |
| 2 度 | 二度 | 2nd | C → D（或 C#） |
| 3 度 | 三度 | 3rd | C → E（或 Eb） |
| 4 度 | 四度 | 4th | C → F（或 F#） |
| 5 度 | 五度 | 5th | C → G（或 Gb） |
| 6 度 | 六度 | 6th | C → A（或 Ab） |
| 7 度 | 七度 | 7th | C → B（或 Bb） |
| 8 度 | 八度 | Octave | C → C'（高八度） |

## 3. 音程性質（Interval Quality）

度數只告訴我們「幾度」，但同樣是三度，C→E（4 半音）和 C→Eb（3 半音）的聲音完全不同。這就需要**音程性質（interval quality）**來區分。

### 性質種類

| 性質 | 中文 | 英文縮寫 | 適用度數 |
|------|------|----------|---------|
| 完全（Pure） | 完全 | P | 1, 4, 5, 8 度 |
| 大（Major） | 大 | M | 2, 3, 6, 7 度 |
| 小（Minor） | 小 | m | 2, 3, 6, 7 度 |
| 增（Augmented） | 增 | A（或 aug） | 所有度數均可 |
| 減（Diminished） | 減 | d（或 dim） | 所有度數均可 |

**大小關係**：Major 比 Minor 多 1 半音；Augmented 比 Perfect/Major 多 1 半音；Diminished 比 Perfect/Minor 少 1 半音。

### 所有基本音程表（以 C 為根音，上行）

| 名稱（中） | 縮寫 | 半音數 | 鍵盤舉例 | 別名 |
|-----------|------|--------|---------|------|
| 完全一度 | P1 | 0 | C → C | 同音（Unison） |
| 小二度 | m2 | 1 | C → C# / C → Db | 半音 |
| 大二度 | M2 | 2 | C → D | 全音 |
| 小三度 | m3 | 3 | C → Eb | |
| 大三度 | M3 | 4 | C → E | |
| 完全四度 | P4 | 5 | C → F | |
| 增四度 | A4 | 6 | C → F# | 三全音（Tritone） |
| 減五度 | d5 | 6 | C → Gb | 三全音（Tritone） |
| 完全五度 | P5 | 7 | C → G | |
| 小六度 | m6 | 8 | C → Ab | |
| 大六度 | M6 | 9 | C → A | |
| 小七度 | m7 | 10 | C → Bb | |
| 大七度 | M7 | 11 | C → B | |
| 完全八度 | P8 | 12 | C → C'（高八度） | 八度（Octave） |

> 注意：增四度（A4）和減五度（d5）半音數相同（都是 6），聲音一樣，只是寫法不同——這種現象叫做**等音（enharmonic equivalent）**。

### 鍵盤圖示：常見音程視覺化

從 C 出發，主要音程的落點：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐         ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│         │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘         └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐       ┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │       │ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘       └───┴───┴───┴───┴───┴───┴───┘
  ●   ↑   ↑   ↑   ↑   ↑   ↑           ●               ↑
  C  M2  M3  P4  P5  M6  M7           C              P5 (7st)
  (根)(2st)(4st)(5st)(7st)(9st)(11st)
```

## 4. 協和與不協和（Consonance & Dissonance）

並非所有音程聽起來都一樣「穩定」。音樂理論根據音程的聽覺張力，分為三類：

### 完全協和（Perfect Consonance）

| 音程 | 聲音特質 |
|------|---------|
| P1（同音） | 完全融合，無張力 |
| P5（完全五度） | 空曠、穩定，古代音樂的支柱 |
| P8（八度） | 融合感極強，兩音幾乎像同一個音 |

> P5 是最穩定的非同音音程，是古代複音音樂（organum）的基礎。

**P4（完全四度）的特殊地位**：四度單獨聽起來跟五度一樣協和，但在古典和聲中地位曖昧：
- **低音上方的四度**（如 C-F，C 在低音）→ 傳統上視為**不協和**，需要解決（這就是為什麼第二轉位和弦 6/4 被視為不穩定）
- **內聲部或高音的四度**（如三聲部以上，四度不在最底下）→ 視為**協和**
- **現代流行/爵士**中 → sus4 和弦直接當作色彩使用，不一定需要解決

因此 P4 不歸入上面任何一類 — 它是唯一「看上下文決定」的音程。

### 不完全協和（Imperfect Consonance）

| 音程 | 聲音特質 |
|------|---------|
| M3（大三度） | 明亮、愉悅 |
| m3（小三度） | 柔和、略帶憂鬱 |
| M6（大六度） | 開朗、溫暖 |
| m6（小六度） | 柔美，帶些微張力 |

> 三度和六度是和聲填充的主力——它們既和諧又有色彩，是現代和弦的基石。

### 不協和（Dissonance）

| 音程 | 聲音特質 |
|------|---------|
| m2（小二度） | 尖銳衝突，強烈張力 |
| M2（大二度） | 輕微摩擦，需要解決 |
| M7（大七度） | 緊張、不穩定 |
| m7（小七度） | 張力略低，常作屬七和弦的特色 |
| A4/d5（三全音） | 最不穩定，古代稱「魔鬼的音程」（diabolus in musica） |

### 為什麼這件事對和弦很重要？

- **和弦的穩定感**來自協和音程的比例。大三和弦（major triad）包含 M3 + m3，聽起來明亮穩定；減三和弦（diminished triad）包含兩個 m3，最外層形成 d5，聽起來緊張。
- **和聲進行（chord progression）**的動力，就來自不協和音程「想要解決」到協和音程的張力（tension → resolution）。
- 學習音程的協和度，就是在學「什麼聲音穩定，什麼聲音需要往下走」。

## 5. 音程轉位（Interval Inversion）

### 什麼是轉位？

**轉位（inversion）**是把音程的低音搬到上方（或高音搬到下方），讓兩音的上下關係對調。

```
   原始：C → E（大三度，M3，4 半音）
   ↓ 把 C 往上移一個八度
   轉位：E → C'（小六度，m6，8 半音）
```

```
  鍵盤示意：
  
  原始（C 在下，E 在上）：
  ┌───┬───┬───┐
  │ C │   │ E │   C → E = M3 (4st)
  └───┴───┴───┘
    ●           ●

  轉位（E 在下，C' 在上）：
  ┌───┬───┬───┬───┬───┬───┬───┐
  │   │ E │ F │ G │ A │ B │C' │  E → C' = m6 (8st)
  └───┴───┴───┴───┴───┴───┴───┘
        ●                   ●
```

### 轉位規則

兩條簡單規則，記住就能心算：

**規則一：度數相加 = 9**

```
原始度數 + 轉位度數 = 9
```

| 原始 | 轉位 |
|------|------|
| 1 度 | 8 度 |
| 2 度 | 7 度 |
| 3 度 | 6 度 |
| 4 度 | 5 度 |
| 5 度 | 4 度 |
| 6 度 | 3 度 |
| 7 度 | 2 度 |
| 8 度 | 1 度 |

**規則二：性質互換**

| 原始性質 | 轉位後性質 |
|---------|----------|
| Major（大） | → Minor（小） |
| Minor（小） | → Major（大） |
| Perfect（完全） | → Perfect（完全） |
| Augmented（增） | → Diminished（減） |
| Diminished（減） | → Augmented（增） |

### 轉位例子

| 原始音程 | 縮寫 | → | 轉位音程 | 縮寫 | 驗算 |
|---------|------|---|---------|------|------|
| C → E（大三度） | M3 | → | E → C'（小六度） | m6 | 3+6=9 ✓，Major→Minor ✓ |
| C → G（完全五度） | P5 | → | G → C'（完全四度） | P4 | 5+4=9 ✓，Perfect→Perfect ✓ |
| C → F（完全四度） | P4 | → | F → C'（完全五度） | P5 | 4+5=9 ✓，Perfect→Perfect ✓ |
| C → A（大六度） | M6 | → | A → C'（小三度） | m3 | 6+3=9 ✓，Major→Minor ✓ |
| C → Bb（小七度） | m7 | → | Bb → C'（大二度） | M2 | 7+2=9 ✓，Minor→Major ✓ |
| C → F#（增四度） | A4 | → | F# → C'（減五度） | d5 | 4+5=9 ✓，Aug→Dim ✓ |

### 轉位的實用意義

- 和弦**轉位（chord inversion）**的名稱，就是來自這裡：C 大三和弦原位（C-E-G）中的 C-E（M3）在第一轉位時變成 E-G（m3）。
- 轉位幫助你快速判斷：看到 m6，馬上知道它是 M3 的轉位，聽覺性格相近。

## 6. 白鍵音程速算法

> **核心前提**：鍵盤上只有兩個天然半音 — **E-F** 和 **B-C**。其餘相鄰白鍵都是全音。
> 所有白鍵音程的規律，都從這一個事實推出來。

### 6.1 二度：只有 2 個半音，其餘全是全音

直接看相鄰白鍵之間是不是 E-F 或 B-C：

```
C-D  D-E  E-F  F-G  G-A  A-B  B-C
 M2   M2   m2   M2   M2   M2   m2
```

> **規則：E-F 和 B-C 是 m2，其餘 5 組都是 M2。**
> 彈鋼琴的人本來就知道這件事 — 這就是「白鍵裡沒有黑鍵的兩個地方」。

### 6.2 三度：跨兩步，看裡面包了幾個半音

三度 = 兩個二度疊加。兩個全音（M2+M2）= 大三度（M3）；一全一半 = 小三度（m3）。

所以只要看這兩步裡有沒有碰到 E-F 或 B-C：

| 三度 | 拆成兩個二度 | 包含半音？ | 結果 |
|------|------------|----------|------|
| C-E | C-D(M2) + D-E(M2) | 無 | **M3** |
| D-F | D-E(M2) + E-F(m2) | E-F | **m3** |
| E-G | E-F(m2) + F-G(M2) | E-F | **m3** |
| F-A | F-G(M2) + G-A(M2) | 無 | **M3** |
| G-B | G-A(M2) + A-B(M2) | 無 | **M3** |
| A-C | A-B(M2) + B-C(m2) | B-C | **m3** |
| B-D | B-C(m2) + C-D(M2) | B-C | **m3** |

> **規則：大三度只有 3 組 — C-E、F-A、G-B（= C、F、G 大三和弦的根音與三度）。其餘 4 組都是小三度。**

### 6.3 四度和五度：各只有 1 個例外

**四度**：幾乎全部是 P4（5 個半音）。
唯一例外：**F-B = A4**（增四度，6 個半音 = 三全音）。
原因：F 到 B 跨了 3 個全音，中間完全沒碰到 E-F 或 B-C 半音，比正常多了一個半音。

**五度**：幾乎全部是 P5（7 個半音）。
唯一例外：**B-F = d5**（減五度，6 個半音 = 三全音）。
原因：B 到 F 跨的範圍裡包了 E-F 和 B-C 兩個半音，比正常少了一個半音。

> **規則：四度和五度各只記一個例外 — F→B（A4）和 B→F（d5），兩個其實是同一個三全音的轉位。**

```
四度：C-F ✓  D-G ✓  E-A ✓  F-B ✗(A4)  G-C ✓  A-D ✓  B-E ✓
五度：C-G ✓  D-A ✓  E-B ✓  F-C ✓  G-D ✓  A-E ✓  B-F ✗(d5)
```

### 6.4 六度和七度：用轉位從二度、三度推

六度 = 八度 - 二度的轉位，七度 = 八度 - 三度的轉位（見 §5）。不需要另外記，直接推：

**七度 = 二度的轉位**（度數 2+7=9，大小互換）：

```
原始二度：  C-D(M2)  D-E(M2)  E-F(m2)  F-G(M2)  G-A(M2)  A-B(M2)  B-C(m2)
翻轉成七度：D-C(m7)  E-D(m7)  F-E(M7)  G-F(m7)  A-G(m7)  B-A(m7)  C-B(M7)
```

> **規則：M7 只有 2 組 — C-B 和 F-E（= m2 的兩組 E-F、B-C 翻過來）。其餘 5 組都是 m7。**

**六度 = 三度的轉位**（度數 3+6=9，大小互換）：

```
原始三度：  C-E(M3)  D-F(m3)  E-G(m3)  F-A(M3)  G-B(M3)  A-C(m3)  B-D(m3)
翻轉成六度：E-C(m6)  F-D(M6)  G-E(M6)  A-F(m6)  B-G(m6)  C-A(M6)  D-B(M6)
```

> **規則：m6 只有 3 組 — E-C、A-F、B-G（= M3 的三組翻過來）。其餘 4 組都是 M6。**

### 6.5 總結：只需要記 3 條規則

| # | 規則 | 記法 |
|---|------|------|
| 1 | **E-F 和 B-C 是半音** | 鍵盤上沒有黑鍵的地方（你已經知道了）|
| 2 | **大三度只有 C-E、F-A、G-B** | C、F、G 大三和弦（最常見的三個大和弦）|
| 3 | **三全音只有 F-B / B-F** | 唯一一組四度/五度的例外 |

- 二度：從規則 1 直接得到
- 三度：規則 2
- 四度、五度：規則 3（其餘都是 P4/P5）
- 六度：規則 2 轉位（M3 → m6）
- 七度：規則 1 轉位（m2 → M7）

### 6.6 碰到黑鍵怎麼辦

先用上面的規則算出白鍵音程，再根據升降記號調整一步：

**品質階梯**（每次升降只移一格）：

```
二/三/六/七度：  … ← 減(d) ← 小(m) ← 大(M) ← 增(A) ← …
四/五/八度：          … ← 減(d) ← 完全(P) ← 增(A) ← …
                      ←── 縮小 ──┤── 擴大 ──→
```

| 變化 | 效果 | 例子 |
|------|------|------|
| 上方音升半音（#） | 擴大一格：m→M, M→A, P→A | E→G(m3) → E→G#(**M3**) |
| 上方音降半音（♭） | 縮小一格：M→m, m→d, P→d | C→E(M3) → C→E♭(**m3**) |
| 下方音升半音（#） | 縮小一格（底部升 = 距離縮） | F→C(P5) → F#→C(**d5**) |
| 下方音降半音（♭） | 擴大一格（底部降 = 距離擴） | E→G(m3) → E♭→G(**M3**) |

> 記憶口訣：**上升擴、上降縮；下升縮、下降擴**。每次只移一格，不會跳級。

**例 1：E → B♭ = ？**　白鍵 E-B = P5 → 上方降半音 → 縮小 → **d5**

**例 2：E♭ → G = ？**　白鍵 E-G = m3 → 下方降半音 → 擴大 → **M3**

**例 3：A → C# = ？**　白鍵 A-C = m3 → 上方升半音 → 擴大 → **M3**

**例 4：D → F = ？**　全部白鍵，直接用規則 2 → D-F 不在 C-E/F-A/G-B 裡 → **m3**

## 7. 音程辨識練習（心算訓練）

試著用上面的規則心算以下音程（答案在下方）：

1. C → Ab（上行）= ？
2. D → F（上行）= ？
3. G → D'（上行）= ？
4. E → C'（上行）= ？

<details>
<summary>答案</summary>

1. C → Ab：C-A = M6（9st），A 降半音 → **m6（8st）**
2. D → F：D-E-F = 3 個字母 = 三度；D-E=M2(2st)，E-F=m2(1st) → 共 3st = **m3**
3. G → D'：G-D = P5（7st）；上行一個八度依然是 P5 → **P5（7st）**
4. E → C'（E 在下，C' 在上）：E-F-G-A-B-C = 6 個字母 = 六度；E 到 C 共 8st = **m6**（C → E 是 M3，轉位得 m6 ✓）

</details>

## 8. 下一步

音程是和聲理論的原子（atom）——所有更複雜的結構都由它組成。掌握了音程的度數、性質、協和度和轉位，你就具備了讀懂和弦的基本語言。

**三和弦（triad）**是下一個目標：任何三和弦都是兩個三度疊加而成。大三和弦（major triad）= M3 + m3；小三和弦（minor triad）= m3 + M3；減三和弦（diminished triad）= m3 + m3。認識音程之後，和弦的結構就變得透明。
