# 變化和弦（Chromatic Chords）

> 前置知識：[concept_triad — 三和弦](concept_triad.md)、[concept_seventh_chord — 七和弦](concept_seventh_chord.md)、[concept_cadence — 終止式](concept_cadence.md)
> 建議先讀：[concept_secondary_dominant — 副屬和弦](concept_secondary_dominant.md)

副屬和弦讓你「短暫拜訪」別的調；但古典音樂還有一群更戲劇性的和弦——它們使用調外音（chromatic notes）來製造強烈的色彩與張力，然後以極具說服力的方式解決。這些就是**變化和弦（chromatic chords）**。

本篇介紹三種最重要的變化和弦：**拿坡里和弦**、**增六和弦**、**皮卡第三度**。

---

## 1. 拿坡里和弦（Neapolitan Chord）

### 1-a. 定義

**拿坡里和弦（Neapolitan chord, N）**是建立在**降二級（♭II）**上的大三和弦。

以 C 小調為例：

- 自然二級音 = D
- 降二級音 = D♭
- 在 D♭ 上建立大三和弦 = **D♭ 大三和弦（D♭–F–A♭）**

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

  C 小調自然音：C D E♭ F G A♭ B♭

  ♭II（N）: D♭–F–A♭    ← D♭ 是調外音（D 被降了半音）
```

### 1-b. 最常見的用法：♭II6（第一轉位）

拿坡里和弦**幾乎都以第一轉位出現**，記作 **♭II6** 或 **N6**。

為什麼？因為第一轉位時低音 = F，接下來進入 V（G）時低音 F → G 是半音上行，聲部進行非常順暢。

典型進行：

```
i → ♭II6 → V → i

C 小調：Cm → D♭/F → G → Cm
```

```
低音線：C → F → G → C
          i   ♭II6  V   i
               ↑
          F 是 D♭ 的第一轉位低音
```

### 1-c. 聲響特色

拿坡里和弦的效果是**戲劇性的、陰暗而美麗的**。D♭ 這個音比 D 低半音，帶來一種「往下沉」的張力；接到 V 再解決到 i，產生極強的終止感。

### 1-d. 名稱由來與應用

「拿坡里」之名來自 18 世紀**那不勒斯歌劇學派（Neapolitan opera school）**——Alessandro Scarlatti 等作曲家大量使用。

著名應用：
- 貝多芬：「月光」奏鳴曲第一樂章
- 蕭邦：多首敘事曲與夜曲
- 電影配樂：營造悲劇性或宿命感的場景

## 2. 增六和弦（Augmented Sixth Chords）

### 2-a. 核心概念

增六和弦是一組含有**增六度音程**的和弦，這個增六度**向外解決到屬音的八度**。

以 C 大調或 C 小調為例：

- 增六度音程：A♭ → F#（從 ♭6 到 #4）
- A♭ 向下半音解決到 G，F# 向上半音解決到 G
- 兩個音從兩個方向「夾擊」屬音 G

```
  A♭ ──→ G ←── F#
  (♭6)  (5)   (#4)
   ↓半音       ↑半音

增六度向外擴張解決為八度（G–G）
```

### 2-b. 三種增六和弦

三種增六和弦的差別在於 A♭ 和 F# 之間還有哪些音：

| 名稱 | 代號 | 組成音（C 調） | 音數 | 特徵 |
|------|------|---------------|------|------|
| 義大利增六 | It+6 | A♭–C–F# | 3 | 最精簡，只有三個音 |
| 法國增六 | Fr+6 | A♭–C–D–F# | 4 | 多一個 2 級音（D），帶來不協和的色彩 |
| 德國增六 | Ger+6 | A♭–C–E♭–F# | 4 | 多一個 ♭3（E♭），聽起來像 A♭ 屬七和弦 |

逐一說明：

**義大利增六（Italian 6th, It+6）**：♭6–1–#4

```
A♭–C–F#     （三個音）
♭6  1  #4
```

最簡單的增六和弦，只含增六度框架加上主音。

**法國增六（French 6th, Fr+6）**：♭6–1–2–#4

```
A♭–C–D–F#   （四個音）
♭6  1  2  #4
```

多了一個 D（2 級音），產生額外的不協和感。D 與 A♭ 之間是三全音，讓這個和弦聽起來特別尖銳。

**德國增六（German 6th, Ger+6）**：♭6–1–♭3–#4

```
A♭–C–E♭–F#  （四個音）
♭6  1  ♭3  #4
```

如果把 F# 重新拼寫（enharmonic）為 G♭，這個和弦就是 A♭–C–E♭–G♭ = **A♭ 屬七和弦（A♭7）**。所以德國增六和弦**聽起來跟屬七和弦一模一樣**，但功能和解決方向完全不同。

### 2-c. 解決方式

三種增六和弦都**解決到 V**（屬和弦）：

```
It+6 → V
Fr+6 → V
Ger+6 → I64 → V    （德國增六通常先經過 I64）
```

為什麼德國增六要先經過 I64？因為 Ger+6 直接到 V 會產生**平行五度（E♭→D 與 A♭→G）**，這在古典聲部進行中是要避免的。插入 I64（C–E–G，低音 G）讓 E♭ 先解決到 E，避免了平行五度。

### 2-d. 記憶口訣

一個簡單的記法——看 A♭ 和 F# 之間「夾了什麼」：

- **義大利**：只夾一個 C → 3 個音 → 最「精簡」
- **法國**：夾了 C 和 D → 4 個音 → 含 2 級音
- **德國**：夾了 C 和 E♭ → 4 個音 → 聽起來像屬七

## 3. 皮卡第三度（Picardy Third）

### 3-a. 定義

**皮卡第三度（Picardy third, tierce de Picardie）**：在小調樂曲中，**最後一個和弦將小三和弦改為大三和弦**（升高三音）。

以 C 小調為例：

- 正常結尾：Cm（C–E♭–G）
- 皮卡第三度結尾：**C（C–E–G）**

```
正常結尾：
  V  →  i
  G  →  Cm (C–E♭–G)    小三和弦，暗色

皮卡第三度結尾：
  V  →  I
  G  →  C  (C–E–G)     大三和弦！意外的明亮
              ↑
          E♭ 升為 E（升高三音）
```

### 3-b. 效果

整首曲子都在小調的陰暗色彩中行進，最後一刻突然**從暗轉亮**——像烏雲散開露出陽光。這種效果可以是：

- **莊嚴、神聖的光明感**（巴洛克宗教音樂中最常見）
- **意外的溫暖與釋懷**
- **宿命感中的一絲希望**

### 3-c. 歷史與應用

- **巴洛克時期（Baroque era）**：幾乎是標準做法。巴赫（Bach）的聖詠（chorales）中，小調結尾經常使用皮卡第三度。當時的觀念認為大三和弦比小三和弦更「完美」、更適合作為結尾。
- **古典與浪漫時期**：使用減少，但仍出現在需要特殊效果的場合。
- **名稱由來**：法語 "tierce de Picardie"，意為「皮卡第的三度」。名稱起源有爭議——可能與法國北部的皮卡第地區有關，也可能源自某個古法語詞彙。確切來源至今未有定論。

## 4. 三種變化和弦的比較

| 和弦 | 調外音 | 功能 | 解決方向 | 常見時期 |
|------|--------|------|---------|---------|
| 拿坡里（♭II） | ♭2 級音 | 下屬功能，強化到 V 的推進 | ♭II6 → V → i | 古典、浪漫 |
| 增六和弦 | ♭6 + #4 | 強化到 V 的推進（增六度夾擊） | +6 → V | 古典、浪漫 |
| 皮卡第三度 | ♮3（在小調中） | 改變最終和弦色彩 | 直接作為結尾 | 巴洛克 |

**共同點**：三者都是**半音化（chromatic）**手法——使用不屬於本調的音來創造特殊效果。

**功能分工**：

- **拿坡里**和**增六和弦**是「通往 V 的路上」的和弦，它們強化了終止式的推進力。
- **皮卡第三度**則是關於「終點本身」——改變最後一個和弦的色彩。

## 5. 小測驗

試著回答以下問題（答案在下方）：

1. 拿坡里和弦（Neapolitan chord）建立在哪個音級上？以 A 小調為例，拿坡里和弦是什麼？
2. 為什麼拿坡里和弦幾乎都以第一轉位（♭II6）出現？
3. 增六和弦中的「增六度」指的是哪兩個音之間的音程？以 C 調為例。
4. 義大利增六、法國增六、德國增六的組成音分別是什麼（以 C 調為例）？
5. 德國增六和弦為什麼通常先解決到 I64 再到 V，而不是直接到 V？
6. 德國增六（Ger+6）聽起來像什麼常見的和弦？為什麼？
7. 什麼是皮卡第三度（Picardy third）？以 D 小調為例說明。
8. 皮卡第三度在哪個音樂時期最為常見？當時的音樂家為什麼喜歡用它？
9. 拿坡里和弦和增六和弦在功能上有什麼共同點？
10. 在 E 小調中，寫出以下進行的具體和弦：i → ♭II6 → Ger+6 → I64 → V → I（皮卡第三度結尾）。

<details>
<summary>答案</summary>

1. **降二級（♭II）。A 小調的拿坡里和弦 = B♭ 大三和弦（B♭–D–F）** — A 小調的二級音是 B，降半音 = B♭，在 B♭ 上建立大三和弦。

2. **因為第一轉位的低音進行更順暢** — ♭II6 的低音是和弦三音（以 C 小調為例，低音 = F），接到 V（G）時 F → G 是半音上行，聲部進行平滑自然。根音位置的低音 D♭ → G 則是增四度跳進，不夠流暢。

3. **♭6 到 #4 之間的音程。以 C 調為例：A♭ → F#** — A♭ 到 F# 是增六度（比大六度多一個半音）。A♭ 向下半音解決到 G，F# 向上半音解決到 G，兩個音從兩個方向「夾擊」屬音。

4. **It+6 = A♭–C–F#（3 音）；Fr+6 = A♭–C–D–F#（4 音）；Ger+6 = A♭–C–E♭–F#（4 音）** — 三者都有 A♭ 和 F# 的增六度框架，差別在中間的音：義大利只有 C，法國加 D，德國加 E♭。

5. **為了避免平行五度** — Ger+6 直接到 V 時，E♭→D 與 A♭→G 會形成平行五度（古典聲部進行的禁忌）。先到 I64（低音 G），讓 E♭ 先解決到 E，就避開了平行五度。

6. **聽起來像屬七和弦** — 以 C 調為例，Ger+6 = A♭–C–E♭–F#。如果把 F# 異名同音（enharmonic）改寫為 G♭，就變成 A♭–C–E♭–G♭ = A♭7（A♭ 屬七和弦）。兩者聽起來完全相同，但在和聲分析中的功能和解決方向不同。

7. **在小調樂曲中，將結尾的小三和弦改為大三和弦（升高三音）。D 小調：原本結尾為 Dm（D–F–A），皮卡第三度結尾改為 D 大三和弦（D–F#–A）** — F 升為 F#，讓最後一個和弦從暗色變為明亮。

8. **巴洛克時期（Baroque era）最為常見** — 當時的音樂家（尤其是巴赫）認為大三和弦比小三和弦更「完美」、更協和，更適合作為樂曲的結尾。所以小調作品的最後一個和弦經常升高三音，以大三和弦收尾。

9. **兩者都具有下屬功能，強化到 V（屬和弦）的推進** — 拿坡里和弦（♭II6 → V）和增六和弦（+6 → V）都出現在 V 之前，透過半音化的聲部進行為終止式增添張力和推進力。它們是「通往 V 的路上」的和弦。

10. **Em → F/A → C–E–G#–C# (enharmonic: A#) → B/E → B → E** — 詳細展開：i = Em，♭II6 = F 大三和弦第一轉位（F/A，因為 E 小調的 ♭II = F），Ger+6 = C–E–G–D#（E 小調中 ♭6=C，1=E，♭3=G，#4=D#，但注意此處增六度為 C→A#，即 C→D# 的異名同音寫法需注意），I64 = E/B（主和弦第二轉位，低音 B），V = B 大三和弦，I = E 大三和弦（皮卡第三度：E–G#–B，而非 Em）。

</details>
