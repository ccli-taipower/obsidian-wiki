# 七和弦（Seventh Chord）

你已經掌握三和弦：根音 + 三音 + 五音，三個聲部。現在只需要**再疊一個三度**，就到達七和弦的世界。

七和弦（seventh chord）= 三和弦 + 一個疊在五音上方的三度音，共四個音。最高音距根音七度（seventh），因此得名。七和弦讓和聲色彩更豐富，也帶來更強的張力與方向感——這是爵士、古典、流行中「大人感」聲響的來源。

---

## 1. 七和弦定義

### 結構：三和弦 + 第四個音

```
 三和弦：  根音 + 三音 + 五音
 七和弦：  根音 + 三音 + 五音 + 七音
                               ↑
                      在五音上再疊一個三度
```

| 位置 | 中文名 | 英文名 | 說明 |
|------|--------|--------|------|
| 最低音 | 根音 | Root | 和弦命名基準 |
| 第二音 | 三音 | Third | 距根音三度，決定大/小性格 |
| 第三音 | 五音 | Fifth | 距根音五度，穩定感基礎 |
| 最高音 | 七音 | Seventh | 距根音七度，帶來色彩與張力 |

以 **C 大七和弦（Cmaj7）= C–E–G–B** 為例：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●       ●
  根音        三音     五音     七音
  C           E        G       B
  (Root)    (Third)  (Fifth) (7th)
```

- **C → E**：大三度（M3，4 半音）
- **E → G**：小三度（m3，3 半音）
- **G → B**：大三度（M3，4 半音）← 這是新加的七音
- **C → B**：大七度（Major 7th，11 半音）

---

## 2. 五種常見七和弦

七和弦的種類由**三和弦基礎**和**加上的七度性質**共同決定。以下五種是調性音樂中最常見的。

### 2a. 大七和弦（Major 7th / Maj7）

**公式**：1 – 3 – 5 – 7　（= 大三和弦 + 大七度）  
**C 根音**：**C–E–G–B**

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●       ●
  C     M3    E   m3  G   M3  B
```

- **聽感**：溫暖、成熟、夢幻，帶有「不完全的滿足」。是流行和爵士中常見的主和弦色彩。
- 符號：**Cmaj7 / CM7 / CΔ7**
- 詳細：[chord_major7](chord_major7.md)

---

### 2b. 小七和弦（Minor 7th / m7）

**公式**：1 – ♭3 – 5 – ♭7　（= 小三和弦 + 小七度）  
**C 根音**：**C–E♭–G–B♭**

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●       ↑       ●       ↑
  C   m3  E♭  M3  G   m3  B♭
```

（E♭ = D# 黑鍵；B♭ = A# 黑鍵）

- **聽感**：柔和、略帶憂鬱又帶圓潤感，相比小三和弦更加流動。大調中 ii 級、iii 級、vi 級的自然七和弦均為此類型。
- 符號：**Cm7 / Cmin7**
- 詳細：[chord_minor7](chord_minor7.md)

---

### 2c. 屬七和弦（Dominant 7th / dom7）

**公式**：1 – 3 – 5 – ♭7　（= 大三和弦 + 小七度）  
**C 根音**：**C–E–G–B♭**

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●   ↑
  C     M3    E   m3  G  m3  B♭
```

- **聽感**：強烈張力，幾乎「必須」向前解決。三音（E）和七音（B♭）之間形成**三全音（tritone）**，是張力的來源。
- 符號：**C7**（直接寫數字 7，不加其他標記）
- 詳細：[chord_dominant7](chord_dominant7.md)

---

### 2d. 減七和弦（Diminished 7th / dim7）

**公式**：1 – ♭3 – ♭5 – 𝄫7（＝6）　（= 減三和弦 + 減七度）  
**C 根音**：**C–E♭–G♭–B𝄫**（B𝄫 = A 等音）

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●       ↑   ↑       ●
  C   m3  E♭ m3  G♭  m3  A(=B𝄫)
```

（G♭ = F# 黑鍵；B𝄫 = A 白鍵）

- **聽感**：極度緊張、驚悚、懸而未決。四個音完全等距（各 3 半音），整體和弦有完美對稱性——任何音都可視為根音。
- 符號：**C°7 / Cdim7**
- 詳細：[chord_dim7](chord_dim7.md)

---

### 2e. 半減七和弦（Half-diminished 7th / m7♭5）

**公式**：1 – ♭3 – ♭5 – ♭7　（= 減三和弦 + 小七度）  
**C 根音**：**C–E♭–G♭–B♭**

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●       ↑   ↑           ↑
  C   m3  E♭ m3  G♭  M3  B♭
```

- **聽感**：比減七和弦稍緩和，保留緊張感但又帶點柔性哀愁。大調中 vii 級的自然七和弦即為此類型。
- 符號：**Cø7 / Cm7♭5**（ø = half-diminished 符號）
- 詳細：[chord_half_dim7](chord_half_dim7.md)

---

### 比較總表

| 名稱 | 符號 | 公式 | 三和弦基礎 | 七度性質 | 半音數（根→七） | 聽感 |
|------|------|------|-----------|---------|--------------|------|
| 大七和弦 Major 7th | Cmaj7 | 1–3–5–7 | 大三 | 大七（M7） | 11st | 溫暖夢幻、柔和滿足 |
| 小七和弦 Minor 7th | Cm7 | 1–♭3–5–♭7 | 小三 | 小七（m7） | 10st | 柔和憂鬱、圓潤流動 |
| 屬七和弦 Dominant 7th | C7 | 1–3–5–♭7 | 大三 | 小七（m7） | 10st | 強烈張力、急需解決 |
| 減七和弦 Diminished 7th | C°7 | 1–♭3–♭5–𝄫7 | 減三 | 減七（dim7） | 9st | 極度緊張、驚悚懸念 |
| 半減七和弦 Half-dim 7th | Cø7 | 1–♭3–♭5–♭7 | 減三 | 小七（m7） | 10st | 緊張帶柔、哀愁流動 |

> 小七與屬七的根→七半音數相同（都是 10st），但三音不同（3 vs ♭3）——這一個半音造就了截然不同的性格。

## 3. 七和弦轉位

七和弦有四個音，因此有**四個位置**：原位 + 三個轉位。

以 **C 屬七和弦（C7）= C–E–G–B♭** 為例：

### 原位（Root Position）

最低音 = 根音 C

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●   ↑
  C           E       G   B♭
  ↑（最低）
```

### 第一轉位（1st Inversion）

最低音 = 三音 E；C 移到上方

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐         ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│         │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘         └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │C' │B♭'│
└───┴───┴───┴───┴───┴───┴───┴───┴───┘
  ↑           ●       ●   ↑   ●
 (移到上方)   E       G   B♭  C'
              ↑（最低）
```

### 第二轉位（2nd Inversion）

最低音 = 五音 G；C、E 均移到上方

```
              ┌──┐ ┌──┐         ┌──┐
              │F#│ │G#│         │A#│
              └──┘ └──┘         └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │C' │ E'│
└───┴───┴───┴───┴───┴───┴───┴───┴───┘
  ↑   ↑       ↑   ●       ↑   ●   ●
 (C E 移走)   F   G   B♭  B♭  C'  E'
                  ↑（最低）
```

### 第三轉位（3rd Inversion）

最低音 = 七音 B♭；C、E、G 均移到上方

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │C' │
└───┴───┴───┴───┴───┴───┴───┴───┘
  ↑   ↑   ↑       ↑           ●
 (移走)          B♭            ...（C E G 在更高八度）
  ↑（B♭ 最低）
```

簡化示意（只標最低一個八度）：
```
最低音：B♭，上方依次為 C–E–G（下一個八度）
```

### 四位置一覽

| 名稱 | 最低音 | 排列 | 數字低音（Figured Bass） |
|------|--------|------|------------------------|
| 原位（Root Position） | 根音 C | C–E–G–B♭ | 7（7/5/3 省略） |
| 第一轉位（1st Inversion） | 三音 E | E–G–B♭–C | 6/5 |
| 第二轉位（2nd Inversion） | 五音 G | G–B♭–C–E | 4/3 |
| 第三轉位（3rd Inversion） | 七音 B♭ | B♭–C–E–G | 4/2（或 2） |

> 第三轉位是七和弦獨有的（三和弦只有三位置），數字低音「2」意謂低音上方有二度音程，聽感特別不穩定，在古典對位中幾乎必須向內半音解決。

## 4. 屬七的特殊地位

在所有七和弦中，**屬七和弦（Dominant 7th）是最重要的一種**。

### 三全音的張力

C 屬七和弦（C7）= C–E–G–B♭。其中，**三音 E 和七音 B♭ 之間**形成了**三全音（tritone = 增四度 / 減五度，6 半音）**：

```
E ─────────── B♭
  ←  6 半音  →
  （三全音，tritone）
```

三全音是西洋音樂裡最不穩定、張力最強的音程。它「迫使」和弦向前解決（resolve）。

### C7 → F 的解決（V7 → I in F major）

```
C7（屬七）解決到 F（主和弦）

C7：  C – E – G – B♭
      ↓     ↓     ↓   ↓
F：   C – F – A – C  （或 F–A–C 省略其中音）

三全音的動向：
  E  → F   （半音上行，解決三音的張力）
  B♭ → A   （半音下行，解決七音的張力）
```

鍵盤示意：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●   ↑        ← C7（C–E–G–B♭）
              │       │   │
              ↓           ↓
          ●       ●   ↑              ← F（F–A–C）
  ●           ●
  F           A
```

- **E → F**：上行半音，「導音式」解決（leading-tone resolution）
- **B♭ → A**：下行半音，「七音」解決（seventh resolution）
- C 和 G 可以保持不動或重組

### V7 → I：調性音樂的引擎

> 屬七和弦（V7）→ 主和弦（I）是西洋調性音樂裡**最強的和聲動力**。從巴哈到流行樂，這個進行無處不在。沒有 V7，音樂的「回家感」（cadence）就大打折扣。

和弦功能的完整體系，見：[concept_chord_function](concept_chord_function.md)

## 5. 大調音階上的七和弦

把 [concept_triad](concept_triad.md) 中每個級數的三和弦再往上疊一個三度，就得到七個**順階七和弦（diatonic seventh chords）**。

### C 大調的七個順階七和弦

C 大調音階：C–D–E–F–G–A–B

| 級數 | 和弦 | 組成音 | 類型 | 符號 |
|------|------|--------|------|------|
| I | Cmaj7 | C–E–G–B | 大七和弦（Major 7th） | IΔ7 |
| ii | Dm7 | D–F–A–C | 小七和弦（Minor 7th） | ii7 |
| iii | Em7 | E–G–B–D | 小七和弦（Minor 7th） | iii7 |
| IV | Fmaj7 | F–A–C–E | 大七和弦（Major 7th） | IVΔ7 |
| V | G7 | G–B–D–F | 屬七和弦（Dominant 7th） | V7 |
| vi | Am7 | A–C–E–G | 小七和弦（Minor 7th） | vi7 |
| vii | Bø7 | B–D–F–A | 半減七和弦（Half-dim） | viiø7 |

```
大調順階七和弦性質規律：
I     ii    iii   IV    V     vi    vii
Δ7    m7    m7    Δ7    7     m7    ø7
大七  小七  小七  大七  屬七  小七  半減七
```

> **口訣**：大調裡只有 **V 級是屬七**（大三和弦 + 小七），I 和 IV 是大七，ii / iii / vi 是小七，vii 是半減七。這個分布是固定的，換任何大調都一樣。

## 6. 下一步

七和弦在五音上疊了一個三度，得到七音。如果繼續往上再疊一個三度：

```
 七和弦：  根音 + 三音 + 五音 + 七音
 九和弦：  根音 + 三音 + 五音 + 七音 + 九音
                                        ↑
                               距根音九度（= 八度 + 二度）
```

這些「七音以上的延伸」稱為**延伸和弦（Extended Chords）**：9th、11th、13th。爵士和弦常以此堆疊，產生豐厚的色彩層次。詳見：[concept_extended_chord](concept_extended_chord.md)
