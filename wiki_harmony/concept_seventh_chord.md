# 七和弦（Seventh Chord）

你已經掌握三和弦：根音 + 三音 + 五音，三個聲部。現在只需要**再疊一個三度**，就到達七和弦的世界。

七和弦（seventh chord）= 三和弦 + 一個疊在五音上方的三度音，共四個音。最高音距根音七度（seventh），因此得名。七和弦讓和聲色彩更豐富，也帶來更強的張力與方向感——這是爵士、古典、流行中「大人感」聲響的來源。

---

## 1. 七和弦定義

### 結構：三和弦 + 第四個音

```
 三和弦：  根音 + 三音 + 五音
 七和弦：  根音 + 三音 + 五音 + 七音
                               ↑
                      在五音上再疊一個三度
```

| 位置 | 中文名 | 英文名 | 說明 |
|------|--------|--------|------|
| 最低音 | 根音 | Root | 和弦命名基準 |
| 第二音 | 三音 | Third | 距根音三度，決定大/小性格 |
| 第三音 | 五音 | Fifth | 距根音五度，穩定感基礎 |
| 最高音 | 七音 | Seventh | 距根音七度，帶來色彩與張力 |

以 **C 大七和弦（Cmaj7）= C–E–G–B** 為例：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●       ●
  根音        三音     五音     七音
  C           E        G       B
  (Root)    (Third)  (Fifth) (7th)
```

- **C → E**：大三度（M3，4 半音）
- **E → G**：小三度（m3，3 半音）
- **G → B**：大三度（M3，4 半音）← 這是新加的七音
- **C → B**：大七度（Major 7th，11 半音）

---

## 2. 五種常見七和弦

七和弦的種類由**三和弦基礎**和**加上的七度性質**共同決定。以下五種是調性音樂中最常見的。

### 2a. 大七和弦（Major 7th / Maj7）

**公式**：1 – 3 – 5 – 7　（= 大三和弦 + 大七度）  
**C 根音**：**C–E–G–B**

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●       ●
  C     M3    E   m3  G   M3  B
```

- **聽感**：溫暖、成熟、夢幻，帶有「不完全的滿足」。是流行和爵士中常見的主和弦色彩。
- 符號：**Cmaj7 / CM7 / CΔ7**
- 詳細：[chord_major7](chord_major7.md)

---

### 2b. 小七和弦（Minor 7th / m7）

**公式**：1 – ♭3 – 5 – ♭7　（= 小三和弦 + 小七度）  
**C 根音**：**C–E♭–G–B♭**

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●       ↑       ●       ↑
  C   m3  E♭  M3  G   m3  B♭
```

（E♭ = D# 黑鍵；B♭ = A# 黑鍵）

- **聽感**：柔和、略帶憂鬱又帶圓潤感，相比小三和弦更加流動。大調中 ii 級、iii 級、vi 級的自然七和弦均為此類型。
- 符號：**Cm7 / Cmin7**
- 詳細：[chord_minor7](chord_minor7.md)

---

### 2c. 屬七和弦（Dominant 7th / dom7）

**公式**：1 – 3 – 5 – ♭7　（= 大三和弦 + 小七度）  
**C 根音**：**C–E–G–B♭**

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●   ↑
  C     M3    E   m3  G  m3  B♭
```

- **聽感**：強烈張力，幾乎「必須」向前解決。三音（E）和七音（B♭）之間形成**三全音（tritone）**，是張力的來源。
- 符號：**C7**（直接寫數字 7，不加其他標記）
- 詳細：[chord_dominant7](chord_dominant7.md)

---

### 2d. 減七和弦（Diminished 7th / dim7）

**公式**：1 – ♭3 – ♭5 – 𝄫7（＝6）　（= 減三和弦 + 減七度）  
**C 根音**：**C–E♭–G♭–B𝄫**（B𝄫 = A 等音）

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●       ↑   ↑       ●
  C   m3  E♭ m3  G♭  m3  A(=B𝄫)
```

（G♭ = F# 黑鍵；B𝄫 = A 白鍵）

- **聽感**：極度緊張、驚悚、懸而未決。四個音完全等距（各 3 半音），整體和弦有完美對稱性——任何音都可視為根音。
- 符號：**C°7 / Cdim7**
- 詳細：[chord_dim7](chord_dim7.md)

---

### 2e. 半減七和弦（Half-diminished 7th / m7♭5）

**公式**：1 – ♭3 – ♭5 – ♭7　（= 減三和弦 + 小七度）  
**C 根音**：**C–E♭–G♭–B♭**

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●       ↑   ↑           ↑
  C   m3  E♭ m3  G♭  M3  B♭
```

- **聽感**：比減七和弦稍緩和，保留緊張感但又帶點柔性哀愁。大調中 vii 級的自然七和弦即為此類型。
- 符號：**Cø7 / Cm7♭5**（ø = half-diminished 符號）
- 詳細：[chord_half_dim7](chord_half_dim7.md)

---

### 比較總表：三和弦 + 三度 = 七和弦

七和弦 = 三和弦 + 再疊一個三度。下表按四種三和弦排列，各加 M3 或 m3：

| 三和弦基礎 | + M3（大三度） | + m3（小三度） |
|-----------|--------------|--------------|
| **增三和弦** (M3+M3) | ✗ 不存在（七音=根音八度） | 增大七 aug(maj7)：1–3–#5–**7** |
| **大三和弦** (M3+m3) | 大七 maj7：1–3–5–**7** | 屬七 dom7：1–3–5–**♭7** |
| **小三和弦** (m3+M3) | 小大七 m(maj7)：1–♭3–5–**7** | 小七 m7：1–♭3–5–**♭7** |
| **減三和弦** (m3+m3) | 半減七 ø7：1–♭3–♭5–**♭7** | 減七 dim7：1–♭3–♭5–**𝄫7** |

> **為什麼增三 + M3 不存在？** 增三和弦的五音是 #5（如 G#），再加 M3 到 B#（= C），等於回到根音八度，不構成七和弦。
>
> **第 8 種：增七和弦（C7#5）**：增三和弦 + **減三度 d3**（G#→B♭ = 2 半音）= 1–3–#5–♭7。實務上不從堆疊角度理解，而是直接記成「**屬七 + 升五**」。

所以實際共 **7 種可由 M3/m3 堆疊產生** + **1 種特殊的增七**（用 d3）= 8 種七和弦。

#### 三度堆疊明細

| 名稱 | 符號 | 根→三 | 三→五 | 五→七 | 根→七 | 常見度 |
|------|------|-------|-------|-------|-------|--------|
| 增大七 Augmented-major 7th | Cmaj7#5 | M3 | M3 | **m3** | M7 (11st) | ★ 少見 |
| 增七 Augmented 7th | C7#5 | M3 | M3 | **d3 (2st)** | m7 (10st) | ★★ 爵士 |
| 大七 Major 7th | Cmaj7 | M3 | m3 | **M3** | M7 (11st) | ★★★★★ |
| 屬七 Dominant 7th | C7 | M3 | m3 | **m3** | m7 (10st) | ★★★★★ |
| 小大七 Minor-major 7th | CmMaj7 | m3 | M3 | **M3** | M7 (11st) | ★★ 電影 |
| 小七 Minor 7th | Cm7 | m3 | M3 | **m3** | m7 (10st) | ★★★★★ |
| 半減七 Half-diminished 7th | Cø7 | m3 | m3 | **M3** | m7 (10st) | ★★★★ |
| 減七 Diminished 7th | C°7 | m3 | m3 | **m3** | d7 (9st) | ★★★★ |

#### 口訣：疊大亮、疊小暗

> 在大三、小三、減三這三組中（增三較特殊，見上）：
> **+ M3 = 七音偏「亮」（大七度 M7 或較高的小七度 m7）**
> **+ m3 = 七音偏「暗」（小七度 m7 或減七度 d7）**

按三和弦從亮到暗排列：

```
增三 ──── 增大七 (aug maj7)           ← +m3，稀有
       └─ 增七 (aug7)               ← +d3，實務記為「屬七+#5」

大三 ──┬─ +M3 → 大七 (maj7)          ← 流行/爵士主和弦
       └─ +m3 → 屬七 (dom7)          ← 最常見，V 級

小三 ──┬─ +M3 → 小大七 (mMaj7)       ← 電影配樂不安感
       └─ +m3 → 小七 (m7)            ← ii-V-I 的 ii

減三 ──┬─ +M3 → 半減七 (ø7)          ← 小調 ii°7
       └─ +m3 → 減七 (dim7)          ← 等距對稱，轉調利器
```

> **記法**：同一種三和弦，**+M3 的七音永遠比 +m3 高一個半音**（大七 vs 屬七、小大七 vs 小七、半減七 vs 減七）。所以每對之中，上面那個聽起來比較「亮」，下面那個比較「暗」。
>
> 日常最常用的 5 種（★★★★ 以上）：大七、屬七、小七、半減七、減七。增大七、增七、小大七較少見，但在爵士與電影配樂中會出現。

## 3. 七和弦轉位

七和弦有四個音，因此有**四個位置**：原位 + 三個轉位。

以 **C 屬七和弦（C7）= C–E–G–B♭** 為例：

### 原位（Root Position）

最低音 = 根音 C

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●   ↑
  C           E       G   B♭
  ↑（最低）
```

### 第一轉位（1st Inversion）

最低音 = 三音 E；C 移到上方

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐         ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│         │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘         └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │C' │B♭'│
└───┴───┴───┴───┴───┴───┴───┴───┴───┘
  ↑           ●       ●   ↑   ●
 (移到上方)   E       G   B♭  C'
              ↑（最低）
```

### 第二轉位（2nd Inversion）

最低音 = 五音 G；C、E 均移到上方

```
              ┌──┐ ┌──┐         ┌──┐
              │F#│ │G#│         │A#│
              └──┘ └──┘         └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │C' │ E'│
└───┴───┴───┴───┴───┴───┴───┴───┴───┘
  ↑   ↑       ↑   ●       ↑   ●   ●
 (C E 移走)   F   G   B♭  B♭  C'  E'
                  ↑（最低）
```

### 第三轉位（3rd Inversion）

最低音 = 七音 B♭；C、E、G 均移到上方

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │C' │
└───┴───┴───┴───┴───┴───┴───┴───┘
  ↑   ↑   ↑       ↑           ●
 (移走)          B♭            ...（C E G 在更高八度）
  ↑（B♭ 最低）
```

簡化示意（只標最低一個八度）：
```
最低音：B♭，上方依次為 C–E–G（下一個八度）
```

### 四位置一覽

| 名稱 | 最低音 | 排列 | 完整數字低音 | 常用省略 |
|------|--------|------|------------|---------|
| 原位（Root Position） | 根音 C | C–E–G–B♭ | 7/5/3 | **7** |
| 第一轉位（1st Inversion） | 三音 E | E–G–B♭–C | 6/5/3 | **6/5** |
| 第二轉位（2nd Inversion） | 五音 G | G–B♭–C–E | 6/4/3 | **4/3** |
| 第三轉位（3rd Inversion） | 七音 B♭ | B♭–C–E–G | 6/4/2 | **4/2**（或 **2**） |

> **數字低音怎麼算？** 數字代表最低音到各上方音的音程度數。以第二轉位 G–B♭–C–E 為例：G→B♭ = 3度、G→C = 4度、G→E = 6度，完整寫法 6/4/3，省略 6 後常寫 4/3。

> 第三轉位是七和弦獨有的（三和弦只有三位置），數字低音「2」意謂低音上方有二度音程，聽感特別不穩定，在古典對位中幾乎必須向內半音解決。

## 4. 屬七的特殊地位

在所有七和弦中，**屬七和弦（Dominant 7th）是最重要的一種**。

### 三全音的張力

C 屬七和弦（C7）= C–E–G–B♭。其中，**三音 E 和七音 B♭ 之間**形成了**三全音（tritone = 增四度 / 減五度，6 半音）**：

```
E ─────────── B♭
  ←  6 半音  →
  （三全音，tritone）
```

三全音是西洋音樂裡最不穩定、張力最強的音程。它「迫使」和弦向前解決（resolve）。

### C7 → F 的解決（V7 → I in F major）

> **羅馬數字級數**：大調音階有七個音，每個音上可以建一個和弦，用 I、II、III、IV、V、VI、VII 標記（詳見 [concept_scale_and_key §7](concept_scale_and_key.md)）。V = 第五級（屬音），I = 第一級（主音）。V7 就是「在第五級上建的七和弦」。

C 是 F 大調的第 V 級（屬音），所以 C7 是 F 大調的屬七和弦，自然解決到 I 級的 F 大三和弦（主和弦）。

```
C7（F 大調 V7）解決到 F（F 大調 I）

C7：  C   –  E   –  B♭  –  G
      根音    三音    七音    五音
      ↓       ↓       ↓       ↓
F：   C   –  F   –   A   –  C'

三全音的動向（相鄰兩聲部各走半音）：
  E（三音）→ F   （半音上行，解決到主音）
  B♭（七音）→ A   （半音下行，解決到三音）
其餘聲部：
  C（根音）→ C   （共同音保留）
  G（五音）→ C'  （可自由移動，此處選擇上行到根音以構成完整和弦）
```

鍵盤示意：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●   ↑        ← C7（C–E–G–B♭）
              │       │   │
              ↓           ↓
          ●       ●   ↑              ← F（F–A–C）
  ●           ●
  F           A
```

- **E → F**：上行半音，「導音式」解決（leading-tone resolution）
- **B♭ → A**：下行半音，「七音」解決（seventh resolution）
- C 和 G 可以保持不動或重組

### V7 → I：調性音樂的引擎

> 屬七和弦（V7）→ 主和弦（I）是西洋調性音樂裡**最強的和聲動力**。從巴哈到流行樂，這個進行無處不在。沒有 V7，音樂的「回家感」（cadence）就大打折扣。

和弦功能的完整體系，見：[concept_chord_function](concept_chord_function.md)

## 5. 大調音階上的七和弦

把 [concept_triad](concept_triad.md) 中每個級數的三和弦再往上疊一個三度，就得到七個**順階七和弦（diatonic seventh chords）**。

### C 大調的七個順階七和弦

C 大調音階：C–D–E–F–G–A–B

| 級數 | 和弦 | 組成音 | 類型 | 符號 |
|------|------|--------|------|------|
| I | Cmaj7 | C–E–G–B | 大七和弦（Major 7th） | IΔ7 |
| ii | Dm7 | D–F–A–C | 小七和弦（Minor 7th） | ii7 |
| iii | Em7 | E–G–B–D | 小七和弦（Minor 7th） | iii7 |
| IV | Fmaj7 | F–A–C–E | 大七和弦（Major 7th） | IVΔ7 |
| V | G7 | G–B–D–F | 屬七和弦（Dominant 7th） | V7 |
| vi | Am7 | A–C–E–G | 小七和弦（Minor 7th） | vi7 |
| vii | Bø7 | B–D–F–A | 半減七和弦（Half-dim） | viiø7 |

```
大調順階七和弦性質規律：
I     ii    iii   IV    V     vi    vii
Δ7    m7    m7    Δ7    7     m7    ø7
大七  小七  小七  大七  屬七  小七  半減七
```

> **口訣**：大調裡只有 **V 級是屬七**（大三和弦 + 小七），I 和 IV 是大七，ii / iii / vi 是小七，vii 是半減七。這個分布是固定的，換任何大調都一樣。

## 6. 小測驗

試著回答以下問題（答案在下方）：

1. 以 A 為根音，建構一個屬七和弦（dominant 7th），組成音是什麼？
2. 在 G7（G-B-D-F）中，哪兩個音形成三全音（tritone）？這個三全音在 V7→I 解決時分別走向哪裡？
3. Dm7 的組成音是 D-F-A-C。它屬於五種常見七和弦中的哪一種？為什麼？
4. 在 F 大調中，V7 級的順階七和弦是什麼和弦？組成音是什麼？
5. 大七和弦（Cmaj7 = C-E-G-B）和屬七和弦（C7 = C-E-G-Bb）只差一個音。是哪個音？這個差異造成什麼聽感上的不同？
6. 以 D 為根音，建構一個半減七和弦（half-diminished 7th），組成音是什麼？
7. 減七和弦（dim7）和增三和弦有一個共同的結構特性——都是等距的。Cdim7 的四個音各相距幾個半音？這產生什麼特殊後果？
8. 七和弦有四個轉位（含原位）。第三轉位的最低音是哪個音？它的數字低音符號是什麼？
9. C 大調的順階七和弦中，只有一個級數是屬七和弦，只有一個是半減七和弦。分別是哪一級？
10. 小七和弦（Cm7）和屬七和弦（C7）的根音到七音距離都是 10 半音（小七度），但三音不同。請比較兩者的三音，並說明為什麼聽感截然不同。

<details>
<summary>答案</summary>

1. **A-C#-E-G** — 屬七和弦公式：1-3-5-b7 = 大三和弦 + 小七度。A 大三和弦 = A-C#-E，加上小七度（A 往上 10 半音）= G。
2. **B 和 F** — B→F 是減五度（= 增四度 = 6 半音 = 三全音）。在 G7→C 的解決中，B（導音）半音上行解決到 C，F（七音）半音下行解決到 E。
3. **小七和弦（Minor 7th）** — 公式 1-b3-5-b7。D→F 是小三度（b3），D→A 是完全五度（5），D→C 是小七度（b7，10 半音）。三和弦基礎是小三和弦，加上小七度 = 小七和弦。
4. **C7（C-E-G-Bb）** — F 大調音階：F-G-A-Bb-C-D-E，V 級根音 = C，順階堆三度到七音：C-E-G-Bb。C→E 大三度、C→Bb 小七度 = 屬七和弦。
5. **七音不同：Cmaj7 的七音是 B（大七度，11 半音），C7 的七音是 Bb（小七度，10 半音）** — 大七和弦聽起來溫暖、夢幻、帶有「不完全的滿足」；屬七和弦因為三音 E 和七音 Bb 之間形成三全音（tritone），充滿強烈張力，「必須」向前解決。一個半音的差異，讓一個和弦安定，另一個和弦急切。
6. **D-F-Ab-C** — 半減七和弦公式：1-b3-b5-b7。D→F 小三度（3 半音），F→Ab 小三度（3 半音），Ab→C 大三度（4 半音）。D→Ab 減五度（6 半音），D→C 小七度（10 半音）。符號：Dø7。
7. **各相距 3 個半音（小三度）** — C-Eb-Gb-Bbb（= A），3+3+3+3 = 12 半音 = 一個八度。因為完全等距對稱，任何一個音都可以視為根音：Cdim7 = Ebdim7 = Gbdim7 = Adim7（等音解釋下）。12 個音只能組成 3 組不同的減七和弦。
8. **最低音是七音（Seventh），數字低音符號是 4/2（或簡寫 2）** — 以 C7 為例，第三轉位 = Bb-C-E-G，最低音 Bb 是七音。低音上方有二度（Bb→C），聽感特別不穩定，在古典對位中幾乎必須解決。
9. **V 級是屬七和弦，vii 級是半減七和弦** — C 大調：V7 = G7（G-B-D-F，大三和弦+小七度），viiø7 = Bø7（B-D-F-A，減三和弦+小七度）。其餘級數為大七（I、IV）或小七（ii、iii、vi）。
10. **Cm7 的三音是 Eb（b3，小三度），C7 的三音是 E（3，大三度）** — 小七和弦（Cm7）以小三和弦為基礎，聽感柔和、圓潤、帶憂鬱；屬七和弦（C7）以大三和弦為基礎，三音 E 與七音 Bb 形成三全音（6 半音），製造強烈的解決張力。同樣的七度，配上不同的三音，一個「安靜流動」，一個「急需前進」。

</details>

## 7. 下一步

七和弦在五音上疊了一個三度，得到七音。如果繼續往上再疊一個三度：

```
 七和弦：  根音 + 三音 + 五音 + 七音
 九和弦：  根音 + 三音 + 五音 + 七音 + 九音
                                        ↑
                               距根音九度（= 八度 + 二度）
```

這些「七音以上的延伸」稱為**延伸和弦（Extended Chords）**：9th、11th、13th。爵士和弦常以此堆疊，產生豐厚的色彩層次。詳見：[concept_extended_chord](concept_extended_chord.md)
