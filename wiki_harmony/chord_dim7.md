# 減七和弦（Diminished 7th）

## 組成

- **結構公式**：1 – ♭3 – ♭5 – 𝄫7（double-flat 7th，即降降七音 = 大六度）
- **音程堆疊**：小三度（m3）+ 小三度（m3）+ 小三度（m3）
- **半音總跨距**：9 個半音（大六度）

四音完全由**等距的小三度**堆疊而成，每層相差 3 個半音。

**𝄫7 的理解**：理論上寫作「減七度」，但實際音高等同於大六度（enharmonic）。例如 C°7 的最高音，理論記譜為 B𝄫（B double-flat），聽起來等同於 A。

**Symbol（記號）**：Cdim7、C°7。

## 對稱性：只有 3 個不同的減七和弦

減七和弦是高度對稱的和弦——由於四音等距，**每移動 3 個半音（小三度）就得到相同的組成音集合**：

- **C°7 = E♭°7 = G♭°7 = A°7**（均含 C、E♭、G♭、A 四音）
- **C#°7 = E°7 = G°7 = B♭°7**（均含 C#、E、G、B♭ 四音）
- **D°7 = F°7 = A♭°7 = B°7**（均含 D、F、A♭、B 四音）

12 個根音，實際上只有 **3 種不同的音高集合**，異名同音（enharmonic）是關鍵。

## 轉位

以 C°7（C-E♭-G♭-A）為例：

| 位置 | 音排列 | 說明 |
|------|--------|------|
| **根音位置**（Root position） | C – E♭ – G♭ – A（=B𝄫） | 根音在最低聲部 |
| **第一轉位**（1st inversion） | E♭ – G♭ – A – C | ♭3 音在最低聲部 |
| **第二轉位**（2nd inversion） | G♭ – A – C – E♭ | ♭5 音在最低聲部 |
| **第三轉位**（3rd inversion） | A – C – E♭ – G♭ | 𝄫7 音在最低聲部 |

由於四音等距，轉位後可以**重新理解為另一個根音的減七和弦**：C°7 的第一轉位（E♭-G♭-A-C）等同於 E♭°7 的根音位置。

## 常見用法

- **vii°7/V（經過減七）**：如 C 大調中，在 F 與 G 之間插入 F#°7，低音半音上行 F → F# → G，帶來流暢的半音經過。
- **vii°7 解決**：在和聲小調中，vii°7 → i 是最強烈的終止之一（如 B°7 → Cm）。
- **Passing diminished（經過和弦）**：在相鄰同功能和弦之間插入，上行如 C → C#°7 → Dm，或下行如 Dm → C#°7 → C。
- **戲劇性張力**：電影配樂、浪漫主義鋼琴曲（如蕭邦）中，dim7 長時間持續帶來懸疑、恐懼感。
- **重新解讀（Re-harmonization）**：因為只有 3 種音集合，dim7 可以從 4 個根音方向解決，提供豐富的和聲彈性。

## 鍵盤應用

- 右手常用指法（根音位置）：**1–2–3–5**
- 四音等距，轉位時手形幾乎相同，練好一個根音等於練好全部四個。
- 常見練習：C°7 → Cmaj7/C（下行解決），或 B°7 → Cmaj7（半音上行導音解決）。
- 由於對稱性，只需學 3 組指法即可涵蓋全部 12 個根音：C°7、C#°7、D°7。

→ 指法詳見 [和弦指法](../wiki_piano/concept_chord_fingering.md)

## 聽覺特徵

**極度緊張、戲劇性、懸疑感**——減七和弦是西洋音樂中張力最強的和弦之一，四層等距小三度製造出無方向性的漂浮感與強烈的不穩定；聽者會本能地感到恐懼或期待，要求立即解決。它是浪漫主義鋼琴曲與電影配樂的戲劇性標配音效。
