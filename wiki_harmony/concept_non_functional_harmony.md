# 非功能和聲（Non-Functional Harmony）

> 前置知識：[concept_chord_function — 和弦功能](concept_chord_function.md)（T/S/D 三大功能、功能流向）
> 建議先讀：[concept_modes — 教會調式](concept_modes.md)（七種調式的結構與色彩）

在功能和聲的世界裡，和弦有「職責」：主功能安定、下屬功能出發、屬功能渴望回家，V→I 是最強的引力。但並非所有音樂都遵循這套邏輯——當作曲者選擇和弦不是因為「它該去哪裡」，而是因為「它聽起來什麼感覺」，我們就進入了**非功能和聲（Non-Functional Harmony）**的領域。

---

## 1. 什麼是非功能和聲

### 功能和聲的回顧

在功能和聲（functional harmony）中：

- 每個和弦都有角色（T / S / D）
- 和弦之間有明確的「引力」——V「想要」解決到 I
- 音樂有清楚的調性中心（tonal center）
- 進行遵循 T → S → D → T 的流向

### 非功能和聲的特點

非功能和聲（non-functional harmony）則完全不同：

- 和弦的選擇基於**色彩（color）和音響效果（sonority）**，而非功能角色
- 沒有清楚的調性中心，或調性中心不斷移動
- 和弦之間不存在「必須去哪裡」的引力
- 重點是**氛圍（atmosphere）**而非**方向（direction）**

### 哪裡會聽到？

非功能和聲在許多音樂風格中極為常見：

| 風格 | 代表 | 特徵 |
|------|------|------|
| 印象派 | Debussy、Ravel | 平行和弦、全音階、色彩優先 |
| 電影配樂 | Hans Zimmer、John Williams | 對稱結構、三度中音關係 |
| 環境音樂 | Brian Eno | 持續和弦、極簡反覆 |
| 遊戲 OST | 多數 RPG 配樂 | 調式和聲、氛圍營造 |
| 現代流行 | Radiohead、Billie Eilish | 調式互換、半音平移 |

> **關鍵區別**：功能和聲像「敘事」——有起承轉合；非功能和聲像「畫面」——重點是此刻的色彩和感受。

## 2. 常見手法

### 2.1 平行和弦移動（Parallel / Planing）

**定義**：把同一個和弦形狀（chord shape）沿半音或全音上下平移，不考慮調性歸屬。

```
Cmaj7 → D♭maj7 → Dmaj7 → E♭maj7
  ↑        ↑        ↑        ↑
全部都是大七和弦，只是根音半音上行
```

- 所有和弦都是 maj7，彼此之間沒有功能關係
- 聽感：像一面色彩漸層的牆，平滑、夢幻
- Debussy 在鋼琴曲和管弦樂中大量使用這個手法

**為什麼「非功能」？** 在 C 大調裡，D♭maj7 和 E♭maj7 都不是自然音階和弦，它們出現純粹是因為「和弦形狀相同」這個聲響邏輯，不是因為級數功能。

### 2.2 持續和弦（Constant Structure / Pedal）

**定義**：兩個和弦在持續低音（pedal bass）上方交替，或同一種和弦類型放在不同根音上反覆。

```
持續低音 C ─────────────────────────
上方和弦：  Cm7    D♭maj7   Cm7    D♭maj7
           交替      交替     交替     交替
```

- Cm7 和 D♭maj7 交替 = 調式氛圍循環（modal vamp）
- 沒有解決方向，營造出懸浮、靜態的感覺
- 適合：電影中的懸疑場景、環境音樂、冥想音樂

**為什麼「非功能」？** 沒有 V→I 的解決、沒有引力方向，和弦只是在兩種色彩之間擺盪。

### 2.3 調式和聲（Modal Harmony）

**定義**：和弦來自某個調式（mode），刻意避開 V→I 的功能進行。

**Dorian 循環**：

```
Dm7 ↔ Em7（只有兩個和弦，不斷交替）
 i      ii（D Dorian 的 i 和 ii）
```

- 沒有屬和弦（dominant），沒有導音解決
- Miles Davis 的 "So What" 就是純粹的 Dorian 和聲——整首歌只用兩個和弦
- 聽感：浮游、冷靜、不急著去哪裡

**Lydian 靜態**：

- 一個大和弦加上 #4 的色彩（例如 Cmaj7#11）
- #4 讓和弦聽起來「打開」、明亮、帶有奇幻感
- 電影配樂中常用來表現「壯闊」或「神秘」

**為什麼「非功能」？** 調式和聲的核心是「留在一個色彩裡」，而非「從 A 走到 B」。沒有 V→I，就沒有傳統意義的解決。

### 2.4 對稱結構（Symmetric / Chromatic Mediant）

**定義**：和弦根音按等距音程排列（大三度或小三度），形成對稱的環形結構。

**大三度循環**（把八度分成三等份）：

```
C → E → A♭ → C
  M3   M3   M3
```

**小三度循環**（把八度分成四等份）：

```
C → E♭ → G♭ → A → C
  m3    m3    m3   m3
```

- 這些和弦在傳統調性中沒有共同的調——它們「跳出」了功能系統
- 電影配樂大量使用，製造「異世界」、「超自然」的感覺
- John Williams 在星際大戰配樂中多次使用三度中音關係（chromatic mediant）

**為什麼「非功能」？** 和弦根音不遵循五度圈邏輯，無法歸入任何單一調的 T/S/D 框架。

### 2.5 只用兩個和弦（Two-Chord Vamp）

**定義**：兩個和弦不斷交替，沒有解決傾向，營造氛圍與質地（texture）。

| 範例 | 根音關係 | 聽感 |
|------|---------|------|
| C → D♭ | 半音上移 | 緊張、不安 |
| Am → Bm | 全音上移 | 流動、漂浮 |
| Cmaj7 ↔ Dmaj7 | 全音交替 | 明亮、開闊 |

- 重點不是「敘事」，而是「沉浸在某種情緒裡」
- Lo-fi、chillhop、環境音樂的根基
- 功能和聲像散文，兩和弦循環像一句不斷重複的詩

## 3. 功能 vs 非功能：不是非黑即白

實際音樂很少是純粹的功能或純粹的非功能——大多數作品**混合使用**兩者。

### 流行歌曲

- **主歌（verse）**：功能和聲，I → vi → IV → V，有方向感
- **橋段（bridge）**：突然切入平行和弦或調式循環，製造「跳脫」感
- **回到副歌（chorus）**：V → I 解決，回歸功能

### 電影配樂

- **動作場景**：功能和聲驅動張力和解決（D → T 的反覆）
- **氛圍場景**：非功能和聲營造空間感（持續和弦、調式靜態）
- **轉場**：對稱結構製造「世界切換」的感覺

### 爵士

- **標準曲（standard）**：ii → V → I 是骨架（功能）
- **調式爵士（modal jazz）**：一個和弦停留 8-16 小節（非功能）
- 很多樂手在同一首曲子裡自由切換兩種思維

> **記住**：功能和非功能是一條光譜，不是兩個箱子。學會辨認「此刻音樂在光譜的哪裡」，比硬性分類更有用。

---

## 4. 如何判斷是非功能和聲

當你分析一段音樂時，以下四個跡象暗示你正在聽非功能和聲：

| 跡象 | 說明 |
|------|------|
| **沒有 V→I 或 ii→V→I** | 缺乏傳統的屬到主解決 |
| **和弦根音不走五度圈** | 根音移動是半音、全音、三度，而非四/五度 |
| **同一種和弦類型反覆出現** | 例如全部都是 maj7 或全部都是 m7，只換根音 |
| **找不到「家」** | 沒有一個和弦聽起來像明確的終點 |

**實用測試**：如果你嘗試用羅馬數字標記一段進行，發現標不出來、或標出來的數字看起來毫無邏輯（例如 ♭II → ♭III → ♭VI → ♭VII），那很可能是非功能和聲。

## 5. 小測驗

試著回答以下問題（答案在下方）：

1. 功能和聲選擇和弦的依據是什麼？非功能和聲呢？
2. 什麼是平行和弦移動（planing）？請舉一個例子。
3. Dm7 ↔ Em7 的循環屬於非功能和聲的哪種手法？為什麼它是「非功能」的？
4. 大三度循環 C → E → A♭ → C 為什麼被認為是非功能的？
5. 兩和弦循環（two-chord vamp）的重點是什麼？它和功能和聲的 I → V 交替有什麼不同？
6. 在電影配樂中，功能和聲通常用在什麼類型的場景？非功能和聲呢？
7. 請列出判斷非功能和聲的四個跡象中的任意兩個。
8. Lydian 調式的特徵音是什麼？為什麼它常被用來營造奇幻或壯闊的感覺？
9. 持續和弦（pedal）手法中，低音的作用是什麼？上方和弦的行為又是什麼？
10. 為什麼說「功能 vs 非功能不是非黑即白」？請舉一個混合使用的例子。

<details>
<summary>答案</summary>

1. **功能和聲根據和弦的功能角色（T/S/D）和引力方向來選擇和弦**，例如 V 接 I 是因為屬功能渴望解決到主功能。**非功能和聲根據色彩和音響效果選擇和弦**，不考慮功能歸屬，重點是「聽起來什麼感覺」。
2. **平行和弦移動是把同一個和弦形狀沿半音或全音平移。** 例如 Cmaj7 → D♭maj7 → Dmaj7 → E♭maj7，全部都是大七和弦，根音半音上行，和弦之間沒有功能關係。
3. **調式和聲（modal harmony）。** 這是 D Dorian 的 i 和 ii 交替，沒有屬和弦（dominant），沒有導音（leading tone）解決到主音，因此缺乏 V→I 的功能引力，和弦只是在兩個調式色彩之間擺盪。
4. **因為 C、E、A♭ 三個大三和弦無法歸入任何單一調的功能體系。** 它們的根音按等距大三度排列（把八度分成三等份），不遵循五度圈邏輯，無法標記為同一個調的 I、IV、V 等級數。
5. **兩和弦循環的重點是營造氛圍和質地（texture），讓聽者沉浸在某種情緒裡。** 與功能和聲的 I → V 不同：I → V 有明確的「離家→想回家」引力方向，而非功能的兩和弦循環（如 C → D♭ 或 Cmaj7 ↔ Dmaj7）沒有解決傾向，只是在兩種色彩之間反覆。
6. **功能和聲通常用在動作場景**，利用 D → T 的張力與解決來驅動戲劇性。**非功能和聲通常用在氛圍場景**，利用持續和弦、調式靜態或對稱結構來營造空間感和情緒。
7. 任意兩個即可：(1) 沒有 V→I 或 ii→V→I 進行；(2) 和弦根音不走五度圈，而是半音、全音或三度移動；(3) 同一種和弦類型反覆出現在不同根音上；(4) 找不到明確的「家」和弦。
8. **Lydian 調式的特徵音是 #4（升四度）。** 相較於普通大調的完全四度，#4 消除了四度音對主音的下行引力，讓和弦聽起來「打開」、明亮且懸浮，不急著解決，因此常被用來營造奇幻、壯闘或超然的感覺。
9. **低音（pedal bass）保持不動，提供一個穩定的錨點。** 上方的和弦則在不同色彩之間交替（例如 Cm7 和 D♭maj7），因為低音不變，和弦的切換聽起來不像「移動」而像「色彩閃爍」，營造出懸浮、靜態的氛圍。
10. **大多數音樂混合使用功能和非功能手法。** 例如一首流行歌的主歌可能是功能進行（I → vi → IV → V），而橋段突然切入平行和弦移動或調式循環，製造跳脫感，然後副歌再用 V → I 回歸功能和聲。

</details>
