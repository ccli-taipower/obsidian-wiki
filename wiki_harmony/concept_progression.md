# 和弦進行（Chord Progression）

---

## 1. 什麼是和弦進行

**和弦進行（chord progression）**是一首歌裡依序出現的一串和弦——它構成了音樂的**和聲骨架**。旋律、節奏、歌詞都可以完全不同，但如果底下的和弦進行一樣，聽者就會感覺到一種熟悉的「氣氛」。

這也是為什麼 Let It Be 和 Someone Like You 「聽起來感覺相近」——儘管旋律截然不同，它們共用了幾乎相同的四個和弦。和弦進行就像故事的情節架構，旋律是上面說的台詞，可以千變萬化，但骨架的走法決定了情緒的方向。

理解常見和弦進行，你就能在聽到一首歌的前幾秒「認出」它的骨架，也能在鍵盤上即興重現它——這是從被動聆聽走向主動音樂的關鍵一步。

---

## 2. 常用進行

以下 8 個進行涵蓋了流行、古典、爵士、藍調的核心，幾乎能解釋你日常聽到的大多數歌曲。所有範例使用 **C 大調**。

---

### 2-a．I–IV–V–I（最基本古典進行）

**公式**：I → IV → V → I

**C 大調具體和弦**：C → F → G → C

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I   (C):  C–E–G   ●   ●   ●
IV  (F):  F–A–C       ●   ●   ●
V   (G):  G–B–D           ●   ●   ●
I   (C):  C–E–G   ●   ●   ●   ← 回家
```

**功能分析**：T → S → D → T — 最完整的張力–釋放循環。

**代表曲目**：〈Twinkle Twinkle Little Star〉、大量民謠與鄉村歌曲、巴哈眾多聖詠。

**為什麼好聽**：這是功能和聲最「教科書」的版本。I 穩定出發，IV 製造流動感，G 集中所有緊張能量，最後 C 的到來讓人深吸一口氣。正因為太工整，現代流行歌反而少用純 I–IV–V–I，更多是下面的變體。

---

### 2-b．I–V–vi–IV（流行四和弦）

**公式**：I → V → vi → IV

**C 大調具體和弦**：C → G → Am → F

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I   (C):   C–E–G   ●   ●   ●
V   (G):   G–B–D           ●   ●   ●
vi  (Am):  A–C–E   ●   ●       ●
IV  (F):   F–A–C       ●   ●   ●
```

**功能分析**：T → D → T（vi 作為主功能的替代）→ S — 不按傳統方向走，卻因為 vi 帶來情感轉折，形成更豐富的循環。

**代表曲目**：〈Let It Be〉（Beatles）、〈Someone Like You〉（Adele）、〈小幸運〉（田馥甄）、〈Payphone〉（Maroon 5）。

**為什麼好聽**：這是 21 世紀流行歌使用率最高的進行。C → G 明亮有力，接著 Am 的出現帶來一絲柔情甚至憂傷，F 像是在說「但一切都還好」——四個和弦的情緒弧線非常完整，從自信、渴望、惆悵到接受，一圈走完。

---

### 2-c．vi–IV–I–V（暗色四和弦）

**公式**：vi → IV → I → V

**C 大調具體和弦**：Am → F → C → G

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

vi  (Am):  A–C–E   ●   ●       ●
IV  (F):   F–A–C       ●   ●   ●
I   (C):   C–E–G   ●   ●   ●
V   (G):   G–B–D           ●   ●   ●
```

**功能分析**：T（vi）→ S → T → D — 和 I–V–vi–IV 是同一組四個和弦的**旋轉（rotation）**，但從 vi 開始，整個氣氛偏向小調感、更帶惆悵。

**代表曲目**：〈Despacito〉（Luis Fonsi）、〈可惜不是你〉（梁靜茹）、〈Hello〉（Adele）。

**為什麼好聽**：以 vi（Am）開場，第一個和弦就是小三和弦，天生帶憂鬱。這讓整個進行「暗了半格」，特別適合帶著遺憾或渴望情緒的歌詞。和 2-b 相比，旋律可以完全一樣，但起點不同就帶來截然不同的感受。

---

### 2-d．I–vi–IV–V（50s / Doo-wop 進行）

**公式**：I → vi → IV → V

**C 大調具體和弦**：C → Am → F → G

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I   (C):   C–E–G   ●   ●   ●
vi  (Am):  A–C–E   ●   ●       ●
IV  (F):   F–A–C       ●   ●   ●
V   (G):   G–B–D           ●   ●   ●   ← 回到 I 繼續循環
```

**功能分析**：T → T（vi）→ S → D — 最符合「T–S–D 流向」的變體，vi 作為 I 的情感延伸，再流向 S 和 D。

**代表曲目**：〈Stand By Me〉（Ben E. King）、〈月亮代表我的心〉（鄧麗君）、〈Earth Angel〉，以及幾乎整個 1950–60 年代的 doo-wop 風格。

**為什麼好聽**：C 落地之後不急著離開，先用 Am 在主功能稍微停留（多一個「柔軟著陸」的感覺），然後 F → G 提供了一個完整的推進動力，讓循環想一遍又一遍地轉下去。節奏上常是 ♩♩♩♩ 的 shuffle 感，讓人忍不住搖頭晃腦。

---

### 2-e．ii–V–I（爵士核心進行）

**公式**：ii → V → I

**C 大調具體和弦（加上七音）**：Dm7 → G7 → Cmaj7

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

ii7   (Dm7):   D–F–A–C       ●   ●   ●   ●
V7    (G7):    G–B–D–F   ●   ●   ●   ●
Imaj7 (Cmaj7): C–E–G–B   ●   ●   ●       ●
```

**功能分析**：S（ii7）→ D（V7）→ T（Imaj7）— 三步直線，每一步都是和聲引力最強的方向，是功能和聲的「最短最有效路徑」。

**代表曲目**：幾乎每一首爵士標準曲（jazz standard）都有 ii–V–I，如〈Autumn Leaves〉、〈All The Things You Are〉、〈Fly Me to the Moon〉。

**為什麼好聽**：ii 的根音 D 到 V 的根音 G 是純五度下行（circle of fifths 的一步），G 的根音到 I 的根音 C 也是純五度下行——兩步都走五度圈，是和聲引力最強的根音移動。加上 V7（G7）裡的三全音（B↔F）在 Cmaj7 中完美解決（B → C，F → E），功能和聲的「磁性」幾乎達到最大值。

---

### 2-f．I–IV–vi–V（卡農進行變體）

**公式**：I → IV → vi → V

**C 大調具體和弦**：C → F → Am → G

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I   (C):   C–E–G   ●   ●   ●
IV  (F):   F–A–C       ●   ●   ●
vi  (Am):  A–C–E   ●   ●       ●
V   (G):   G–B–D           ●   ●   ●   ← 停在 D 功能，等待回家
```

**功能分析**：T → S → T（vi）→ D — 和 2-b 相比，中間把 V 和 vi 的位置對調，先走 S 再出現 vi，最後 V 壓軸製造懸念，等待下一輪的 I。

**代表曲目**：〈Let It Go〉（Frozen，《冰雪奇緣》）、Pachelbel《D 大調卡農》（歷史最著名的使用者）。

**為什麼好聽**：卡農原曲以連續下行低音線搭配上方和聲，而這個進行的音符共同音多（C 在 C、F、Am 裡都有，E 在 C 和 Am 裡都有），相鄰和弦轉換非常順滑，幾乎感覺不到明顯的「切換」，整個進行流動而夢幻。

---

### 2-g．12 小節藍調（12-bar Blues）

**公式**（12 小節）：

```
| I7  | I7  | I7  | I7  |
| IV7 | IV7 | I7  | I7  |
| V7  | IV7 | I7  | V7  |
```

**C 大調具體和弦**：

```
| C7  | C7  | C7  | C7  |
| F7  | F7  | C7  | C7  |
| G7  | F7  | C7  | G7  |（末尾 G7 稱為 turnaround，引回下一輪）
```

**鍵盤圖示（單輪核心和弦）**：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I7  (C7):  C–E–G–Bb  ●   ●   ●         ● （Bb = A#，黑鍵）
IV7 (F7):  F–A–C–Eb      ●   ●   ●   ● （Eb = D#，黑鍵）
V7  (G7):  G–B–D–F           ●   ●   ●   ●
```

**關鍵特色**：全部三個和弦都是**屬七和弦（dominant 7th）**，包括理論上應該是主功能的 I 也用 I7。這讓整個藍調帶著一種「永遠沒有完全解決」的張力，反而形成了藍調的標誌性情緒——悲喜交雜、輾轉不息。

**代表曲目**：〈Johnny B. Goode〉（Chuck Berry）、〈Blue Suede Shoes〉（Elvis）、〈Hound Dog〉，以及幾乎所有早期搖滾和藍調。

**為什麼好聽**：12 小節藍調是一套**完整的故事框架**——前四小節「說出問題」（I7），中間四小節「感嘆一次」（IV7 → I7），最後四小節「爆發後緩緩落地」（V7 → IV7 → I7），然後 turnaround（G7）把聽眾帶回下一輪。就算只有三個和弦，12 小節的結構讓它永遠說不膩。

---

### 2-h．IV–V–iii–vi（4536 華語流行進行）

**公式**：IV → V → iii → vi

**C 大調具體和弦**：F → G → Em → Am

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

IV  (F):   F–A–C       ●   ●   ●
V   (G):   G–B–D           ●   ●   ●
iii (Em):  E–G–B       ●   ●   ●
vi  (Am):  A–C–E   ●   ●       ●   ← 落在 vi，帶憂傷感
```

**功能分析**：S → D → T（iii 作為主功能）→ T（vi）— 以下屬開場，先製造出發感，V → Em 讓緊張以一種「不那麼完全」的方式落地，vi 的出現帶來情感的餘韻，是這個進行獨特之處。

**代表曲目**：〈小情歌〉（蘇打綠）、〈那些年〉（胡夏）、〈告白氣球〉（周杰倫）、大量日系 J-pop 如〈愛にできることはまだあるかい〉。

**為什麼好聽**：這是華語流行和 J-pop 的「隱藏招牌」，在台灣有個口語稱呼叫「4536 進行」（指音階的第 4、5、3、6 級）。以 IV（F）起頭製造流動感和期待，V 推動情緒到頂點，但接的不是 I 而是 iii → vi，讓解決感來得「側面」而帶著一絲甜美憂傷。聽眾不覺得完全落地，反而帶著輕飄飄的感覺繼續轉下一圈。

## 3. 為什麼這些進行好聽

### 共同音（Common Tones）讓轉換平滑

相鄰和弦之間往往有**一個或多個共同音**——比如 C（C–E–G）和 Am（A–C–E）共享 C 和 E 兩個音，轉換時耳朵感受到的「跳動」很小，聽起來流暢自然。這就是為什麼 vi 常被用來替代 I（「副主和弦代理 tonic substitution」），效果柔和而不突兀。

### 功能流向（Functional Flow）製造張力與釋放

T → S → D → T 的循環構建了情緒的「出發–緊張–回家」弧線。每個方向的移動都有其引力：D → T 最強（導音解決），S → D 次之（準備推進），T → S 最溫和（離家出發）。多數流行進行不嚴格遵守這個順序，但最能讓人「感到滿足」的結尾幾乎都以 D → T 收尾。

### 五度圈移動（Circle of Fifths Motion）

和聲引力最強的根音移動是**純五度下行**（或等效的純四度上行）：G → C、D → G、A → D……這正是 ii–V–I 的核心，也是藍調中 V7 → I7 的力量來源。每當進行裡出現連續的五度圈移動，聽者會感覺到一種「不可抗拒地被拉著走」的感覺——那就是功能和聲最原始的魔法。

## 4. 自己動手

### 第一步：在 C 大調彈奏所有進行

依照本頁的鍵盤圖示，用右手在 C 大調把上面 8 個進行各彈 2–4 輪。注意聽：
- 哪一個進行讓你想到你聽過的某首歌？
- vi 出現時情緒怎麼改變？
- V7 的那種「不穩定、等待解決」感覺有多明顯？

### 第二步：移調到 G 大調

G 大調是練習移調最方便的選擇（鋼琴上只多一個黑鍵 F#）。技巧：**把所有音往上移 7 個半音（純五度）**：

| C 大調 | G 大調 |
|--------|--------|
| C      | G      |
| Dm     | Am     |
| Em     | Bm     |
| F      | C      |
| G      | D      |
| Am     | Em     |

以 I–V–vi–IV 為例：C–G–Am–F → **G–D–Em–C**。試著在 G 大調重彈一遍，注意聽聲音「高了一個五度」但情緒結構完全一樣。

### 第三步：找一首你喜歡的歌，試著「聽出」進行

很多流行歌的和弦進行在網路上都有 chord chart，找一首你喜歡的，對照本頁的 8 個進行，看看你能認出哪個骨架。

> 想深入了解移調的系統方法，前往 [concept_modulation](concept_modulation.md)。

## 5. 小測驗

試著回答以下問題（答案在下方）：

1. 一首歌的和弦進行是 C → G → Am → F（C 大調），這對應本頁的哪個常見進行模式？
2. 同樣是 C、G、Am、F 四個和弦，如果從 Am 開始（Am → F → C → G），情緒會有什麼變化？這對應哪個進行？
3. 把 I–V–vi–IV 從 C 大調移調到 G 大調，四個和弦分別變成什麼？
4. 12 小節藍調（12-bar blues）有一個特殊之處：I 級也用屬七和弦（如 C7）。這和一般大調中 I 級用大三/大七和弦有什麼聽感上的差別？
5. ii–V–I 進行（Dm7 → G7 → Cmaj7）被稱為爵士的「核心進行」。它的根音移動有什麼規律？為什麼這讓引力特別強？
6. I–vi–IV–V（50s 進行）和 I–V–vi–IV（流行四和弦）使用完全相同的四個和弦，但順序不同。比較兩者的功能流向，並解釋為什麼情緒感受不同。
7. 4536 進行（IV–V–iii–vi）在華語流行和 J-pop 中非常常見。V 之後接的是 iii 而非 I，這為什麼讓解決感「來得側面」？
8. 12 小節藍調的最後一個小節常用 V7（如 G7），這叫 turnaround。它的功能是什麼？
9. I–IV–vi–V（卡農進行變體）有一個特點：相鄰和弦之間共同音很多。以 C 大調為例，列出 C、F、Am 三個和弦的組成音，找出它們之間的共同音。
10. 你聽到一首歌的進行是 F → G → Em → Am（C 大調），它對應本頁哪個模式？如果移到 G 大調，四個和弦變成什麼？

<details>
<summary>答案</summary>

1. **I–V–vi–IV（流行四和弦，2-b）** — C=I, G=V, Am=vi, F=IV。這是 21 世紀流行歌使用率最高的進行，代表曲如〈Let It Be〉、〈Someone Like You〉。
2. **情緒偏暗、帶惆悵，對應 vi–IV–I–V（暗色四和弦，2-c）** — 同一組四個和弦的旋轉（rotation），但從小三和弦 Am 開始，第一個和弦就帶憂鬱。代表曲如〈Hello〉（Adele）。
3. **G–D–Em–C** — I=G, V=D, vi=Em, IV=C。所有音往上移純五度（7 半音）：C→G, G→D, Am→Em, F→C。級數關係不變，情緒結構完全相同。
4. **藍調中 I7 帶著「永遠沒有完全解決」的張力** — 一般大調中 I 級用大三或大七和弦，聽起來穩定、安定；藍調的 I7（含 b7）本身就是屬七和弦結構，帶著持續的張力和不安定感，形成藍調標誌性的「悲喜交雜」情緒。
5. **根音都是純五度下行（circle of fifths motion）：D → G（純五度下行），G → C（純五度下行）** — 純五度下行（或等效的純四度上行）是和聲引力最強的根音移動方向。ii–V–I 連續兩次走五度圈，加上 V7 裡的三全音（B↔F）在 Imaj7 中完美解決，引力幾乎達到最大值。
6. **I–vi–IV–V 的流向是 T→T(vi)→S→D，先在主功能停留，再流向 S 和 D；I–V–vi–IV 的流向是 T→D→T(vi)→S，V 提前製造張力，vi 意外接住** — 50s 進行感覺「穩重、輕搖」（先安穩再出發）；流行四和弦感覺「自信、轉折」（先衝刺再柔情）。起點相同但中間段的張力安排不同，造成不同的情緒弧線。
7. **因為 iii（Em）是主功能但不是 I** — V 之後聽眾期待完全落地到 I（C），但接到的是 iii（Em），它是主功能的「替代品」，有穩定感但「不完全到家」——像是從側門進了家。接著 vi（Am）再次延伸這種「差一步」的感覺，整個進行帶有甜美的未完成感。
8. **Turnaround 的功能是引導回到下一輪的 I 級** — 最後一個小節用 V7（如 G7），利用屬功能的張力「彈弓」回到開頭的 I7，讓 12 小節可以無縫循環。沒有 turnaround 的話，I7 直接回到 I7，缺乏方向感。
9. **C = C-E-G，F = F-A-C，Am = A-C-E** — C 和 F 共享 C；C 和 Am 共享 C 和 E（兩個共同音！）；F 和 Am 共享 A。特別是 C 這個音在三個和弦中都出現，讓整個進行的轉換極度平滑，幾乎感覺不到「切換」。
10. **4536 進行（IV–V–iii–vi，2-h）** — F=IV, G=V, Em=iii, Am=vi。移到 G 大調：IV=C, V=D, iii=Bm, vi=Em，進行變成 **C → D → Bm → Em**。

</details>
