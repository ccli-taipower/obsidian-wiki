# 三和弦（Triad）

三和弦是由**三個音**疊加而成的和弦（chord），是西洋調性音樂（tonal music）最基本的和聲單位。掌握三和弦，等於拿到了讀懂絕大多數流行、古典、爵士和弦進行的入場券。

從 [concept_interval](concept_interval.md) 你已知道：三度音程（3rd）是和聲的主力色彩。三和弦的核心就是把**兩個三度疊在一起**——下方三度決定和弦的「大小性格」，上方三度決定「尾音的穩定感」。

---

## 1. 三和弦定義

### 結構：兩個三度的疊加

三和弦由三個音組成，從下到上依序稱為：

| 位置 | 中文名 | 英文名 | 說明 |
|------|--------|--------|------|
| 最低音 | 根音 | Root | 和弦的命名基準，決定和弦叫什麼名字 |
| 中間音 | 三音 | Third | 距根音一個三度，決定大/小性格 |
| 最高音 | 五音 | Fifth | 距根音一個五度（= 兩個三度的頂端） |

用 C 大三和弦（C major triad）為例：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●
  根音        三音     五音
  C           E        G
  (Root)    (Third)  (Fifth)
```

- **C → E**：大三度（Major 3rd，4 半音）
- **E → G**：小三度（Minor 3rd，3 半音）
- **C → G**：完全五度（Perfect 5th，7 半音）= 大三度 + 小三度

> 記憶口訣：三和弦 = **根音 + 兩個疊起來的三度**。改變這兩個三度的性質，就得到不同種類的三和弦。

---

## 2. 四種三和弦

四種三和弦的差異，完全在於兩個三度的排列方式。以下均以 C 為根音示範。

### 比較總表

| 名稱 | 公式 | 下方音程 | 上方音程 | 總半音數（根→五） | 聽感 |
|------|------|---------|---------|----------------|------|
| 大三和弦（Major Triad） | 1–3–5 | 大三度（M3，4st） | 小三度（m3，3st） | 7st（P5） | 明亮、穩定、喜悅 |
| 小三和弦（Minor Triad） | 1–♭3–5 | 小三度（m3，3st） | 大三度（M3，4st） | 7st（P5） | 柔和、憂鬱、內斂 |
| 減三和弦（Diminished Triad） | 1–♭3–♭5 | 小三度（m3，3st） | 小三度（m3，3st） | 6st（d5） | 緊張、不穩定、收縮感 |
| 增三和弦（Augmented Triad） | 1–3–#5 | 大三度（M3，4st） | 大三度（M3，4st） | 8st（A5） | 懸浮、神秘、膨脹感 |

> 大三和弦與小三和弦的五音都是完全五度（P5），所以都有基本的穩定感——差別只在中間的三音。減三和弦的五音縮小（d5），增三和弦的五音拉大（A5），聽感因此更不穩定。

---

### 大三和弦（Major Triad）

**公式**：根音 + 大三度（M3）+ 小三度（m3）→ 組成音 1–3–5

C 大三和弦：**C–E–G**

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●
  C     M3→   E  m3→  G
        (4st)     (3st)
```

- 聽感：明亮、堅定、喜悅——是流行、古典中最常見的和弦。
- 詳細 12 個調的大三和弦指法與圖表：[chord_major](chord_major.md)

### 小三和弦（Minor Triad）

**公式**：根音 + 小三度（m3）+ 大三度（M3）→ 組成音 1–♭3–5

C 小三和弦：**C–E♭–G**（三音從 E 降半音變成 E♭）

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●       ↑       ●
  C      E♭       G
     m3→(3st) M3→(4st)
```

（鍵盤上 E♭ = D# 黑鍵，位於 D 右側）

- 聽感：柔和、略帶憂鬱——相較大三和弦，只有三音低半音，但情緒對比明顯。
- 詳細 12 個調的小三和弦指法與圖表：[chord_minor](chord_minor.md)

---

### 減三和弦（Diminished Triad）

**公式**：根音 + 小三度（m3）+ 小三度（m3）→ 組成音 1–♭3–♭5

C 減三和弦：**C–E♭–G♭**（三音和五音都降半音）

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●       ↑   ↑
  C      E♭  G♭
     m3→(3st) m3→(3st)
```

（鍵盤上 G♭ = F# 黑鍵，位於 F 右側）

- 根音到五音形成**減五度（d5）= 三全音（tritone）**——是最不穩定的音程，和弦充滿強烈張力。
- 聽感：收縮感、不安定，常出現在導音和弦（leading tone chord）位置。
- 詳細圖表：[chord_diminished](chord_diminished.md)

---

### 增三和弦（Augmented Triad）

**公式**：根音 + 大三度（M3）+ 大三度（M3）→ 組成音 1–3–#5

C 增三和弦：**C–E–G#**（五音從 G 升半音變成 G#）

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●         ↑
  C     M3→   E   M3→  G#
        (4st)      (4st)
```

- 根音到五音形成**增五度（A5）= 8 半音**——五音被「撐開」，和弦充滿懸浮感。
- 增三和弦有一個特殊性：三個音完全等距（各 4 半音），所以任何一個音都可以視為根音——它本身就是對稱的。
- 聽感：神秘、飄浮，常用於過渡與轉調。
- 詳細圖表：[chord_augmented](chord_augmented.md)

## 3. 轉位（Inversions）

### 什麼是轉位？

**原位（root position）**：根音在最低音。  
**轉位（inversion）**：把某個音移到最低音位置，根音依然是根音，但和弦的「聲音重心」改變了。

轉位不改變和弦的**名稱與性質**，只改變**最低音**。C 大三和弦不管哪個轉位，都還是叫「C 大三和弦」。

### C 大三和弦的三個位置

**原位（Root Position）**：最低音 = 根音 C

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●           ●       ●
  C           E       G
  ↑（最低）
```

**第一轉位（First Inversion）**：把最低音 C 移到上方，最低音改為 E

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │C' │
└───┴───┴───┴───┴───┴───┴───┴───┘
  ↑           ●       ●   ●
  (移到上方)  E        G   C'
              ↑（最低）
```

**第二轉位（Second Inversion）**：繼續把 E 也移到上方，最低音改為 G

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐         ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│         │D#│   │F#│
  └──┘ └──┘   └──┘ └──┘ └──┘         └──┘   └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │C' │D' │E' │F' │
└───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┘
  ↑               ●           ●       ●
  (移到上方)       G          C'      E'
                  ↑（最低）
```

### 三個位置一覽

| 名稱 | 最低音 | 排列 | 數字低音（Figured Bass） | 聽感 |
|------|--------|------|------------------------|------|
| 原位（Root Position） | 根音（C） | C–E–G | 5/3（省略為無符號） | 最穩定、最扎根 |
| 第一轉位（1st Inversion） | 三音（E） | E–G–C | 6/3（省略為 6） | 較輕盈，稍不穩定 |
| 第二轉位（2nd Inversion） | 五音（G） | G–C–E | 6/4 | 最不穩定，常需要解決 |

> **Figured bass（數字低音）**是巴洛克時代的一種記譜法：在最低音下方寫數字，表示上方各音程的距離。現代和聲教科書依然使用這套符號討論轉位。5/3 = 低音上方有五度和三度，6/3 = 低音上方有六度和三度，6/4 = 低音上方有六度和四度。

## 4. 如何判斷根音

### 方法：重新疊成三度

拿到任意三個音，不管順序，把它們**重新排列成「最小的三度疊加」**，最底部的那個音就是根音（root）。

**步驟**：
1. 把三個音都放在同一個八度範圍內考慮（忽略八度位置）。
2. 嘗試排列，找出讓兩個相鄰音都形成三度（大三度或小三度）的順序。
3. 符合條件的排列，底部 = 根音。

### 例子一：原位和弦

給定音：**C、E、G**（已是三度疊加）

```
 C → E：大三度（M3）✓
 E → G：小三度（m3）✓
 → 根音 = C，大三和弦
```

### 例子二：第一轉位（三音在最低）

給定音（由低到高）：**E、G、C**

```
 E → G：小三度（m3）✓
 G → C：完全四度（P4）✗（四度不是三度！）
 
 重新排列嘗試 C 在最低：
 C → E：大三度（M3）✓
 E → G：小三度（m3）✓
 → 根音 = C，大三和弦（第一轉位）
```

### 例子三：辨識減三和弦的轉位

給定音（由低到高）：**G♭、C、E♭**

```
 嘗試 C 在最低：
 C → E♭：小三度（m3）✓
 E♭ → G♭：小三度（m3）✓
 → 根音 = C，減三和弦（C°）；G♭ 是第二轉位的最低音
```

> 快速口訣：**找到讓兩個相鄰距離都是三度的排法，最低音就是根音。** 如果怎麼排都有一個音是四度，那就跳過那個音，從下一個嘗試。

## 5. 大調音階上的三和弦

### C 大調七個級數和弦

大調音階（major scale）的每一個音都可以作為根音，在音階內的音上方疊兩個三度，就得到七個**順階三和弦（diatonic triads）**。

C 大調音階：C–D–E–F–G–A–B

| 級數 | 根音 | 組成音 | 和弦名稱 | 性質 | 功能預告 |
|------|------|--------|---------|------|---------|
| I | C | C–E–G | C | 大三（Major） | 主功能（Tonic） |
| ii | D | D–F–A | Dm | 小三（minor） | 下屬功能（Subdominant） |
| iii | E | E–G–B | Em | 小三（minor） | 主功能（Tonic） |
| IV | F | F–A–C | F | 大三（Major） | 下屬功能（Subdominant） |
| V | G | G–B–D | G | 大三（Major） | 屬功能（Dominant） |
| vi | A | A–C–E | Am | 小三（minor） | 主功能（Tonic） |
| vii° | B | B–D–F | B° | 減三（Diminished） | 屬功能（Dominant） |

```
大調音階上的和弦性質規律：
I   ii   iii   IV   V   vi   vii°
大  小   小    大   大  小   減
M   m    m     M    M   m    dim
```

### 鍵盤圖示：C 大調 I、IV、V（最重要的三個）

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │
└───┴───┴───┴───┴───┴───┴───┘
  ●       ●       ●             ← I 級：C–E–G（C 大三）
          ●           ●   ●     ← ??? （試試看！）
              ●       ●   ●     ← ???

I  = C–E–G   （大三）
IV = F–A–C   （大三）
V  = G–B–D   （大三）
```

> 大調音階中，**I、IV、V 都是大三和弦**——這三個和弦構成了流行、藍調、民謠的骨幹進行（the three-chord trick）。

### 功能說明（預告）

三個功能區塊決定和聲進行的動力：

- **主功能（Tonic，T）**：I、iii、vi — 最穩定，常作為起點或終點。
- **下屬功能（Subdominant，S）**：IV、ii — 中間張力，推向屬功能。
- **屬功能（Dominant，D）**：V、vii° — 最大張力，強烈「想要」解決回主和弦。

T → S → D → T 是西洋調性音樂最基本的動力循環。詳細說明見：[concept_chord_function](concept_chord_function.md)

## 6. 小測驗

試著回答以下問題（答案在下方）：

1. 給定三個音 E、G、B，這是什麼三和弦？它的兩個三度分別是大三度還是小三度？
2. 以 F 為根音，建構一個減三和弦（diminished triad），組成音是什麼？
3. 給定音（由低到高）：G、C、E，這是什麼和弦的什麼轉位？根音是哪個音？
4. 大調音階的 vii° 級三和弦是什麼性質？以 G 大調為例，vii° 是哪個和弦？
5. 增三和弦（augmented triad）有一個獨特的對稱性。C 增三和弦的組成音是什麼？為什麼說「任何一個音都可以視為根音」？
6. 大三和弦和小三和弦的五音都是完全五度（P5），那它們的聽感差異完全來自哪個音？
7. 給定音（由低到高）：Ab、C、E，判斷這是什麼和弦？是什麼轉位？
8. C 大調中，I、IV、V 都是大三和弦。請分別寫出它們的組成音，並觀察：這三個和弦的組成音合起來剛好涵蓋哪些音？
9. 第二轉位（6/4）被認為是最不穩定的轉位。以 C 大三和弦的第二轉位為例，最低音 G 上方的兩個音程分別是什麼？為什麼這讓和弦不穩定？
10. 以 Bb 為根音，建構一個大三和弦，組成音是什麼？

<details>
<summary>答案</summary>

1. **E 小三和弦（Em）** — E→G 是小三度（m3，3 半音），G→B 是大三度（M3，4 半音）。下方小三度 + 上方大三度 = 小三和弦。E→B 是完全五度（P5，7 半音）。
2. **F-Ab-Cb（= F-Ab-B）** — 減三和弦公式：根音 + 小三度 + 小三度 = 1-b3-b5。F→Ab 是小三度（3 半音），Ab→Cb 是小三度（3 半音）。F→Cb 是減五度（d5，6 半音）。鍵盤上 Cb = B。
3. **C 大三和弦的第二轉位（2nd inversion）** — 重新排列成三度疊加：C→E 大三度、E→G 小三度，根音 = C。最低音是五音 G，所以是第二轉位（6/4）。
4. **減三和弦（diminished triad）；G 大調的 vii° = F#dim（F#-A-C）** — G 大調音階：G-A-B-C-D-E-F#，第 7 音 = F#，順階堆三度得 F#-A-C。F#→A 小三度、A→C 小三度 → 減三和弦。
5. **C-E-G#（組成音）** — 三個音之間各相距大三度（M3，4 半音），完全等距（4+4+4=12 半音 = 一個八度）。因為結構完全對稱，E-G#-C 和 G#-C-E 也各自形成相同的增三和弦結構，所以任何一個音都可以視為根音。這意味著 C aug = E aug = G# aug（等音解釋下）。
6. **三音（Third）** — 大三和弦的三音距根音 4 半音（M3），小三和弦的三音距根音 3 半音（m3），差距僅一個半音，但這一個半音就決定了和弦的「大調明亮」vs.「小調憂鬱」性格。五音（P5）在兩者中完全相同，只提供穩定感。
7. **Ab 增三和弦（Ab+）的原位** — 重新排列成三度疊加：Ab→C 大三度（4 半音），C→E 大三度（4 半音）。兩個大三度 = 增三和弦，根音 = Ab。Ab→E 是增五度（A5，8 半音）。最低音就是根音 Ab，所以是原位。
8. **I = C-E-G，IV = F-A-C，V = G-B-D** — 合起來涵蓋 C、D、E、F、G、A、B，剛好是 C 大調音階的全部 7 個音。這說明 I-IV-V 三個和弦就足以覆蓋整個大調音階，這也是為什麼「三和弦把戲（three-chord trick）」能支撐大量歌曲。
9. **G 上方有完全四度（G→C，P4）和大六度（G→E，M6）** — 數字低音標記為 6/4。低音上方的完全四度在古典和聲中被視為不協和音程（見音程章節 P4 的特殊地位），這讓整個和弦處於不穩定狀態，通常需要解決到根音位置（如 I6/4 → V → I）。
10. **Bb-D-F** — 大三和弦公式 1-3-5：Bb→D 大三度（4 半音：Bb→B→C→C#→D），D→F 小三度（3 半音：D→Eb→E→F）。Bb→F 完全五度（7 半音）。

</details>

## 7. 下一步

### 加上第四個音：七和弦（Seventh Chord）

三和弦是基礎，但實際音樂中常常在五音上再疊一個三度，形成**七和弦（seventh chord）**——因為根音到最高音是七度而得名。

```
 三和弦：  根音 + 三音 + 五音
 七和弦：  根音 + 三音 + 五音 + 七音
                               ↑
                        再疊一個三度
```

七和弦帶來更豐富的色彩與張力：C 大七和弦（Cmaj7）= C–E–G–B，C 屬七和弦（C7）= C–E–G–B♭。詳見：[concept_seventh_chord](concept_seventh_chord.md)
