# 對稱與特殊音階（Symmetric & Special Scales）

> 前置知識：[concept_modes — 教會調式](concept_modes.md)（七種調式的結構與公式）
> 建議先讀：[concept_scale_and_key — 音階與調性](concept_scale_and_key.md)（大調/小調音階、全音半音排列）

大調、小調、教會調式都是**非對稱的**——它們的全音/半音排列有獨特的形狀，讓每個音都有不同的「角色」。但有些音階用**重複的間距模式**均等地切割八度，形成高度對稱的結構。這些音階聽起來「沒有方向」、「漂浮不定」，反而成為作曲家和即興樂手製造特殊色彩的利器。

---

## 1. 什麼是對稱音階

### 普通音階 vs 對稱音階

普通音階（大調、小調、各種調式）有一個特徵：**全音和半音的排列是不對稱的。**

```
大調：W-W-H-W-W-W-H   ← 七個間距，模式不重複
小調：W-H-W-W-H-W-W   ← 七個間距，模式不重複
```

這種不對稱讓每個音都有獨特的「位置感」——你能聽出哪裡是主音、哪裡是導音、哪裡有張力。

**對稱音階則恰好相反：它們用相同的間距模式反覆堆疊，把八度均等切割。**

```
全音音階：W-W-W-W-W-W       ← 「W」重複 6 次
減音階：  H-W-H-W-H-W-H-W   ← 「H-W」重複 4 次
半音階：  H-H-H-H-H-H-H-H-H-H-H-H  ← 「H」重複 12 次
```

### 對稱音階的特殊性質

因為間距模式會自我重複，對稱音階有一個驚人的結果：**移調的數量比普通音階少。**

- 大調音階：12 種移調（C 大調、D♭大調……每個起始音都不同）
- **全音音階：只有 2 種**（因為每隔一個全音就回到「同一條音階」）
- **減音階：只有 3 種**（因為每隔小三度就回到「同一條音階」）
- 半音階：只有 1 種（所有音都包含在內）

> 核心概念：**對稱 = 均等切割 = 少了方向感 = 更少的移調可能性。**

## 2. 全音音階（Whole Tone Scale）

### 公式：W-W-W-W-W-W（全部都是全音，6 個音）

全音音階是最極端的對稱——六個音之間全是全音，沒有任何半音。

### C 全音音階

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C'│
└───┴───┴───┴───┴───┴───┴───┴───┘
  ●   ●   ●           ●
                  ↑         ↑
                 F#        G#
```

音：**C - D - E - F# - G# - A#**（= C - D - E - F# - G# - B♭）

注意間距完全均等：每兩個相鄰的音之間都是全音。

### 只有 2 種全音音階

由於完美對稱，全世界只有兩條全音音階：

| 編號 | 音階 |
|------|------|
| WT-1 | C - D - E - F# - G# - A# |
| WT-2 | C# - D# - F - G - A - B |

這兩條互為「補集」——WT-1 沒有的音，全都在 WT-2 裡。12 個音被完美地一分為二。

### 聽感與用途

- **漂浮、夢幻、沒有方向**——因為沒有半音，就沒有導音（leading tone），音樂失去了「想解決到某個音」的引力
- **德布西（Debussy）** 大量使用，營造印象派的朦朧色彩
- 內含**增三和弦**（augmented triad）：C-E-G# 就藏在 C 全音音階裡
- 內含**屬七 #5 和弦**（dominant 7th #5）：C-E-G#-B♭

### 對應和弦

| 和弦類型 | 範例 | 音階選擇 |
|---------|------|---------|
| aug（增三和弦） | Caug = C-E-G# | C 全音音階 |
| 7#5（屬七增五） | C7#5 = C-E-G#-B♭ | C 全音音階 |

> 實戰口訣：**看到增和弦或 7#5 → 全音音階。**

## 3. 減音階（Diminished Scale / Octatonic Scale）

減音階是另一種對稱音階，但結構更複雜：**8 個音**，用「半音-全音」或「全音-半音」交替排列。

### 兩種類型

| 類型 | 公式 | 起始間距 | 常用名稱 |
|------|------|---------|---------|
| H-W（半全） | H-W-H-W-H-W-H-W | 半音開始 | 減音階（用在 dim7 和弦上） |
| W-H（全半） | W-H-W-H-W-H-W-H | 全音開始 | 屬減音階（用在 V7 和弦上） |

### C H-W 減音階（半全減音階）

```
C - D♭ - E♭ - E - F# - G - A - B♭
  H    W    H   W   H   W  H   W
```

- 8 個音（八聲音階，octatonic）
- 內含 **dim7 和弦**：C-E♭-F#(G♭)-A
- 同時包含每個和弦音的**上下半音鄰音**（chromatic neighbors），提供豐富的裝飾可能

### C W-H 減音階（全半減音階 / 屬減音階）

```
C - D - E♭ - F - F# - G# - A - B
  W   H    W   H    W    H   W  H
```

- 同樣 8 個音
- 內含 **dom7 和弦**：C-E(藏在裡面嗎？注意：E♭ 而非 E)

更準確地說，以 C 為根音的 W-H 減音階包含：

| 張力音 | 音名 | 來源 |
|--------|------|------|
| 根音 | C | — |
| ♭9 | D♭... | 等等——讓我們用正確的音來分析 |

重新整理 C W-H 減音階的和聲內容：

```
C  D  E♭  F  F#  G#  A  B
1  9  ♭3  11  #11  #5  13  7
      (=#9)     (=♭5)
```

以 **C7** 和弦的角度來看，這條音階提供了：
- 和弦音：C（根）、E♭ 可視為 #9、B（大七?）

實際上，W-H 減音階最常這樣理解——**從屬七和弦根音出發**：

```
C  D   E♭  F   F#   A♭  A   B
1  9   #9  11  #11  ♭13  13  7
            (=♭3)  (=♭5) (=#5)
```

它一次提供了 **♭9、#9、#11、13** 等豐富的色彩張力音，是爵士即興中「屬和弦上最多選擇」的一條音階。

### 只有 3 種減音階

由於每小三度（3 個半音）就回到同一組音：

| 編號 | H-W 版本 | W-H 版本 |
|------|---------|---------|
| Dim-1 | C-D♭-E♭-E-F#-G-A-B♭ | C-D-E♭-F-F#-G#-A-B |
| Dim-2 | C#-D-E-F-G-A♭-B♭-B | C#-D#-E-F#-G-A-B♭-C |
| Dim-3 | D-E♭-F-F#-G#-A-B-C | D-E-F-G-G#-A#-B-C# |

> C dim7 = E♭ dim7 = F# dim7 = A dim7（同一組音），所以它們共用**同一條**減音階。

### 代表作曲家與風格

- **巴爾托克（Bartók）**、**斯特拉文斯基（Stravinsky）**、**梅湘（Messiaen）**：20 世紀古典音樂中大量使用
- **爵士樂**：W-H 減音階（dominant diminished）是即興時在屬七和弦上製造「outside」色彩的強大工具
- **柯乘恩（Coltrane）** 等爵士大師運用自如

> 實戰口訣：**dim7 和弦 → H-W 減音階；V7 和弦要加料 → W-H 減音階。**

## 4. 變化音階（Altered Scale / Super Locrian）

### 公式：H-W-H-W-W-W-W

變化音階不是對稱音階（它有 12 種移調），但它是爵士和聲中最重要的「特殊音階」之一，和對稱音階一樣產生強烈的色彩效果。

### C Altered Scale

```
C - D♭ - E♭ - F♭(E) - G♭ - A♭ - B♭
  H    W      H       W    W    W    W
```

音：**C - D♭ - E♭ - E(F♭) - G♭ - A♭ - B♭**

### 包含所有變化張力音

以 C7 和弦的角度分析：

| 音 | 級數 | 張力類型 |
|----|------|---------|
| C | 1 | 根音 |
| D♭ | ♭9 | 變化張力 |
| E♭ | #9 | 變化張力 |
| E (F♭) | 3 | 和弦音（大三度） |
| G♭ | ♭5 / #11 | 變化張力 |
| A♭ | #5 / ♭13 | 變化張力 |
| B♭ | ♭7 | 和弦音 |

**一條音階包含了全部四個變化張力音：♭9、#9、♭5、#5。** 這就是為什麼它叫「altered」——所有能改的都改了。

### 來源：旋律小調的第 7 個調式

Altered scale = **升序旋律小調的第 7 調式（Super Locrian）**。

```
C Altered = D♭ 旋律小調從第 7 音開始
D♭ 旋律小調：D♭ E♭ F♭ G♭ A♭ B♭ C
              ↑ 從 C 開始讀 → C D♭ E♭ F♭ G♭ A♭ B♭
```

> 記憶捷徑：**在 G7 上彈 altered → 想成「彈 A♭ 旋律小調」。** 根音上方半音的旋律小調！

### 用途：V7 → I 的最大張力解決

G altered 用在 G7alt → Cmaj7 的解決中：

```
G7alt:  G  A♭  B♭  B  D♭  E♭  F
        1  ♭9  #9  3  ♭5  #5  ♭7

解決到 Cmaj7：所有變化音都有半音解決的路徑
  A♭ → G（或 A♭ → A）
  B♭ → A（或 B♭ → B）
  D♭ → C
  E♭ → E
```

**最大張力 → 最滿意的解決。** 這是 bebop 和現代爵士的核心語彙。

## 5. 旋律小調衍生音階（Melodic Minor Modes）

Altered scale 來自旋律小調，但旋律小調還衍生出許多其他有用的調式。以下是最常用的幾個：

### 升序旋律小調公式

旋律小調（升序）= 自然小調但升第 6 和第 7 音 = **W-H-W-W-W-W-H**

```
C 旋律小調：C D E♭ F G A B
            W H  W  W W W H
```

> 聽起來像「小調和大調的混合體」——小三度（E♭）搭配大六度（A）和大七度（B）。

### 七個調式一覽

| 調式 | 名稱 | 公式 | 代表和弦 | 用途 |
|------|------|------|---------|------|
| 第 1 | Melodic Minor | W-H-W-W-W-W-H | m(maj7) | 小大七和弦 |
| 第 2 | Dorian ♭2（Phrygian ♮6） | H-W-W-W-W-H-W | sus♭9 | 懸掛 ♭9 |
| 第 3 | Lydian Augmented | W-W-W-W-H-W-H | maj7#5 | 增大七和弦 |
| 第 4 | Lydian Dominant（Lydian ♭7） | W-W-W-H-W-H-W | 7#11 | 三全音代理（♭II7）、V7/IV |
| 第 5 | Mixolydian ♭6 | W-W-H-W-H-W-W | 7♭13 | 屬七 ♭13 |
| 第 6 | Locrian ♮2（Half-diminished scale） | W-H-W-H-W-W-W | ø7 | 半減七和弦（比 Locrian 好聽） |
| 第 7 | Altered（Super Locrian） | H-W-H-W-W-W-W | 7alt | V7alt 解決 |

### 最常用的三個

**Lydian Dominant（第 4 調式）**

```
C Lydian Dominant：C D E F# G A B♭
= 大調 + #4 + ♭7
```

- 聽感：Lydian 的夢幻 + 屬七的張力
- 用途：**三全音代理**（tritone substitution）的首選音階。D♭7 代理 G7 時，D♭ Lydian Dominant 完美適配

**Locrian ♮2（第 6 調式）**

```
C Locrian ♮2：C D E♭ F G♭ A♭ B♭
= Locrian 但第 2 音不降
```

- 用途：**ø7（半減七）和弦的首選音階**。比原版 Locrian（♭2）聽起來更平衡
- 爵士 ii-V-i 中的 iiø7 幾乎都用這條

**Altered（第 7 調式）** — 見上一節詳細說明。

## 6. 對稱與特殊音階的特性比較

| 音階 | 音數 | 移調數 | 間距模式 | 特徵聽感 | 代表作曲家/風格 |
|------|------|--------|---------|---------|---------------|
| 全音音階 | 6 | 2 | W 重複 | 漂浮夢幻、無方向 | Debussy |
| 減音階（H-W） | 8 | 3 | H-W 重複 | 緊張、對稱、神秘 | Bartók, Stravinsky |
| 減音階（W-H） | 8 | 3 | W-H 重複 | 爵士屬七豐富色彩 | Coltrane, 爵士 |
| Altered | 7 | 12 | 不對稱 | 最大張力、不安定 | Bebop, 現代爵士 |
| 旋律小調 | 7 | 12 | 不對稱 | 小調/大調混合體 | 爵士、古典 |
| 半音階 | 12 | 1 | H 重複 | 全部包含 | — |

### 如何選擇

```
看到和弦 → 選音階

aug / 7#5         → 全音音階
dim7              → H-W 減音階
dom7 要加料       → W-H 減音階
dom7alt（♭9#9♭5#5）→ Altered
ø7                → Locrian ♮2
m(maj7)           → 旋律小調
7#11 / ♭II7       → Lydian Dominant
```

## 7. 小測驗

試著回答以下問題（答案在下方）：

1. 對稱音階和普通音階最大的差異是什麼？為什麼對稱音階的移調數量較少？
2. 全世界共有幾條全音音階？寫出兩條的所有音。
3. 全音音階聽起來「漂浮夢幻」的原因是什麼？
4. 減音階有幾個音？有哪兩種類型？
5. 在 C dim7 和弦上即興，應該使用 H-W 還是 W-H 減音階？寫出這條音階的音。
6. Altered scale 包含哪四個變化張力音？
7. 「在 G7 上彈 altered」等於彈哪個旋律小調？
8. Lydian Dominant 和普通 Lydian 差在哪裡？它常用在什麼情境？
9. 為什麼 Locrian ♮2 比原版 Locrian 更適合用在 ø7 和弦上？
10. 一個和弦標記為 C7#5，你會選擇哪條音階來即興？

---

### 答案

1. **對稱音階用相同的間距模式反覆堆疊，均等切割八度；普通音階的排列不重複。** 因為間距會自我重複，某些移調會產生完全相同的一組音，所以實際的移調數量減少。例如全音音階每隔一個全音就回到同一組音，12 ÷ 6 = 只有 2 種。

2. **2 條。** WT-1：C-D-E-F#-G#-A#；WT-2：C#-D#-F-G-A-B。兩條互為補集，合起來剛好是 12 個音。

3. **因為全音音階完全沒有半音，也就沒有導音（leading tone）。** 導音是驅動音樂「想解決」的力量，沒有導音 = 沒有引力 = 漂浮感。

4. **8 個音。** 兩種類型：H-W（半全，從半音開始）和 W-H（全半，從全音開始）。

5. **H-W 減音階。** C H-W 減音階：C-D♭-E♭-E-F#-G-A-B♭。它包含 C dim7 和弦的所有音（C-E♭-G♭/F#-A）加上每個和弦音的半音鄰音。

6. **♭9、#9、♭5（=#11）、#5（=♭13）。** 一條音階包含了所有能「alter」的張力音，這就是它名字的由來。

7. **A♭ 旋律小調（根音上方半音的旋律小調）。** G Altered = A♭ 旋律小調從第 7 音（G）開始讀。所以在 G7alt 上即興，心裡想著 A♭ 旋律小調的音就對了。

8. **Lydian Dominant = Lydian + ♭7（降七度）。** 普通 Lydian 的第 7 音是大七度，Lydian Dominant 降為小七度，變成屬七和弦的色彩。常用在**三全音代理**（tritone substitution）：例如 D♭7 代理 G7 時，使用 D♭ Lydian Dominant。

9. **Locrian 的第 2 音是 ♭2，形成和根音之間的小二度（半音），聽起來非常刺耳。** Locrian ♮2 把第 2 音還原為自然二度（全音），保留了 ♭5 和 ♭3 的半減七特色，但去掉了最不舒服的 ♭2 碰撞，讓旋律更自然流暢。

10. **全音音階。** C7#5 包含 C-E-G#-B♭，這些音全部都在 C 全音音階（C-D-E-F#-G#-B♭）中。看到 #5 或增和弦類型 → 全音音階是最直覺的選擇。
