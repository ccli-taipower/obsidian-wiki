# 轉調（Modulation）

在 [concept_secondary_dominant](concept_secondary_dominant.md) 裡，我們學了**離調**：短暫拜訪另一個和弦的調，但最終還是回家。**轉調（Modulation）**則不同——音樂**真的搬家了**，在新的調重新建立一個「家」的感覺，聽眾開始把新的主音當作新的參考點。

離調 vs. 轉調的最直接區分：**離調走一兩個和弦就回頭；轉調在新的調停留夠久，讓你覺得「現在在這裡了」**。

---

## 1. 轉調定義

**轉調（Modulation）= 音樂從一個調性移動到另一個調性，並在新的調裡確立新的主音。**

確立新主音的方式通常是：在新的調裡出現 **V → I** 的終止式（即使只有一次），讓聽眾的耳朵「重置」，把新調的 I 當作落腳點。

**比喻**：
- **離調** = 去朋友家玩一個下午，當天回家。
- **轉調** = 真的搬家，新的地方成為你的住所。

---

## 2. 近系調與遠系調

### 近系調（Closely Related Keys）

**近系調定義**：調號只差一個升降號的調，彼此之間共用大量和弦，轉換聽起來自然流暢。

C 大調的近系調：

| 近系調 | 調號 | 與 C 大調差異 | 共用自然和弦數 |
|--------|------|--------------|--------------|
| G 大調 | 1# (F#) | 多 1 升號 | 6/7（除了 F → F# 之外幾乎相同）|
| F 大調 | 1♭ (B♭) | 多 1 降號 | 6/7（除了 B → B♭ 之外幾乎相同）|
| A 小調 | 無升降（C 的關係小調）| 相同調號 | 完全相同（7 個）|
| E 小調 | 1# (F#)（G 大調的關係小調）| 1 升號 | 6/7 |
| D 小調 | 1♭ (B♭)（F 大調的關係小調）| 1 降號 | 6/7 |

**規則**：五度圈上的鄰居 = 天然的近系調。C 大調和 G 大調相距一步，有很多共同的和弦，轉調幾乎不需要大動作就能做到。

### 遠系調（Distantly Related Keys）

**遠系調**：調號相差多個升降號，共用和弦少，轉調需要更明顯的「橋樑」或直接的大幅轉換。

| 轉調例子 | 調號距離 | 共同自然和弦數 |
|---------|---------|--------------|
| C 大調 → D 大調 | 相差 2 升號 | 4/7 |
| C 大調 → E 大調 | 相差 4 升號 | 2–3/7 |
| C 大調 → F# 大調 | 相差 6 升號 | 1/7（只有 B°）|
| C 大調 → D♭ 大調 | 相差 5 降號 | 接近 0（異名同音調，F# = G♭）|

遠系調的轉調需要更刻意的處理，但也因此效果更戲劇化——聽眾會明顯感覺到「咦，換地方了」。

## 3. 共同和弦轉調（Pivot Chord Modulation）

**最常見、最平滑的轉調方式**：找一個在兩個調裡都存在的和弦，用它作為「橋樑」——在舊調裡它是某個角色，在新調裡它換了角色但聽起來一樣，聽眾幾乎察覺不到切換的瞬間。

這個橋樑和弦叫做**共同和弦（Pivot Chord）**。

### 範例：C 大調 → G 大調

**共用和弦分析**：

| 和弦 | 在 C 大調中的級數 | 在 G 大調中的級數 |
|------|-----------------|-----------------|
| C    | I               | IV              |
| Dm   | ii              | v（不常用）       |
| Em   | iii             | vi              |
| G    | V               | I               |
| Am   | vi              | ii              |

**最佳 Pivot Chord 選擇**：**Am**
- 在 C 大調：Am = vi（主功能，穩定）
- 在 G 大調：Am = ii（下屬功能，準備接 V→I）

**轉調進行**：C → Em → **Am（pivot）** → D7 → G

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

C 大調框架：
I    (C):   C–E–G     ●   ●   ●
iii  (Em):  E–G–B         ●   ●   ●

↓ 以下這個 Am 是「雙重身份」的 pivot chord：
vi/C  = ii/G (Am): A–C–E  ●   ●       ●

G 大調框架（從這裡開始建立 G 為主）：
V/G  (D7):  D–F#–A–C      ●  ↑  ●   ● （F# 是黑鍵）
I/G  (G):   G–B–D              ●   ●   ●  ← G 成為新的「家」
```

**聽的重點**：Am 出現時，你的耳朵仍然覺得在 C 大調（vi）；接著 D7 的 F# 出現，你感覺「好像換地方了」；G 落下，G 大調確立。

### 共同和弦轉調的步驟

1. **確定起點調和終點調**（如 C 大調 → A 小調）
2. **列出兩個調共有的自然和弦**
3. **選擇一個在兩個調裡功能都合理的和弦作為 pivot**（盡量選兩個調中功能都「正常」的）
4. **在 pivot 之後立即進行新調的 V → I**，確立新主音

## 4. 半音轉調（Chromatic Modulation）

**定義**：某個和弦的根音或聲部以半音移動，直接過渡到新調的和弦，不需要共同和弦的橋接。

這是流行歌**副歌升半音**最常用的手法，帶來情感上的「提升感」、「再高一段」的效果。

### 最常見：整段升半音（直接模進）

例：主歌在 C 大調，副歌第二次出現升半音到 D♭ 大調（= C# 大調）。

進行方式：
```
副歌第一輪（C 大調）：
... G7 → C → F → G7 → [換調！]

副歌第二輪（D♭ 大調）：
A♭7 → D♭ → G♭ → A♭7 → D♭
```

半音轉調的特點：
- **轉換通常很突然**——音樂直接往上（或往下）移動，不需要橋接過程。
- **心理效果強烈**：聽眾感覺情緒被「再拉高一格」，流行歌副歌反覆時用來製造高潮。
- **轉調後一切調性關係不變**，只是音高整體移動。

> 半音轉調的轉換點通常是一個「剪切」——前一個調的結尾接著新調的開頭，中間沒有任何過渡和弦。正因為突兀，反而讓聽眾**意識到「換地方了」**，這是刻意的效果。

---

## 5. 直接轉調（Direct Modulation）

**定義**：沒有共同和弦、沒有半音準備，直接從一個調跳到另一個調。

與半音轉調的差別：半音轉調通常升（或降）半音；直接轉調可以跳到任意調，有時甚至是遠系調。

效果：**震驚感、戲劇性**。聽眾完全沒有被「帶著走」，突然就在新的地方了。

### 使用場景

- **音樂劇**：場景切換時常用直接轉調，配合舞台上的戲劇性時刻。
- **古典樂的展開部（development section）**：和聲關係複雜、突然，製造不穩定感。
- **流行歌橋段（bridge）**：橋段出現時用截然不同的調，讓整首歌有「結構上的驚喜」。
- **貝多芬等浪漫派作曲家**：刻意用遠系調的直接轉調製造戲劇衝擊，再回頭重建主調。

直接轉調簡短說明：它比共同和弦轉調和半音轉調少見，但效果可以非常強烈。在初學階段，**認出「突然變調了」這件事**本身就是重要的聽辨能力。

## 6. 聽辨提示：轉調 vs. 離調，怎麼區分

這是最實際的問題：「我聽到的是離調還是轉調？」

| 特徵 | 離調（Tonicization）| 轉調（Modulation）|
|------|-------------------|-----------------|
| 持續時間 | 1–2 個和弦 | 數個和弦，有時整個段落 |
| 是否建立新 V → I | 不一定，通常只有一個副屬和弦 | 是，會出現明確的新調 V → I |
| 回到原調 | 很快回來 | 不一定回來（或很久才回來）|
| 聽感 | 「稍微飄了一下」 | 「感覺換地方了，這裡有新的重心」 |

**實際聽辨方法**：

1. **聽主音感（tonal center）**：你在聽的時候，什麼音感覺是「家」？如果感覺到的「家」改變了，就是轉調。
2. **等 V → I 出現**：如果在新的音域裡出現了 V → I 終止式，那就是轉調確立了。
3. **離調是「訪客」，轉調是「新住所」**：離調的「外來感」一閃即逝；轉調的「新調感」會停留，讓你在那裡「住」一段時間。

### 具體例子對照

**離調**：C → E7 → Am → G → C
- E7 帶著 G#，「拜訪」了一下 Am 的世界，但 G → C 讓你馬上回到 C 大調。
- 你的耳朵從頭到尾感覺「家在 C」。

**轉調**：C → Em → Am → D7 → G → C → D7/G → G → D → G
- D7 → G 把 G 確立為新主音，後續一直在 G 大調裡進行（G → D → G 等）。
- 你的耳朵在 G 確立後開始把 G 當作新的「家」。

> **記憶口訣**：離調是「一日遊」，轉調是「搬家」。如果一個「外來」的感覺只有一瞬間就消失，它是離調；如果它停留下來、建立了新的重心，那就是轉調。

## 7. 鍵盤實作：試著聽出轉調

### 練習一：共同和弦轉調（C 大調 → G 大調）

在鍵盤上緩慢地彈以下進行，並試著在 Am 出現時「感覺兩個調」：

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

[C 大調段落]
I   (C):   C–E–G   ●   ●   ●
IV  (F):   F–A–C       ●   ●   ●
vi  (Am):  A–C–E   ●   ●       ●   ← pivot：vi in C = ii in G

[G 大調建立]
V/G (D7):  D–F#–A–C    ●  ↑  ●   ● （F# 是黑鍵）
I/G (G):   G–B–D           ●   ●   ●  ← G 成為新的主音
V/G (D7):  D–F#–A–C    ●  ↑  ●   ●
I/G (G):   G–B–D           ●   ●   ●  ← 確認落地
```

**感受**：彈到 Am，你還不覺得「換地方了」；彈到 D7（F# 出現），感覺「稍微走遠了」；G 落下時，新的「家」確立。

### 練習二：對比離調與轉調

先彈**離調版**（一直在 C 大調）：
```
C → E7 → Am → G7 → C
```

再彈**轉調版**（從 C 大調走到 A 小調）：
```
C → Em → Am → E7 → Am → Dm → E7 → Am
```

兩個都有 E7，但結果不同：前者回到 C 大調，後者建立 Am 為新的主音。聽聽最後的落點：第一個落在 C，第二個落在 Am——哪個才是你的「家」？

## 8. 小測驗

試著回答以下問題（答案在下方）：

1. C 大調要轉到 G 大調，Am 可以作為共同和弦（pivot chord）。Am 在 C 大調中是什麼級數？在 G 大調中是什麼級數？
2. 一首歌的副歌從 C 大調突然整段升半音到 Db 大調，這屬於哪種轉調方式？
3. C 大調和 E 大調是近系調還是遠系調？為什麼？
4. 你聽到一段音樂中出現 E7 → Am 的進行。如果 E7 之後音樂馬上回到 C 大調（G → C），這算離調還是轉調？如果 E7 → Am 之後繼續 Dm → E7 → Am，呢？

<details>
<summary>答案</summary>

1. **Am 在 C 大調中是 vi（主功能），在 G 大調中是 ii（下屬功能）** — 這讓 Am 成為理想的 pivot chord：在 C 大調的語境中它是穩定的主功能和弦，接下來 D7→G 把音樂帶入 G 大調時，Am 自然地「變身」為 ii（準備接 V→I 的下屬功能）。
2. **半音轉調（Chromatic Modulation）** — 整段音樂往上移動半音，不需要共同和弦橋接，轉換通常很突然。這是流行歌副歌反覆時製造情感「再拉高一格」的經典手法。
3. **遠系調** — C 大調無升降，E 大調有 4 個升號（F#, C#, G#, D#），調號相差 4 個升號，共用的自然和弦很少（只有 2-3 個）。五度圈上 C 到 E 相距 4 步，不是鄰居。
4. **前者是離調，後者是轉調** — 第一種情況，E7（含 G#）只出現一瞬間，Am 之後馬上 G→C 回到 C 大調，耳朵始終把 C 當作「家」= 離調（一日遊）。第二種情況，E7→Am 之後繼續在 A 小調裡進行（Dm→E7→Am），建立了 Am 為新的主音，聽眾感覺「搬家了」= 轉調。

</details>
