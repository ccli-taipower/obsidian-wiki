# 終止式（Cadence）

> 前置知識：[concept_chord_function — 功能和聲](concept_chord_function.md)（T / S / D 三大功能）
> 建議先讀：[concept_seventh_chord — 七和弦](concept_seventh_chord.md)（V7 的三全音與解決）

學會了和弦功能（T / S / D），你已知道和聲在「移動」——那它在哪裡「停下來」？

**終止式（Cadence）**是樂句結尾的和聲公式，就像語言裡的標點符號：句號讓你完全停下，逗號讓你暫停一下，驚嘆號帶來意外的轉折。音樂同樣用不同的終止式，傳遞「結束了」、「還沒完」、「意外！」的感覺。

理解終止式，你就能聽出一首曲子何時「說完一句話」，何時「故意製造懸念」，以及作曲家怎麼操控聽眾的期待。

---

## 1. 終止式定義

**終止式 = 出現在樂句末尾的特定和弦進行**（通常是最後 2 個和弦）。

關鍵特點：
- 終止式發生在**樂句末尾**，不是隨便兩個和弦。
- 它的功能是**結束感知**——或完全結束，或暫時結束，或出乎意料。
- 不同終止式對應不同**功能流向**（見 [concept_chord_function](concept_chord_function.md)）。

---

## 2. 四種基本終止式

### 2-1 正格終止（Authentic Cadence）

**公式**：V → I（屬 → 主）

**標點比喻**：。**句號**。最終、完整的停頓。

這是和聲引力最強的終止式：導音（leading tone）解決到主音，屬功能的張力完全釋放。

#### 完全正格終止（PAC, Perfect Authentic Cadence）

條件：
- V 和 I 均為**根音位置（root position）**
- I 的最高聲部落在**主音（tonic）**上

聽感：**最終確定、無懸念**。古典樂段和流行歌副歌結尾最常見。

**C 大調範例**：Am → Dm → G → C

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

vi  (Am):  A–C–E   ↑   ↑   ↑
ii  (Dm):  D–F–A       ↑   ↑   ↑
V   (G):   G–B–D           ↑   ↑   ↑
I   (C):   C–E–G   ●   ●   ●     ← 落地！
```

引導路徑：vi（T）→ ii（S）→ V（D）→ I（T）——完整的 T–S–D–T 循環。

#### 不完全正格終止（IAC, Imperfect Authentic Cadence）

條件：V → I 但有一項不滿足 PAC 條件（轉位、或最高聲部不在主音）

聽感：**有落地感但稍顯曖昧**，常用在樂段中間作為次要收尾。

---

### 2-2 半終止（Half Cadence）

**公式**：? → V（任何和弦 → 屬和弦）

**標點比喻**：，**逗號**。暫停一下，話還沒說完。

樂句停在 V，留下開放感、懸念感——聽眾下意識等待後半句繼續。

**C 大調範例**：C → F → G（停在 G）

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I   (C):   C–E–G   ●   ●   ●
IV  (F):   F–A–C       ●   ●   ●
V   (G):   G–B–D           ●   ●   ●  ← 停在這！
```

聽感：G 大三和弦是明亮的，但停在這裡感覺「懸空」——音樂說到一半停下來，等著繼續。

**常見前接和弦**：I → V（最簡單）、IV → V（有準備感）、ii → V（更精緻）

> 半終止常出現在**問句**的結尾，正格終止出現在**答句**的結尾，共同構成「前句 + 後句」的樂句對稱結構。

---

### 2-3 變格終止（Plagal Cadence）

**公式**：IV → I（下屬 → 主）

**標點比喻**：**阿門句號**（Amen Cadence）。溫柔、平靜地落地，沒有正格終止那麼強烈。

F → C 的進行，沒有導音製造的強烈引力，卻有一種「輕輕放下」的平和感。教堂音樂中常在結尾加上這個 Amen 終止。

**C 大調範例**：C → G → F → C

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I   (C):   C–E–G   ●   ●   ●
V   (G):   G–B–D           ●   ●   ●
IV  (F):   F–A–C       ●   ●   ●
I   (C):   C–E–G   ●   ●   ●   ← 溫柔落地
```

聽感：比起 V → I 少了一份迫切感，多了一份慈和。流行歌中「IV → I」的進行非常普遍，有時整個副歌就反覆 IV–I–IV–I。

---

### 2-4 欺騙終止（Deceptive Cadence）

**公式**：V → vi（本應解決到 I，卻解決到 vi）

**標點比喻**：！**驚嘆號**。聽眾期待 I，卻得到 vi——意外轉折，情緒延伸。

導音仍然解決（B → C），但根音改走 G → A，整個和弦感覺「側滑」了一步。vi 是關係小調的主和弦，有穩定感但帶憂鬱，聽起來像：「以為到家了，發現走錯門。」

**C 大調範例**：F → G → Am（預期 C，得到 Am）

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

IV  (F):   F–A–C       ●   ●   ●
V   (G):   G–B–D           ●   ●   ●  ← 製造期待
vi  (Am):  A–C–E   ●   ●       ●       ← 意外！（不是 C）
```

欺騙終止幾乎不收尾——它延長了音樂，讓作曲家繼續說下去，最終用正格終止真正結束。

## 3. 聽辨提示（How Each Cadence Feels）

| 終止式 | 英文 | 公式 | 感受 | 標點 |
|--------|------|------|------|------|
| 完全正格終止 | PAC | V → I（根音位，主音在頂） | 完全結束，無懸念 | 。 |
| 不完全正格終止 | IAC | V → I（有轉位或頂音非主音） | 落地但稍曖昧 | 。（小字號）|
| 半終止 | HC | ? → V | 懸空，等待繼續 | ， |
| 變格終止 | PC | IV → I | 平靜、柔和落地 | 。（輕聲）|
| 欺騙終止 | DC | V → vi | 意外、情緒延伸 | ！ |

**聽辨方法**：
- 樂句末尾聽到**大和弦，感覺完整** → 可能是正格終止（I）或半終止（停在 V）
- 末尾**感覺落地但輕柔** → 變格終止（IV → I）
- 末尾**明顯懸空、還沒完** → 半終止（停在 V）
- 你以為要結束**但突然轉向** → 欺騙終止（V → vi）

## 4. 實際曲目中的終止式

### 正格終止（V → I）

- **巴哈《創意曲》（Two-Part Inventions）**：幾乎每個段落結尾都是 V → I，骨架清晰。
- **披頭四〈Let It Be〉**：副歌結尾 G → C，典型 PAC，強烈「放下」感。

### 半終止（? → V）

- **莫扎特奏鳴曲**：前句結尾反覆使用 HC，製造對稱的「問句」。
- **〈Twinkle Twinkle Little Star〉**：「how I wonder what you are」停在 V（G），緊接著後半句繼續。

### 變格終止（IV → I）

- **教堂聖歌〈Amazing Grace〉**：多處 IV → I，帶著溫暖虔誠的收尾。
- **披頭四〈Hey Jude〉**：尾奏反覆 F → C（IV → I in C），綿長平靜。

### 欺騙終止（V → vi）

- **貝多芬《第五號交響曲》第一樂章**：在最緊張處使用欺騙終止，拉長戲劇張力。
- **流行歌曲**：常在副歌高點用 V → vi 製造情緒延伸，讓副歌「再唱一遍」而不是直接結束。

## 5. 小測驗

試著回答以下問題（答案在下方）：

1. 在 C 大調中，樂句結尾出現 G → C，這是什麼終止式？
2. 四種基本終止式中，哪一種讓人感覺「話還沒說完」？它的公式是什麼？
3. V → vi 為什麼叫「欺騙終止」？在 G 大調中，欺騙終止的具體和弦是什麼？
4. 變格終止（IV → I）和正格終止（V → I）都解決到 I，為什麼正格終止的結束感更強？
5. 完全正格終止（PAC）和不完全正格終止（IAC）都是 V → I，但 PAC 有兩個額外條件。是哪兩個？
6. 在 A 小調（和聲小調）中，正格終止 V → i 的具體和弦是什麼？導音是哪個音？
7. 「前句 + 後句」結構（antecedent + consequent）中，前句通常以什麼終止式結束？後句呢？這構成了什麼對稱效果？
8. 欺騙終止（V → vi）之後，音樂通常不會直接結束。為什麼？作曲家接下來一般會怎麼做？
9. 在 C 大調中，一段音樂結尾的進行是 Dm → G → Am。後兩個和弦（G → Am）是什麼終止式？用功能標記分析這三個和弦。
10. 變格終止（IV → I）在教堂音樂中被稱為什麼？流行歌中 IV → I 的反覆使用，和古典變格終止的用法有什麼不同？

<details>
<summary>答案</summary>

1. **正格終止（Authentic Cadence）** — V → I 是最基本的終止式，屬功能解決到主功能，導音半音上行到主音，帶來最完整的「句號」效果。如果 G 和 C 都在根音位置且 C 的最高音是主音，則是完全正格終止（PAC）。
2. **半終止（Half Cadence）** — 公式：? → V（任何和弦解決到屬和弦）。樂句停在 V 上，留下開放感和懸念，像逗號，等待後半句繼續。
3. **因為聽眾期待 V 之後會解決到 I（正格終止），結果卻「被騙」解決到 vi** — vi 是關係小調的主和弦，有穩定感但帶憂鬱，不是期待中的「回家」。在 G 大調中，欺騙終止 = **D → Em**（V = D major，vi = Em）。
4. **因為 V 含有導音（leading tone）和三全音（tritone），製造了強烈的解決張力** — 在 C 大調中，G 和弦含導音 B（半音上行到 C）；若用 G7 則 B 和 F 形成三全音。IV（F）不含導音，IV → I 只有平穩的「放下」感，沒有張力-釋放的衝擊力。
5. **（1）V 和 I 都必須在根音位置（root position）；（2）I 的最高聲部（soprano）必須落在主音上** — 兩個條件都滿足才是 PAC（最終確定、無懸念）。若有一項不滿足（例如 I 用轉位，或最高音不是主音），則降級為 IAC，落地感稍打折扣。
6. **V = E major（E-G#-B），i = Am（A-C-E），導音 = G#** — 和聲小調升第 7 音（G → G#），讓 V 成為大三和弦。G# 是 A 的導音，半音上行解決到 A（主音），製造小調中 V → i 的強烈回家感。
7. **前句以半終止（HC，停在 V）結束，後句以正格終止（PAC，V → I）結束** — 前句的 HC 像「問句」，製造懸念等待；後句的 PAC 像「答句」，完整落地。兩者構成「問-答」的對稱結構，是古典樂段最基本的句法框架。
8. **因為欺騙終止解決到 vi 而非 I，聽眾沒有得到期待的「回家」，音樂的敘事還沒完成** — 作曲家通常在欺騙終止後繼續延伸樂句，重新走一次 S → D → T 的功能流向，最終以正格終止（V → I）真正結束。欺騙終止的作用是「拉長戲劇張力」，讓結尾來得更有份量。
9. **G → Am = 欺騙終止（Deceptive Cadence）** — 功能分析：Dm = ii（S），G = V（D），Am = vi（T）。V 之後期待 I（C），卻得到 vi（Am），是典型的欺騙終止。整體流向 S → D → T(vi) 仍符合功能方向，但落點是 vi 而非 I，帶來情緒延伸。
10. **「阿門終止」（Amen Cadence）** — 教堂聖歌中常在最後一個 Amen 上用 IV → I 收尾，溫柔平靜。流行歌中 IV → I 的反覆使用（如副歌循環 F → C → F → C）則更像是一種**持續的節奏律動**，不是一次性的句末結束，而是一個「綿長的、反覆嘆息般」的進行，心理效果從「一次性句號」變成了「情緒的持續搖擺」。

</details>
