# 副屬和弦（Secondary Dominant）

> 前置知識：[concept_chord_function — 功能和聲](concept_chord_function.md)（V → I 的解決引力）
> 建議先讀：[concept_seventh_chord — 七和弦](concept_seventh_chord.md)（屬七和弦結構）

你已經知道 V → I 是最強的和聲解決——屬和弦帶著張力，主和弦把它釋放。現在問：如果不想轉調，但想讓某個**非主和弦**（比如 Dm 或 Am）暫時感覺像「主角」，怎麼辦？

答案是：**給它一個臨時的 V**。這個「借來的屬和弦」就是**副屬和弦（Secondary Dominant）**。

---

## 1. 離調定義

**離調（Tonicization）**：在不改變調性的前提下，暫時讓音樂「拜訪」另一個和弦所在的調。

注意：

- **離調是短暫的**——進去了就出來，你還在原來的調。
- **轉調是永久的**——你搬到新的調，舊的調不是家了。

把它想像成旅遊：**離調 = 去朋友家玩一下，當天回來**；**轉調 = 搬家**。

以 C 大調為例，V → I（G → C）是正常的回家路線。現在如果我們在 Dm 前面插入 A7，A7 → Dm 就像是「短暫以 Dm 為家、進行了一次 V → I」——只是這個「家」不是真正的主調，而是一個暫時的落腳點。聽完 Dm，音樂還是會繼續走回 C 大調。

---

## 2. 副屬和弦（Secondary Dominant）

**副屬和弦的定義**：某個調內和弦（diatonic chord）的屬七和弦。

寫法：**V/X**，唸作「V of X」= X 的屬和弦。

原則：
1. V/X 的根音比 X **低一個純五度**（或高一個純四度）——和 V → I 的根音關係完全一樣。
2. V/X 通常做成**屬七和弦（dominant 7th）**，導音效果更強。
3. V/X → X 的解決路徑就是一次**局部的 V → I**。

### C 大調的副屬和弦一覽

| 副屬和弦 | 唸作 | 解決到 | C 大調中的和弦 | 組成音 | 含臨時升降音 |
|----------|------|--------|---------------|--------|------------|
| V/ii     | V of ii | Dm（ii） | A7 | A–C#–E–G | C# ↑ |
| V/iii    | V of iii | Em（iii） | B7 | B–D#–F#–A | D#, F# ↑ |
| V/IV     | V of IV | F（IV） | C7 | C–E–G–B♭ | B♭ ↓ |
| V/V      | V of V | G（V） | D7 | D–F#–A–C | F# ↑ |
| V/vi     | V of vi | Am（vi） | E7 | E–G#–B–D | G# ↑ |

> **為什麼 V/I 不在表裡？** V/I 就是 G7（C 大調的 V7），那是正規的屬和弦，不是「副」屬和弦——副屬和弦專指那些「借來的臨時 V」。

### 重要細節：臨時升降音

注意上表最右欄：幾乎每個副屬和弦都含有**不屬於 C 大調的音**（C#、D#、F#、B♭、G#）。這些臨時的升降音就是讓副屬和弦聽起來「有點不一樣」的來源——它們製造了新的導音張力。

---

## 3. 辨認方法

遇到一個「看起來不屬於這個調」的和弦，如何判斷它是不是副屬和弦？

**三步驟辨認法**：

1. **找出含臨時升降音的和弦** — 比如在 C 大調看到 A7（含 C#），C# 不屬於 C 大調，可疑。
2. **計算它解決到哪裡** — A7 的根音 A，往下純五度 = D；往上純四度 = D。所以 A7 應該解決到 Dm。
3. **確認解決對象是調內和弦** — Dm 是 C 大調的 ii，是自然和弦，符合。→ 確認 A7 = V/ii。

**反例辨認**：如果一個「外來」和弦解決到的目標**也不是調內和弦**，那可能是轉調，不是離調。

### 具體範例走一遍

進行：**C → A7 → Dm → G7 → C**

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I    (C):   C–E–G      ●   ●   ●
V/ii (A7):  A–C#–E–G       ●   ●   ● （C# 是黑鍵，不屬於 C 大調）
ii   (Dm):  D–F–A          ↑
V7   (G7):  G–B–D–F            ●   ●   ●
I    (C):   C–E–G      ●   ●   ●
```

分析：
- A7 含 C#（C 大調沒有這個音）→ 可疑
- A7 → Dm：根音 A 往下純五度 = D，Dm 是 C 大調的 ii → **確認是 V/ii**
- A7 在 C 大調裡只「停留一瞬間」，離調到 Dm 的世界後，G7 → C 把音樂帶回 C 大調

## 4. 常見用法

### 4-a．V/V → V → I：強化到 V 的推進

公式：I → **D7** → G → C

在 C 大調裡，D7 是 G 大調的 V7——它在解決到 G 之前製造了額外的張力，讓「到達 G」感覺比直接從 C 過去更有份量。

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I    (C):   C–E–G      ●   ●   ●
V/V  (D7):  D–F#–A–C       ●  ↑  ●   ● （F# 是黑鍵）
V    (G):   G–B–D              ↑  ●   ●   ●
I    (C):   C–E–G      ●   ●   ●
```

F# → G 的導音解決（半音上行）是讓 D7 → G 如此有力的原因。

### 4-b．V/vi：流行歌最愛

公式：I → **E7** → Am → ...

C 大調中，E7（E–G#–B–D）解決到 Am——這是流行歌和拉丁音樂裡非常常見的色彩和弦。G# 不屬於 C 大調，但它是 A 小調的導音，向上半音解決到 A，給 Am 的出現一種額外的「被迎接」的感覺。

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

I    (C):   C–E–G      ●   ●   ●
V/vi (E7):  E–G#–B–D       ●  ↑  ●       （G# 是黑鍵）
vi   (Am):  A–C–E      ●   ●       ●   ← G# 解決到 A
```

很多流行歌的主歌用這個手法讓 Am 出現得更有感覺：C → E7 → Am，比 C → Am 多了一份「引力」。

### 4-c．V/IV：主和弦變成屬和弦

公式：**C7** → F

這個特別有趣：在 C 大調裡，C 本來是主和弦（I），但只要加上小七度（B♭），C7 = C–E–G–B♭，就成了 F 的屬七和弦（V7/IV）。C7 → F 是讓 IV（F）有特別存在感的手法，藍調音樂中大量使用。

```
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

V/IV (C7):  C–E–G–Bb  ●   ●   ●   ↓ （Bb = A#，黑鍵）
IV   (F):   F–A–C          ●   ●   ●  ← Bb 解決到 A
```

B♭ → A（半音下行解決）帶來了 F 和弦到來的張力釋放感。

## 5. 鍵盤範例：完整四小節

以下是包含 V/ii 的完整 4 小節進行，在 C 大調彈奏：

**C → A7 → Dm → G7 → C**

```
  ┌──┐ ┌──┐   ┌──┐ ┌──┐ ┌──┐
  │C#│ │D#│   │F#│ │G#│ │A#│
  └──┘ └──┘   └──┘ └──┘ └──┘
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ C │ D │ E │ F │ G │ A │ B │ C │
└───┴───┴───┴───┴───┴───┴───┴───┘

第1拍  I  (C):   C–E–G      ●   ●   ●
第2拍 V/ii(A7):  A–C#–E–G       ●  ↑  ●   ● （C# 黑鍵）
第3拍  ii (Dm):  D–F–A          ●   ●       ●
第4拍  V7 (G7):  G–B–D–F            ●   ●   ●   ●
第1拍  I  (C):   C–E–G      ●   ●   ●
```

**聽的重點**：

- 彈到 A7 時，注意那個 C#——它不屬於 C 大調，帶來一種「稍微離開了」的感覺。
- A7 → Dm：C# 向上半音解決到 D，G 向下半音解決到 F——聽聽看 Dm 是不是感覺被「迎接」進來的。
- G7 → C：熟悉的屬七到主和弦，你又回家了。

**建議練習**：先分別彈 A7 和 Dm，熟悉 A7 的「外來感」；再彈完整進行，感受 A7 「拉著」Dm 到來的引力。

## 6. 副屬和弦 vs. 借用和弦

初學者容易混淆的：

| 概念 | 定義 | 來源 | 常見例子 |
|------|------|------|---------|
| **副屬和弦** | 某個調內和弦的臨時 V | 來自「目標和弦的調」 | V/ii = A7（C 大調中） |
| **借用和弦** | 從同主音小調借來的和弦 | 來自「平行小調」 | C 大調借用 iv（Fm）、bVII（B♭） |

兩者都含有「不屬於本調的音」，但來源和功能不同：副屬和弦的目的是強化某個目標和弦；借用和弦的目的是改變色彩（通常讓大調帶點小調的暗色）。

## 7. 小測驗

試著回答以下問題（答案在下方）：

1. 在 C 大調中，V/vi 是什麼和弦？它的組成音是什麼？它解決到哪個和弦？
2. 你在 C 大調的進行中看到 D7（D-F#-A-C），F# 不屬於 C 大調。這是副屬和弦嗎？它解決到哪裡？
3. 副屬和弦（secondary dominant）和轉調（modulation）都會引入不屬於本調的音，它們最關鍵的區別是什麼？
4. V/IV 在 C 大調中是什麼和弦？為什麼它特別有趣？
5. 用三步驟辨認法分析：在 C 大調中出現 B7（B-D#-F#-A），這是副屬和弦嗎？它解決到哪裡？含有哪些臨時升降音？
6. 為什麼沒有「V/I」這個概念？V/I 就是什麼？
7. 副屬和弦和借用和弦（borrowed chord）都含有不屬於本調的音。以 C 大調為例，A7 和 Fm 分別是哪一種？它們的來源有什麼不同？
8. 在 C 大調中，V/ii → ii → V → I 的完整進行是什麼具體和弦？其中 V/ii 的導音解決路徑是什麼？
9. C 大調中可以有 V/vii° 嗎？為什麼？（提示：vii° 是什麼性質的和弦？）
10. 一段 C 大調進行：C → C7 → F → Fm → C。其中 C7 和 Fm 分別是什麼（副屬和弦 or 借用和弦）？

<details>
<summary>答案</summary>

1. **E7（E-G#-B-D），解決到 Am（vi）** — V/vi 的根音比 vi（Am）低一個純五度：A 往下純五度 = E。做成屬七和弦 = E7。其中 G# 是 A 小調的導音，不屬於 C 大調，半音上行解決到 A。
2. **是，V/V，解決到 G（V）** — D7 的根音 D 往下純五度 = G，G 是 C 大調的 V 級（自然和弦），確認 D7 = V/V。F# 是 G 大調的導音，半音上行到 G，強化了「到達 G」的推進感。
3. **持續時間和調性重心是否改變** — 副屬和弦只是短暫「拜訪」（1-2 個和弦即回到原調），不改變整體調性重心，像一日遊；轉調則真的在新調停留夠久、建立新的 V→I 終止式，讓聽眾把新主音當作「家」，像搬家。
4. **C7（C-E-G-Bb），因為主和弦 I 變成了屬七和弦** — 在 C 大調中，C 本來是穩定的主和弦（I），但加上 Bb 變成 C7 後，它就成了 F 的屬七和弦（V7/IV）。一個本來最穩定的和弦突然充滿張力，要解決到 IV（F），這在藍調音樂中大量使用。
5. **是，V/iii，解決到 Em（iii）** — 步驟 1：B7 含 D# 和 F#，都不屬於 C 大調。步驟 2：根音 B 往下純五度 = E，往上純四度 = E。步驟 3：Em 是 C 大調的 iii 級（自然和弦），確認 B7 = V/iii。臨時升降音：D#（C 大調中 D 升半音）和 F#（F 升半音）。
6. **因為 V/I 就是 V（正規的屬和弦），不是「副」屬和弦** — 在 C 大調中，V/I = G7（G 大調的 V7 解決到 C），但 G7 本來就是 C 大調的 V7。「副屬和弦」專指那些「借來的臨時 V」，正規的 V 不算在內。
7. **A7 是副屬和弦（V/ii），Fm 是借用和弦（iv，借自 C 小調）** — 副屬和弦來自「目標和弦的調」（A7 來自 D 小調，解決到 Dm）；借用和弦來自「同主音的平行小調」（Fm 借自 C 小調，用來改變色彩，讓大調帶暗色）。兩者功能不同：副屬強化目標和弦，借用改變整體色彩。
8. **A7 → Dm → G7 → C** — V/ii = A7（A-C#-E-G），ii = Dm，V = G7，I = C。A7 的導音解決：C#（A7 的三音 = D 小調的導音）半音上行到 D（Dm 的根音），G（A7 的七音）半音下行到 F（Dm 的三音）。
9. **理論上不建議使用 V/vii°** — vii° 是減三和弦（B° = B-D-F），不是大三或小三和弦。副屬和弦的目的是用 V→I 的引力「迎接」目標和弦，但減三和弦本身極度不穩定，無法像大/小三和弦那樣「被迎接」成為臨時主音。所以實際音樂中幾乎不見 V/vii°。
10. **C7 是副屬和弦（V/IV），Fm 是借用和弦（iv，借自 C 小調）** — C7 含 Bb（不屬於 C 大調），解決到 F = V/IV。Fm（F-Ab-C）含 Ab（不屬於 C 大調），來自 C 小調（C 小調的 iv = Fm），是借用和弦，用來在結尾製造柔和的暗色效果。

</details>
